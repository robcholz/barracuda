# Barracuda

Barracuda is the agentic platform for embedded devices: everything is a Plugin,
and an agent helps at every step. Every capability on a device is a Plugin,
composed into one firmware for a selected Board and Platform.

## Documentation

All documentation lives in [docs/](docs/), published as a Mintlify site. Start
with the [overview](docs/index.mdx), then
[Build and run](docs/get-started/build-and-run.mdx).

Preview the site locally from `docs/`:

```bash
npx mint dev
```
