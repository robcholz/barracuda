# Barracuda

Barracuda is a plugin-based embedded runtime: every capability on a device is a
Plugin, composed into one firmware for a selected Board and Platform.

## Documentation

All documentation lives in [docs/](docs/), published as a Mintlify site. Start
with the [overview](docs/index.mdx), then
[Build and run](docs/get-started/build-and-run.mdx).

Preview the site locally from `docs/`:

```bash
npx mint dev
```
