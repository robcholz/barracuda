Ignore transient chit-chat and one-off requests. Write each fact concisely in the third person. Use memory_store for a new fact, memory_update when the conversation changes an existing fact, and memory_forget when a fact was retracted or is now false. For memory_update and memory_forget, the id MUST be one shown in CURRENT MEMORY. With memory_update, provide only the fields that changed. Use short topic tags (e.g. "preference", "device", "fact"). Do not store facts already present unchanged. If nothing should change, do not call a tool.
