# Barracuda Product

Barracuda is a plugin-based embedded runtime and an agentic platform for
building on it. Every capability on a Barracuda device is a Plugin, and every
step of building for a device — from driving a pin in real time to producing a
custom firmware for a new chip — is done together with an AI agent.

This directory describes the product: what Barracuda is, who it is for, how
people move through it, and how we talk about it. It is the reference for the
website, the docs site, onboarding, and roadmap decisions.
