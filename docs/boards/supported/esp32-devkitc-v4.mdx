The ESP32-DevKitC V4 is an ESP32 Board from Espressif.

- Board ID: `esp32-devkitc-v4`
- Vendor: Espressif
- Chip: ESP32
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32-none-elf`
- Profile: [`headless`](/boards/profiles) (the default)
- Flash layout: `boards/configs/esp32-devkitc-v4/partitions.csv`

## Build and run

```bash terminal
cargo board select esp32-devkitc-v4
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).
