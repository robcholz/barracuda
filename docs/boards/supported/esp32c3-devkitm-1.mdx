The ESP32-C3-DevKitM-1 is an ESP32-C3 Board from Espressif.

- Board ID: `esp32c3-devkitm-1`
- Vendor: Espressif
- Chip: ESP32-C3
- Platform: [ESP32](/platforms/esp32)
- Rust target: `riscv32imc-unknown-none-elf`
- Profile: [`connected`](/boards/profiles)
- Flash layout: `boards/configs/esp32c3-devkitm-1/partitions.csv`

## Build and run

```bash terminal
cargo board select esp32c3-devkitm-1
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).
