The ESP32-C6-DevKitC-1 is an ESP32-C6 Board from Espressif.

- Board ID: `esp32c6-devkitc-1`
- Vendor: Espressif
- Chip: ESP32-C6
- Platform: [ESP32](/platforms/esp32)
- Rust target: `riscv32imac-unknown-none-elf`
- Profile: [`headless`](/boards/profiles) (the default)
- Flash layout: `boards/configs/esp32c6-devkitc-1/partitions.csv`

## Build and run

```bash terminal
cargo board select esp32c6-devkitc-1
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).
