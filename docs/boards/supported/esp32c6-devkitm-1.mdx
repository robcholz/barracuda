The ESP32-C6-DevKitM-1 is an ESP32-C6 Board from Espressif.

- Board ID: `esp32c6-devkitm-1`
- Vendor: Espressif
- Chip: ESP32-C6
- Platform: [ESP32](/platforms/esp32)
- Rust target: `riscv32imac-unknown-none-elf`
- Profile: [`headless`](/boards/profiles) (the default)
- Flash layout: `boards/configs/esp32c6-devkitm-1/partitions.csv`

## Build and run

```bash terminal
cargo board select esp32c6-devkitm-1
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).

## Peripherals

This Board declares no peripherals yet. The network, the Agent, and the
portal run on it; add its devices to
`boards/configs/esp32c6-devkitm-1/board.yml` to drive them. See
[Peripheral composition](/boards/peripherals).
