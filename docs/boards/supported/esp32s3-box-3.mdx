The ESP32-S3-BOX-3 is an ESP32-S3 Board from Espressif.

- Board ID: `esp32s3-box-3`
- Vendor: Espressif
- Chip: ESP32-S3
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32s3-none-elf`
- Profile: [`headless`](/boards/profiles) (the default)
- Flash layout: `boards/configs/esp32s3-box-3/partitions.csv`

## Build and run

```bash terminal
cargo board select esp32s3-box-3
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).

## Peripherals

This Board declares no peripherals yet. The network, the Agent, and the
portal run on it; add its devices to
`boards/configs/esp32s3-box-3/board.yml` to drive them. See
[Peripheral composition](/boards/peripherals).
