The ESP32-S3-BOX-3 is an ESP32-S3 Board from Espressif.

- Board ID: `esp32s3-box-3`
- Vendor: Espressif
- Chip: ESP32-S3
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32s3-none-elf`
- Profile: [`screen`](/boards/profiles)
- Flash layout: `boards/configs/esp32s3-box-3/partitions.csv`

## Build and run

```bash terminal
cargo board select esp32s3-box-3
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).
