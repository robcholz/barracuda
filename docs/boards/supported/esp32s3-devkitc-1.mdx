The ESP32-S3-DevKitC-1 is an ESP32-S3 Board from Espressif.

- Board ID: `esp32s3-devkitc-1`
- Vendor: Espressif
- Chip: ESP32-S3
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32s3-none-elf`
- Profile: [`headless`](/boards/profiles) (the default)
- Flash layout: `boards/configs/esp32s3-devkitc-1/partitions.csv`

## Build and run

```bash terminal
cargo board select esp32s3-devkitc-1
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).

## Exposed pins

Lua scripts open these pins by name.

| Name | Pin |
| --- | --- |
| `expansion-1` | `GPIO1` |
| `expansion-2` | `GPIO2` |
| `expansion-3` | `GPIO3` |
| `expansion-4` | `GPIO4` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("expansion-1", "up")
print(pin:read())
```
