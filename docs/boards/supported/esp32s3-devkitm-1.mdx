The ESP32-S3-DevKitM-1 is an ESP32-S3 Board from Espressif.

- Board ID: `esp32s3-devkitm-1`
- Vendor: Espressif
- Chip: ESP32-S3
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32s3-none-elf`
- Profile: [`headless`](/boards/profiles) (the default)
- Flash layout: `boards/configs/esp32s3-devkitm-1/partitions.csv`

## Build and run

```bash terminal
cargo board select esp32s3-devkitm-1
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).
