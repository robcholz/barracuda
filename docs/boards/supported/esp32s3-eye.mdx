The ESP32-S3-EYE is an ESP32-S3 Board from Espressif.

- Board ID: `esp32s3-eye`
- Vendor: Espressif
- Chip: ESP32-S3
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32s3-none-elf`
- Profile: [`screen`](/boards/profiles)
- Flash layout: `boards/configs/esp32s3-eye/partitions.csv`

## Build and run

```bash terminal
cargo board select esp32s3-eye
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).

## Peripherals

| Device | What it is | Lua package |
| --- | --- | --- |
| `camera` | Camera (OV2640) | [`camera`](/plugins/vm-camera) |
| `display` | Display (MIPI DBI) | [`display`](/plugins/vm-display) |
| `buttons` | Buttons (ADC resistor ladder) | — |

The four front buttons share one ADC ladder on GPIO1. A Board declares one
`buttons` device, so the BOOT button (GPIO0) is not declared.
