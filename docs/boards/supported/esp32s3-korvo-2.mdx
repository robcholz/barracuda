The ESP32-S3-Korvo-2 is an ESP32-S3 Board from Espressif.

- Board ID: `esp32s3-korvo-2`
- Vendor: Espressif
- Chip: ESP32-S3
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32s3-none-elf`
- Profile: [`headless`](/boards/profiles) (the default)
- Flash layout: `boards/configs/esp32s3-korvo-2/partitions.csv`

## Build and run

```bash terminal
cargo board select esp32s3-korvo-2
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).

## Peripherals

| Device | What it is | Lua package |
| --- | --- | --- |
| `camera` | Camera (OV3660) | [`camera`](/plugins/vm-camera) |
| `buttons` | Buttons (ADC resistor ladder) | [`buttons`](/plugins/vm-buttons) |
| `boot-button` | BOOT button (GPIO0) | [`buttons`](/plugins/vm-buttons) |
| `battery` | Battery voltage (ADC resistor divider) | [`power_monitor`](/plugins/vm-power-monitor) |
| `audio-codec` | Audio codec (ES8311 and ES7210) | [`audio`](/plugins/vm-audio) |

The six buttons on the ADC ladder are the primary `buttons` device. GPIO0,
the BOOT button, is also the MOSI of the optional LCD board's SPI bus, which
this Board does not declare.
