The M5Stack AirQ is an ESP32-S3 Board from M5Stack.

- Board ID: `m5stack-airq`
- Vendor: M5Stack
- Chip: ESP32-S3
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32s3-none-elf`
- Profile: [`screen`](/boards/profiles)
- Flash layout: `boards/configs/m5stack-airq/partitions.csv`

## Build and run

```bash terminal
cargo board select m5stack-airq
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).

## Peripherals

| Device | What it is | Lua package |
| --- | --- | --- |
| `led-strip` | RGB LED (WS2812, GPIO21) | [`light`](/plugins/vm-led-strip) |
| `display` | E-paper display, 1.54-inch 200 x 200 (GDEH0154D67 or GDEW0154M09, identified at start-up) | [`display`](/plugins/vm-display) |
| `environment-sensor` | Air-quality sensors: SEN55 (particulate matter, VOC and NOx indices, temperature, humidity) and SCD40 (CO2), as one device | [`environment`](/plugins/vm-environment-sensor) |
| `real-time-clock` | Real-time clock (BM8563) | — |
| `buttons` | Buttons A and B (GPIO0, GPIO8) | — |

The Platform entry drives `GPIO46`, the battery power latch (`hardware.power-hold`), high before anything else is built, so the Board stays on without USB power once its power button is released.

## Exposed pins

Lua scripts open these pins by name.

| Name | Pin |
| --- | --- |
| `port-a-scl` | `GPIO15` |
| `port-a-sda` | `GPIO13` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("port-a-scl", "up")
print(pin:read())
```
