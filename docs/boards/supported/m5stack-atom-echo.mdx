The M5Stack ATOM Echo is an ESP32 Board from M5Stack.

- Board ID: `m5stack-atom-echo`
- Vendor: M5Stack
- Chip: ESP32
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32-none-elf`
- Profile: [`headless`](/boards/profiles) (the default)
- Flash layout: `boards/configs/m5stack-atom-echo/partitions.csv`

## Build and run

```bash terminal
cargo board select m5stack-atom-echo
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).

## Peripherals

This Board declares no peripherals yet. The network, the Agent, and the
portal run on it; add its devices to
`boards/configs/m5stack-atom-echo/board.yml` to drive them. See
[Peripheral composition](/boards/peripherals).

## Exposed pins

Lua scripts open these pins by name.

| Name | Pin |
| --- | --- |
| `grove-g26` | `GPIO26` |
| `grove-g32` | `GPIO32` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("grove-g26", "up")
print(pin:read())
```
