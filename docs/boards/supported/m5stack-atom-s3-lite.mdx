The M5Stack AtomS3 Lite is an ESP32-S3 Board from M5Stack.

- Board ID: `m5stack-atom-s3-lite`
- Vendor: M5Stack
- Chip: ESP32-S3
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32s3-none-elf`
- Profile: [`headless`](/boards/profiles) (the default)
- Flash layout: `boards/configs/m5stack-atom-s3-lite/partitions.csv`

## Build and run

```bash terminal
cargo board select m5stack-atom-s3-lite
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).

## Peripherals

This Board declares no peripherals yet. The network, the Agent, and the
portal run on it; add its devices to
`boards/configs/m5stack-atom-s3-lite/board.yml` to drive them. See
[Peripheral composition](/boards/peripherals).

## Exposed pins

Lua scripts open these pins by name.

| Name | Pin |
| --- | --- |
| `grove-g1` | `GPIO1` |
| `grove-g2` | `GPIO2` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("grove-g1", "up")
print(pin:read())
```
