The M5Stack AtomS3R-CAM is an ESP32-S3 Board from M5Stack.

- Board ID: `m5stack-atom-s3r-cam`
- Vendor: M5Stack
- Chip: ESP32-S3
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32s3-none-elf`
- Profile: [`headless`](/boards/profiles) (the default)
- Flash layout: `boards/configs/m5stack-atom-s3r-cam/partitions.csv`

## Build and run

```bash terminal
cargo board select m5stack-atom-s3r-cam
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).

## Peripherals

| Device | What it is | Lua package |
| --- | --- | --- |
| `inertial-measurement` | Motion sensor (BMI270) | [`motion`](/plugins/vm-imu) |
| `infrared` | Infrared transmitter (GPIO47) | [`infrared`](/plugins/vm-infrared) |

## Exposed pins

Lua scripts open these pins by name.

| Name | Pin |
| --- | --- |
| `grove-g1` | `GPIO1` |
| `grove-g2` | `GPIO2` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("grove-g1", "up")
print(pin:read())
```
