The M5Stack AtomS3R-Ext is an ESP32-S3 Board from M5Stack.

- Board ID: `m5stack-atom-s3r-ext`
- Vendor: M5Stack
- Chip: ESP32-S3
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32s3-none-elf`
- Profile: [`headless`](/boards/profiles) (the default)
- Flash layout: `boards/configs/m5stack-atom-s3r-ext/partitions.csv`

## Build and run

```bash terminal
cargo board select m5stack-atom-s3r-ext
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).

## Exposed pins

Lua scripts open these pins by name.

| Name | Pin |
| --- | --- |
| `grove-g1` | `GPIO1` |
| `grove-g2` | `GPIO2` |
| `header-g3` | `GPIO3` |
| `header-g4` | `GPIO4` |
| `header-g9` | `GPIO9` |
| `header-g10` | `GPIO10` |
| `header-g11` | `GPIO11` |
| `header-g12` | `GPIO12` |
| `header-g13` | `GPIO13` |
| `header-g17` | `GPIO17` |
| `header-g21` | `GPIO21` |
| `header-g40` | `GPIO40` |
| `header-g42` | `GPIO42` |
| `header-g46` | `GPIO46` |
| `header-g48` | `GPIO48` |

The `header-*` pins are on the 2.54 mm proto header.

```lua
local gpio = require("gpio")
local pin = gpio.open_input("grove-g1", "up")
print(pin:read())
```
