The M5Stack AtomS3U is an ESP32-S3 Board from M5Stack.

- Board ID: `m5stack-atom-s3u`
- Vendor: M5Stack
- Chip: ESP32-S3
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32s3-none-elf`
- Profile: [`headless`](/boards/profiles) (the default)
- Flash layout: `boards/configs/m5stack-atom-s3u/partitions.csv`

## Build and run

```bash terminal
cargo board select m5stack-atom-s3u
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).

## Peripherals

| Device | What it is | Lua package |
| --- | --- | --- |
| `led-strip` | RGB LED (WS2812, GPIO35) | [`light`](/plugins/vm-led-strip) |
| `buttons` | Button (GPIO41) | — |
| `infrared` | Infrared transmitter (GPIO12) | [`infrared`](/plugins/vm-infrared) |

## Exposed pins

Lua scripts open these pins by name.

| Name | Pin |
| --- | --- |
| `grove-g1` | `GPIO1` |
| `grove-g2` | `GPIO2` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("grove-g1", "up")
print(pin:read())
```
