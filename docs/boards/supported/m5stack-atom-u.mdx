The M5Stack ATOM U is an ESP32 Board from M5Stack.

- Board ID: `m5stack-atom-u`
- Vendor: M5Stack
- Chip: ESP32
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32-none-elf`
- Profile: [`connected`](/boards/profiles)
- Flash layout: `boards/configs/m5stack-atom-u/partitions.csv`

## Build and run

```bash terminal
cargo board select m5stack-atom-u
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).

## Peripherals

| Device | What it is | Lua package |
| --- | --- | --- |
| `led-strip` | RGB LED (SK6812) | [`light`](/plugins/vm-led-strip) |
| `buttons` | Button (GPIO39) | [`buttons`](/plugins/vm-buttons) |
| `microphone` | Microphone (SPM1423 PDM) | [`audio`](/plugins/vm-audio) |
| `infrared` | Infrared transmitter (GPIO12) | [`infrared`](/plugins/vm-infrared) |
