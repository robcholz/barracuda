The M5Stack Atom VoiceS3R is an ESP32-S3 Board from M5Stack.

- Board ID: `m5stack-atom-voice-s3r`
- Vendor: M5Stack
- Chip: ESP32-S3
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32s3-none-elf`
- Profile: [`headless`](/boards/profiles) (the default)
- Flash layout: `boards/configs/m5stack-atom-voice-s3r/partitions.csv`

## Build and run

```bash terminal
cargo board select m5stack-atom-voice-s3r
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).
