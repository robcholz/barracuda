The M5Stack Basic is an ESP32 Board from M5Stack.

- Board ID: `m5stack-basic`
- Vendor: M5Stack
- Chip: ESP32
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32-none-elf`
- Profile: [`screen`](/boards/profiles)
- Flash layout: `boards/configs/m5stack-basic/partitions.csv`

## Build and run

```bash terminal
cargo board select m5stack-basic
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).

## Peripherals

| Device | What it is | Lua package |
| --- | --- | --- |
| `display` | Display (MIPI DBI) | [`display`](/plugins/vm-display) |
| `power-monitor` | Battery level (IP5306) | [`power_monitor`](/plugins/vm-power-monitor) |
| `buttons` | Buttons A, B, C (GPIO39, GPIO38, GPIO37) | — |

The IP5306 reports the battery level in 25 % steps and whether it charges; it
measures no voltage or current, so `measure` fails on this Board.

The internal I2C bus of the battery chip is also Port A (GPIO21, GPIO22), so
Port A is not an exposed pin pair.
