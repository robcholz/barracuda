The M5Stack Capsule is an ESP32-S3 Board from M5Stack.

- Board ID: `m5stack-capsule`
- Vendor: M5Stack
- Chip: ESP32-S3
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32s3-none-elf`
- Profile: [`headless`](/boards/profiles) (the default)
- Flash layout: `boards/configs/m5stack-capsule/partitions.csv`

## Build and run

```bash terminal
cargo board select m5stack-capsule
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).

## Peripherals

| Device | What it is | Lua package |
| --- | --- | --- |
| `inertial-measurement` | IMU (BMI270) | [`motion`](/plugins/vm-imu) |
| `battery` | Battery voltage (ADC resistor divider) | [`power_monitor`](/plugins/vm-power-monitor) |
| `microphone` | Microphone (PDM) | [`audio`](/plugins/vm-audio) |
| `micro-sd` | microSD card slot (FAT, SPI) | — |

## Exposed pins

Lua scripts open these pins by name.

| Name | Pin |
| --- | --- |
| `grove-g13` | `GPIO13` |
| `grove-g15` | `GPIO15` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("grove-g13", "up")
print(pin:read())
```
