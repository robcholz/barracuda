The M5Stack Cardputer-Adv is an ESP32-S3 Board from M5Stack.

- Board ID: `m5stack-cardputer-adv`
- Vendor: M5Stack
- Chip: ESP32-S3
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32s3-none-elf`
- Profile: [`screen`](/boards/profiles)
- Flash layout: `boards/configs/m5stack-cardputer-adv/partitions.csv`

## Build and run

```bash terminal
cargo board select m5stack-cardputer-adv
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).

## Exposed pins

Lua scripts open these pins by name.

| Name | Pin |
| --- | --- |
| `grove-g1` | `GPIO1` |
| `grove-g2` | `GPIO2` |
| `header-g3` | `GPIO3` |
| `header-g4` | `GPIO4` |
| `header-g5` | `GPIO5` |
| `header-g6` | `GPIO6` |
| `header-g13` | `GPIO13` |
| `header-g15` | `GPIO15` |

The `header-*` pins are on the EXT 2.54-14P header. Its SPI pins are the
microSD bus and its I2C pins the internal bus, so they are not exposed.

```lua
local gpio = require("gpio")
local pin = gpio.open_input("grove-g1", "up")
print(pin:read())
```
