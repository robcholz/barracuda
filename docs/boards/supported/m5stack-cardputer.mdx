The M5Stack Cardputer is an ESP32-S3 Board from M5Stack.

- Board ID: `m5stack-cardputer`
- Vendor: M5Stack
- Chip: ESP32-S3
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32s3-none-elf`
- Profile: [`screen`](/boards/profiles)
- Flash layout: `boards/configs/m5stack-cardputer/partitions.csv`

## Build and run

```bash terminal
cargo board select m5stack-cardputer
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).

## Peripherals

| Device | What it is | Lua package |
| --- | --- | --- |
| `display` | Display (MIPI DBI) | [`display`](/plugins/vm-display) |
| `buttons` | G0 button (GPIO0) | — |
| `keyboard` | 56-key keyboard (74HC138 matrix) | [`keyboard`](/plugins/vm-keyboard) |
| `battery` | Battery voltage (ADC resistor divider) | [`power_monitor`](/plugins/vm-power-monitor) |
| `audio` | Audio (NS4168 amplifier, SPM1423 PDM microphone) | [`audio`](/plugins/vm-audio) |
| `micro-sd` | microSD card slot (FAT, SPI) | — |

The StampS3's WS2812 RGB LED on GPIO21 is not declared: the microSD card and
the display each take one of the ESP32-S3's two SPI controllers, which leaves
none for the LED's SPI output.

## Exposed pins

Lua scripts open these pins by name.

| Name | Pin |
| --- | --- |
| `grove-g1` | `GPIO1` |
| `grove-g2` | `GPIO2` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("grove-g1", "up")
print(pin:read())
```
