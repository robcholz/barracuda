The M5Stack Chain Captain is an ESP32-S3 Board from M5Stack.

- Board ID: `m5stack-chain-captain`
- Vendor: M5Stack
- Chip: ESP32-S3
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32s3-none-elf`
- Profile: [`screen`](/boards/profiles)
- Flash layout: `boards/configs/m5stack-chain-captain/partitions.csv`

## Build and run

```bash terminal
cargo board select m5stack-chain-captain
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).
