The M5Stack Chan is an ESP32-S3 Board from M5Stack.

- Board ID: `m5stack-chan`
- Vendor: M5Stack
- Chip: ESP32-S3
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32s3-none-elf`
- Profile: [`screen`](/boards/profiles)
- Flash layout: `boards/configs/m5stack-chan/partitions.csv`

## Build and run

```bash terminal
cargo board select m5stack-chan
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).

## Peripherals

| Device | What it is | Lua package |
| --- | --- | --- |
| `display` | Display (MIPI DBI) | [`display`](/plugins/vm-display) |

The FT6336U capacitive touch panel is not declared yet: no touch
implementation drives its controller.
