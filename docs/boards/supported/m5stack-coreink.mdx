The M5Stack CoreInk is an ESP32 Board from M5Stack.

- Board ID: `m5stack-coreink`
- Vendor: M5Stack
- Chip: ESP32
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32-none-elf`
- Profile: [`screen`](/boards/profiles)
- Flash layout: `boards/configs/m5stack-coreink/partitions.csv`

## Build and run

```bash terminal
cargo board select m5stack-coreink
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).

## Peripherals

| Device | What it is | Lua package |
| --- | --- | --- |
| `display` | E-paper display, 1.54-inch 200 x 200 (GDEH0154D67 or GDEW0154M09, identified at start-up) | [`display`](/plugins/vm-display) |
| `status-led` | Indicator LED | — |
| `real-time-clock` | Real-time clock (BM8563) | — |
| `buttons` | Rocker up, press, down, top button, power button (GPIO37, GPIO38, GPIO39, GPIO5, GPIO27) | — |
| `battery` | Battery voltage (ADC resistor divider) | [`power_monitor`](/plugins/vm-power-monitor) |

The Platform entry drives `GPIO12`, the battery power latch (`hardware.power-hold`), high before anything else is built, so the Board stays on without USB power once its power button is released.

## Exposed pins

Lua scripts open these pins by name.

| Name | Pin |
| --- | --- |
| `grove-g32` | `GPIO32` |
| `grove-g33` | `GPIO33` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("grove-g32", "up")
print(pin:read())
```
