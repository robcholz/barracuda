The M5Stack CoreS3 is an ESP32-S3 Board from M5Stack.

- Board ID: `m5stack-cores3`
- Vendor: M5Stack
- Chip: ESP32-S3
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32s3-none-elf`
- Profile: [`screen`](/boards/profiles)
- Flash layout: `boards/configs/m5stack-cores3/partitions.csv`

## Build and run

```bash terminal
cargo board select m5stack-cores3
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).

## Peripherals

| Device | What it is | Lua package |
| --- | --- | --- |
| `display` | Display (MIPI DBI) | [`display`](/plugins/vm-display) |
| `touch` | Touch controller (FT6336U) | — |
| `inertial-measurement` | Motion sensor (BMI270, with the BMM150 magnetometer on its auxiliary bus) | [`motion`](/plugins/vm-imu) |
| `environment-sensor` | Ambient-light and proximity sensor (LTR-553ALS) | [`environment`](/plugins/vm-environment-sensor) |
| `real-time-clock` | Real-time clock (BM8563) | — |
| `power-monitor` | Battery gauge (AXP2101) | [`power_monitor`](/plugins/vm-power-monitor) |
| `power-button` | Power button (AXP2101 power key) | — |
| `audio-codec` | Audio codec (AW88298 amplifier, ES7210 microphone ADC) | [`audio`](/plugins/vm-audio) |
| `camera` | Camera (GC0308, 320x240 RGB565) | [`camera`](/plugins/vm-camera) |

The touch implementation releases the controller's reset, P0_0 of the AW9523B
expander at `58h`, which is not a device of its own. The camera implementation
switches on the camera supply, the AXP2101's ALDO3, and releases the sensor's
reset, P1_0 of the same expander.

The battery gauge shares the PMIC with the display: it reads only the PMIC's
measurement registers, and the display keeps its regulators.

The AXP2101 measures no battery current, so `measure` reports the battery
voltage with zero current.

The microSD slot is not declared: its MISO, GPIO35, is also the display's D/C line, which the shared SPI bus cannot switch between the two.

The power button is read through the PMIC, which latches a short press when the
key is released and a long press once it has been held for the long-press time;
the button reads pressed in one sample for each. It sets and clears only the
key's own interrupt bits of the PMIC.

## Exposed pins

Lua scripts open these pins by name.

| Name | Pin |
| --- | --- |
| `port-a-scl` | `GPIO1` |
| `port-a-sda` | `GPIO2` |
| `port-b-g8` | `GPIO8` |
| `port-b-g9` | `GPIO9` |
| `port-c-g17` | `GPIO17` |
| `port-c-g18` | `GPIO18` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("port-a-scl", "up")
print(pin:read())
```
