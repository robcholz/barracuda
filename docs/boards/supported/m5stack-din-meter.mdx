The M5Stack DinMeter is an ESP32-S3 Board from M5Stack.

- Board ID: `m5stack-din-meter`
- Vendor: M5Stack
- Chip: ESP32-S3
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32s3-none-elf`
- Profile: [`screen`](/boards/profiles)
- Flash layout: `boards/configs/m5stack-din-meter/partitions.csv`

## Build and run

```bash terminal
cargo board select m5stack-din-meter
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).

## Peripherals

| Device | What it is | Lua package |
| --- | --- | --- |
| `led-strip` | RGB LED (WS2812, GPIO21) | [`light`](/plugins/vm-led-strip) |
| `display` | Display (MIPI DBI) | [`display`](/plugins/vm-display) |
| `real-time-clock` | Real-time clock (BM8563) | — |
| `buttons` | Buttons A (knob press) and B (GPIO42, GPIO0) | — |
| `battery` | Battery voltage (ADC resistor divider) | [`power_monitor`](/plugins/vm-power-monitor) |

## Exposed pins

Lua scripts open these pins by name.

| Name | Pin |
| --- | --- |
| `port-a-scl` | `GPIO15` |
| `port-a-sda` | `GPIO13` |
| `port-b-g1` | `GPIO1` |
| `port-b-g2` | `GPIO2` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("port-a-scl", "up")
print(pin:read())
```
