The M5Stack Fire is an ESP32 Board from M5Stack.

- Board ID: `m5stack-fire`
- Vendor: M5Stack
- Chip: ESP32
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32-none-elf`
- Profile: [`screen`](/boards/profiles)
- Flash layout: `boards/configs/m5stack-fire/partitions.csv`

## Build and run

```bash terminal
cargo board select m5stack-fire
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).

## Peripherals

| Device | What it is | Lua package |
| --- | --- | --- |
| `led-strip` | 10 RGB LEDs in one chain (SK6812, GPIO15) | [`light`](/plugins/vm-led-strip) |
| `display` | Display (MIPI DBI) | [`display`](/plugins/vm-display) |
| `power-monitor` | Battery level (IP5306) | [`power_monitor`](/plugins/vm-power-monitor) |
| `inertial-measurement` | Motion sensor (MPU6886, or MPU9250 on early units) | [`motion`](/plugins/vm-imu) |
| `buttons` | Buttons A, B, C (GPIO39, GPIO38, GPIO37) | [`buttons`](/plugins/vm-buttons) |
| `micro-sd` | microSD card slot (FAT, SPI) | — |

The IP5306 reports the battery level in 25 % steps and whether it charges; it
measures no voltage or current, so `measure` fails on this Board.

The microSD card shares the display's SPI bus through its own chip select.

## Exposed pins

Lua scripts open these pins by name.

| Name | Pin |
| --- | --- |
| `port-b-g26` | `GPIO26` |
| `port-b-g36` | `GPIO36` |

Port A is the internal I2C bus, and Port C's `GPIO16` / `GPIO17` carry the
PSRAM, so neither is exposed.

```lua
local gpio = require("gpio")
local pin = gpio.open_input("port-b-g26", "up")
print(pin:read())
```
