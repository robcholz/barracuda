The M5Stack M5GO Lite is an ESP32 Board from M5Stack.

- Board ID: `m5stack-m5go-lite`
- Vendor: M5Stack
- Chip: ESP32
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32-none-elf`
- Profile: [`screen`](/boards/profiles)
- Flash layout: `boards/configs/m5stack-m5go-lite/partitions.csv`

## Build and run

```bash terminal
cargo board select m5stack-m5go-lite
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).
