The M5Stack NanoC6 is an ESP32-C6 Board from M5Stack.

- Board ID: `m5stack-nanoc6`
- Vendor: M5Stack
- Chip: ESP32-C6
- Platform: [ESP32](/platforms/esp32)
- Rust target: `riscv32imac-unknown-none-elf`
- Profile: [`connected`](/boards/profiles)
- Flash layout: `boards/configs/m5stack-nanoc6/partitions.csv`

## Build and run

```bash terminal
cargo board select m5stack-nanoc6
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).

## Peripherals

| Device | What it is | Lua package |
| --- | --- | --- |
| `status-led` | Indicator LED | — |
| `buttons` | Button (GPIO9) | [`buttons`](/plugins/vm-buttons) |
| `led-strip` | RGB LED (WS2812, GPIO20) | [`light`](/plugins/vm-led-strip) |
| `infrared` | Infrared transmitter (GPIO3) | [`infrared`](/plugins/vm-infrared) |

GPIO19 switches the RGB LED's supply; the LED turns it on at start.

## Exposed pins

Lua scripts open these pins by name.

| Name | Pin |
| --- | --- |
| `grove-g1` | `GPIO1` |
| `grove-g2` | `GPIO2` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("grove-g1", "up")
print(pin:read())
```
