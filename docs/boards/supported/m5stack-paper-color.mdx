The M5Stack Paper Color is an ESP32-S3 Board from M5Stack.

- Board ID: `m5stack-paper-color`
- Vendor: M5Stack
- Chip: ESP32-S3
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32s3-none-elf`
- Profile: [`screen`](/boards/profiles)
- Flash layout: `boards/configs/m5stack-paper-color/partitions.csv`

## Build and run

```bash terminal
cargo board select m5stack-paper-color
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).

## Peripherals

| Device | What it is | Lua package |
| --- | --- | --- |
| `display` | Color e-paper display, 4-inch 400 x 600, six colors (E Ink Spectra 6, ED2208 controller) | [`display`](/plugins/vm-display) |
| `audio-codec` | Audio codec (ES8311 and ES7210) | [`audio`](/plugins/vm-audio) |
| `real-time-clock` | Real-time clock (RX8130CE) | — |
| `power-monitor` | Battery gauge (M5PM1) | [`power_monitor`](/plugins/vm-power-monitor) |
| `buttons` | Buttons A, B, C (GPIO10, GPIO9, GPIO1) | — |
| `micro-sd` | microSD card slot (FAT, SPI) | — |

Spectra 6 has no partial update: every refresh redraws the whole panel and
takes 10 to 20 seconds.

The M5PM1 measures the battery voltage only. This Board does not route the
charger's status to it, so the battery reads as charging while VIN is present
and the cell is below 4.1 V.

The microSD card shares the e-paper panel's SPI bus through its own chip select.

## Exposed pins

Lua scripts open these pins by name.

| Name | Pin |
| --- | --- |
| `port-a-scl` | `GPIO5` |
| `port-a-sda` | `GPIO4` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("port-a-scl", "up")
print(pin:read())
```
