The M5Stack Paper DIY is an ESP32-S3 Board from M5Stack.

- Board ID: `m5stack-paper-diy`
- Vendor: M5Stack
- Chip: ESP32-S3
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32s3-none-elf`
- Profile: [`screen`](/boards/profiles)
- Flash layout: `boards/configs/m5stack-paper-diy/partitions.csv`

## Build and run

```bash terminal
cargo board select m5stack-paper-diy
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).

## Peripherals

| Device | What it is | Lua package |
| --- | --- | --- |
| `display` | E-paper display, 4.7-inch 540 x 960 portrait, 16 gray levels (ED047TC1, driven directly over the ESP32-S3 parallel bus; supply from the M5PM1) | [`display`](/plugins/vm-display) |
| `power-monitor` | Battery gauge (M5PM1) | [`power_monitor`](/plugins/vm-power-monitor) |
| `buttons` | Buttons A and B (GPIO4, GPIO3) | — |
| `power-button` | Power button (M5PM1 power key) | — |
| `micro-sd` | microSD card slot (FAT, SPI) | — |

The panel has no controller: Barracuda runs M5GFX's waveforms on the CPU
and clocks every frame out line by line, so a refresh holds the display until
it finishes.

The M5PM1 measures the battery voltage only; whether the battery charges comes
from the charger's status line on an M5PM1 pin.

The power button is read from the M5PM1's button status and reads pressed while
the key is down. The M5PM1 keeps its factory behaviour: a single click resets
the Board and a double click turns it off, so a click does not reach the
application unless the Board sets `single-click-reset: disable` on the device.
`buttons` is the primary `buttons` device.
