The M5Stack Paper Mono is an ESP32-S3 Board from M5Stack.

- Board ID: `m5stack-paper-mono`
- Vendor: M5Stack
- Chip: ESP32-S3
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32s3-none-elf`
- Profile: [`screen`](/boards/profiles)
- Flash layout: `boards/configs/m5stack-paper-mono/partitions.csv`

## Build and run

```bash terminal
cargo board select m5stack-paper-mono
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).

## Peripherals

| Device | What it is | Lua package |
| --- | --- | --- |
| `display` | E-paper display, 3.97-inch 480 x 800, 4 gray levels, with front light (SSD1677) | [`display`](/plugins/vm-display) |
| `inertial-measurement` | Motion sensor (BMI270) | [`motion`](/plugins/vm-imu) |
| `real-time-clock` | Real-time clock (RX8130CE) | — |
| `power-monitor` | Battery gauge (M5PM1) | [`power_monitor`](/plugins/vm-power-monitor) |
| `buttons` | Buttons A and B (GPIO2, GPIO3) | — |
| `power-button` | Power button (M5PM1 power key) | — |
| `buzzer` | Passive buzzer (GPIO42) | [`buzzer`](/plugins/vm-buzzer) |
| `nfc-reader` | NFC card reader (ST25R3916, `50h`, supply on M5IOE1 G4) | [`nfc`](/plugins/vm-nfc) |

The M5PM1 measures the battery voltage only. This Board does not route the
charger's status to it, so the battery reads as charging while VIN is present
and the cell is below 4.1 V.

The card reader's supply is switched by M5IOE1 G4; the reader turns it on at
start and waits a second for it, as M5Stack's UIFlow does, so this Board
starts about a second later. The PaperMono-Lite has no reader and is not
this Board.

The power button is read from the M5PM1's button status and reads pressed while
the key is down. The M5PM1 keeps its factory behaviour: a single click resets
the Board and a double click turns it off, so a click does not reach the
application unless the Board sets `single-click-reset: disable` on the device.
`buttons` is the primary `buttons` device.
