The M5Stack PaperS3 is an ESP32-S3 Board from M5Stack.

- Board ID: `m5stack-paper-s3`
- Vendor: M5Stack
- Chip: ESP32-S3
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32s3-none-elf`
- Profile: [`screen`](/boards/profiles)
- Flash layout: `boards/configs/m5stack-paper-s3/partitions.csv`

## Build and run

```bash terminal
cargo board select m5stack-paper-s3
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).

## Peripherals

| Device | What it is | Lua package |
| --- | --- | --- |
| `display` | E-paper display, 4.7-inch 540 x 960 portrait, 16 gray levels (ED047TC1, driven directly over the ESP32-S3 parallel bus) | [`display`](/plugins/vm-display) |
| `inertial-measurement` | IMU (BMI270) | [`motion`](/plugins/vm-imu) |

The panel has no controller: Barracuda runs M5GFX's waveforms on the CPU
and clocks every frame out line by line, so a refresh holds the display until
it finishes.

## Exposed pins

Lua scripts open these pins by name.

| Name | Pin |
| --- | --- |
| `grove-g1` | `GPIO1` |
| `grove-g2` | `GPIO2` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("grove-g1", "up")
print(pin:read())
```
