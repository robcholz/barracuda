The M5Stack Stamp C3 Mate is an ESP32-C3 Board from M5Stack.

- Board ID: `m5stack-stamp-c3-mate`
- Vendor: M5Stack
- Chip: ESP32-C3
- Platform: [ESP32](/platforms/esp32)
- Rust target: `riscv32imc-unknown-none-elf`
- Profile: [`headless`](/boards/profiles) (the default)
- Flash layout: `boards/configs/m5stack-stamp-c3-mate/partitions.csv`

## Build and run

```bash terminal
cargo board select m5stack-stamp-c3-mate
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).

## Peripherals

This Board declares no peripherals yet. The network, the Agent, and the
portal run on it; add its devices to
`boards/configs/m5stack-stamp-c3-mate/board.yml` to drive them. See
[Peripheral composition](/boards/peripherals).
