The M5Stack Stamp C3U is an ESP32-C3 Board from M5Stack.

- Board ID: `m5stack-stamp-c3u`
- Vendor: M5Stack
- Chip: ESP32-C3
- Platform: [ESP32](/platforms/esp32)
- Rust target: `riscv32imc-unknown-none-elf`
- Profile: [`headless`](/boards/profiles) (the default)
- Flash layout: `boards/configs/m5stack-stamp-c3u/partitions.csv`

## Build and run

```bash terminal
cargo board select m5stack-stamp-c3u
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).

## Peripherals

| Device | What it is | Lua package |
| --- | --- | --- |
| `led-strip` | RGB LED (SK6812, GPIO2) | [`light`](/plugins/vm-led-strip) |
| `buttons` | Button (GPIO9) | [`buttons`](/plugins/vm-buttons) |

## Exposed pins

Lua scripts open these pins by name.

| Name | Pin |
| --- | --- |
| `grove-g0` | `GPIO0` |
| `grove-g1` | `GPIO1` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("grove-g0", "up")
print(pin:read())
```
