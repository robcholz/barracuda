The M5Stack StampS3 is an ESP32-S3 Board from M5Stack.

- Board ID: `m5stack-stamp-s3`
- Vendor: M5Stack
- Chip: ESP32-S3
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32s3-none-elf`
- Profile: [`headless`](/boards/profiles) (the default)
- Flash layout: `boards/configs/m5stack-stamp-s3/partitions.csv`

## Build and run

```bash terminal
cargo board select m5stack-stamp-s3
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).
