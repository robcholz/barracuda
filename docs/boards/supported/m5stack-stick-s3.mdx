The M5Stack StickS3 is an ESP32-S3 Board from M5Stack.

- Board ID: `m5stack-stick-s3`
- Vendor: M5Stack
- Chip: ESP32-S3
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32s3-none-elf`
- Profile: [`screen`](/boards/profiles)
- Flash layout: `boards/configs/m5stack-stick-s3/partitions.csv`

## Build and run

```bash terminal
cargo board select m5stack-stick-s3
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).

## Peripherals

| Device | What it is | Lua package |
| --- | --- | --- |
| `display` | Display (MIPI DBI) | [`display`](/plugins/vm-display) |
| `inertial-measurement` | IMU (BMI270) | [`motion`](/plugins/vm-imu) |
| `audio-codec` | Audio codec (ES8311) | [`audio`](/plugins/vm-audio) |

## Exposed pins

Lua scripts open these pins by name.

| Name | Pin |
| --- | --- |
| `port-a-scl` | `GPIO10` |
| `port-a-sda` | `GPIO9` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("port-a-scl", "up")
print(pin:read())
```
