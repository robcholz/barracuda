The M5Stack StickC Plus is an ESP32 Board from M5Stack.

- Board ID: `m5stack-stickc-plus`
- Vendor: M5Stack
- Chip: ESP32
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32-none-elf`
- Profile: [`screen`](/boards/profiles)
- Flash layout: `boards/configs/m5stack-stickc-plus/partitions.csv`

## Build and run

```bash terminal
cargo board select m5stack-stickc-plus
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).

## Exposed pins

Lua scripts open these pins by name.

| Name | Pin |
| --- | --- |
| `grove-g32` | `GPIO32` |
| `grove-g33` | `GPIO33` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("grove-g32", "up")
print(pin:read())
```
