The M5Stack StickC Plus2 is an ESP32 Board from M5Stack.

- Board ID: `m5stack-stickc-plus2`
- Vendor: M5Stack
- Chip: ESP32
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32-none-elf`
- Profile: [`screen`](/boards/profiles)
- Flash layout: `boards/configs/m5stack-stickc-plus2/partitions.csv`

## Build and run

```bash terminal
cargo board select m5stack-stickc-plus2
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).

## Peripherals

| Device | What it is | Lua package |
| --- | --- | --- |
| `display` | Display (MIPI DBI) | [`display`](/plugins/vm-display) |
| `real-time-clock` | Real-time clock (BM8563) | — |
| `inertial-measurement` | Motion sensor (MPU6886) | [`motion`](/plugins/vm-imu) |
| `buttons` | Buttons A, B, and power (GPIO37, GPIO39, GPIO35) | — |

The Platform entry drives `GPIO4`, the battery power latch
(`hardware.power-hold`), high before anything else is built, so the Board
stays on without USB power once its power button is released.

GPIO34 to GPIO39 have no internal pull-up; the buttons use the Board's own
resistors.
