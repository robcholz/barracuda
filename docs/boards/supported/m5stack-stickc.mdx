The M5Stack StickC is an ESP32 Board from M5Stack.

- Board ID: `m5stack-stickc`
- Vendor: M5Stack
- Chip: ESP32
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32-none-elf`
- Profile: [`screen`](/boards/profiles)
- Flash layout: `boards/configs/m5stack-stickc/partitions.csv`

## Build and run

```bash terminal
cargo board select m5stack-stickc
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).

## Peripherals

| Device | What it is | Lua package |
| --- | --- | --- |
| `display` | Display (MIPI DBI) | [`display`](/plugins/vm-display) |
| `status-led` | Indicator LED | — |
| `real-time-clock` | Real-time clock (BM8563) | — |
| `power-monitor` | Battery gauge (AXP192) | [`power_monitor`](/plugins/vm-power-monitor) |
| `buttons` | Buttons A and B (GPIO37, GPIO39) | — |

The battery gauge shares the PMIC with the display: it reads only the PMIC's
measurement registers, and the display keeps its regulators.

The motion sensor is not declared: early units carry an SH200Q instead of the
MPU6886, and no implementation drives it yet.

## Exposed pins

Lua scripts open these pins by name.

| Name | Pin |
| --- | --- |
| `grove-g32` | `GPIO32` |
| `grove-g33` | `GPIO33` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("grove-g32", "up")
print(pin:read())
```
