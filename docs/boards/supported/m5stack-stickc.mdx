The M5Stack StickC is an ESP32 Board from M5Stack.

- Board ID: `m5stack-stickc`
- Vendor: M5Stack
- Chip: ESP32
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32-none-elf`
- Profile: [`headless`](/boards/profiles) (the default)
- Flash layout: `boards/configs/m5stack-stickc/partitions.csv`

## Build and run

```bash terminal
cargo board select m5stack-stickc
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).

## Peripherals

This Board declares no peripherals yet. The network, the Agent, and the
portal run on it; add its devices to
`boards/configs/m5stack-stickc/board.yml` to drive them. See
[Peripheral composition](/boards/peripherals).
