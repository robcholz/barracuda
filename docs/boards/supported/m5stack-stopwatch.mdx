The M5Stack StopWatch is an ESP32-S3 Board from M5Stack.

- Board ID: `m5stack-stopwatch`
- Vendor: M5Stack
- Chip: ESP32-S3
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32s3-none-elf`
- Profile: [`screen`](/boards/profiles)
- Flash layout: `boards/configs/m5stack-stopwatch/partitions.csv`

## Build and run

```bash terminal
cargo board select m5stack-stopwatch
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).

## Peripherals

| Device | What it is | Lua package |
| --- | --- | --- |
| `display` | Round display (CO5300, quad SPI) | [`display`](/plugins/vm-display) |
| `power-monitor` | Battery gauge (M5PM1) | [`power_monitor`](/plugins/vm-power-monitor) |
| `buttons` | Buttons A and B (GPIO2, GPIO1) | — |

The M5PM1 measures the battery voltage only; whether the battery charges comes
from the charger's status line on an M5PM1 pin.
