The M5Stack StopWatch is an ESP32-S3 Board from M5Stack.

- Board ID: `m5stack-stopwatch`
- Vendor: M5Stack
- Chip: ESP32-S3
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32s3-none-elf`
- Profile: [`screen`](/boards/profiles)
- Flash layout: `boards/configs/m5stack-stopwatch/partitions.csv`

## Build and run

```bash terminal
cargo board select m5stack-stopwatch
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).

## Peripherals

| Device | What it is | Lua package |
| --- | --- | --- |
| `display` | Round display (CO5300, quad SPI) | [`display`](/plugins/vm-display) |
| `inertial-measurement` | Motion sensor (BMI270) | [`motion`](/plugins/vm-imu) |
| `real-time-clock` | Real-time clock (RX8130CE) | — |
| `power-monitor` | Battery gauge (M5PM1) | [`power_monitor`](/plugins/vm-power-monitor) |
| `buttons` | Buttons A and B (GPIO2, GPIO1) | — |
| `power-button` | Power button (M5PM1 power key) | — |
| `audio-codec` | Audio codec (ES8311) | [`audio`](/plugins/vm-audio) |
| `vibration` | Vibration motor (M5IOE1 PWM, IO9) | [`vibration`](/plugins/vm-vibration) |

The M5PM1 measures the battery voltage only; whether the battery charges comes
from the charger's status line on an M5PM1 pin.

The power button is read from the M5PM1's button status and reads pressed while
the key is down. The M5PM1 keeps its factory behaviour: a single click resets
the Board and a double click turns it off, so a click does not reach the
application unless the Board sets `single-click-reset: disable` on the device.
`buttons` is the primary `buttons` device.

## Exposed pins

Lua scripts open these pins by name.

| Name | Pin |
| --- | --- |
| `port-a-scl` | `GPIO11` |
| `port-a-sda` | `GPIO10` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("port-a-scl", "up")
print(pin:read())
```
