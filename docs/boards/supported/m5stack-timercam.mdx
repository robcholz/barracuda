The M5Stack TimerCamera is an ESP32 Board from M5Stack.

- Board ID: `m5stack-timercam`
- Vendor: M5Stack
- Chip: ESP32
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32-none-elf`
- Profile: [`connected`](/boards/profiles)
- Flash layout: `boards/configs/m5stack-timercam/partitions.csv`

## Build and run

```bash terminal
cargo board select m5stack-timercam
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).

## Peripherals

| Device | What it is | Lua package |
| --- | --- | --- |
| `status-led` | Indicator LED | — |
| `real-time-clock` | Real-time clock (BM8563) | — |
| `battery` | Battery voltage (ADC resistor divider) | [`power_monitor`](/plugins/vm-power-monitor) |

The Platform entry drives `GPIO33`, the battery power latch (`hardware.power-hold`), high before anything else is built, so the Board stays on without USB power.

## Exposed pins

Lua scripts open these pins by name.

| Name | Pin |
| --- | --- |
| `grove-g4` | `GPIO4` |
| `grove-g13` | `GPIO13` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("grove-g4", "up")
print(pin:read())
```
