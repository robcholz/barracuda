The M5Stack Unit C6L is an ESP32-C6 Board from M5Stack.

- Board ID: `m5stack-unit-c6l`
- Vendor: M5Stack
- Chip: ESP32-C6
- Platform: [ESP32](/platforms/esp32)
- Rust target: `riscv32imac-unknown-none-elf`
- Profile: [`screen`](/boards/profiles)
- Flash layout: `boards/configs/m5stack-unit-c6l/partitions.csv`

## Build and run

```bash terminal
cargo board select m5stack-unit-c6l
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).

## Peripherals

| Device | What it is | Lua package |
| --- | --- | --- |
| `display` | OLED display (SSD1306) | [`display`](/plugins/vm-display) |
| `buttons` | Button (PI4IOE5V6408 P0) | — |
| `led-strip` | RGB LED (WS2812, GPIO2) | [`light`](/plugins/vm-led-strip) |
| `buzzer` | Passive buzzer (GPIO11) | [`buzzer`](/plugins/vm-buzzer) |
| `lora` | LoRa radio (SX1262, 850-930 MHz; CS GPIO23, BUSY GPIO19, DIO1 GPIO7) | [`lora`](/plugins/vm-lora) |

The SX1262 shares the OLED's SPI bus through its own chip select. Its reset,
RF switch, and LNA enable are P7, P6, and P5 of the PI4IOE5V6408 the button
also uses; each implementation configures only its own pins.

## Exposed pins

Lua scripts open these pins by name.

| Name | Pin |
| --- | --- |
| `grove-g4` | `GPIO4` |
| `grove-g5` | `GPIO5` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("grove-g4", "up")
print(pin:read())
```
