The M5Stack Unit C6L is an ESP32-C6 Board from M5Stack.

- Board ID: `m5stack-unit-c6l`
- Vendor: M5Stack
- Chip: ESP32-C6
- Platform: [ESP32](/platforms/esp32)
- Rust target: `riscv32imac-unknown-none-elf`
- Profile: [`screen`](/boards/profiles)
- Flash layout: `boards/configs/m5stack-unit-c6l/partitions.csv`

## Build and run

```bash terminal
cargo board select m5stack-unit-c6l
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).
