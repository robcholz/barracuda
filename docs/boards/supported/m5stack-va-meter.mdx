The M5Stack VAMeter is an ESP32-S3 Board from M5Stack.

- Board ID: `m5stack-va-meter`
- Vendor: M5Stack
- Chip: ESP32-S3
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32s3-none-elf`
- Profile: [`screen`](/boards/profiles)
- Flash layout: `boards/configs/m5stack-va-meter/partitions.csv`

## Build and run

```bash terminal
cargo board select m5stack-va-meter
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).

## Peripherals

| Device | What it is | Lua package |
| --- | --- | --- |
| `display` | Display (MIPI DBI) | [`display`](/plugins/vm-display) |
| `buttons` | Buttons A and B (GPIO2, GPIO0) | [`buttons`](/plugins/vm-buttons) |
| `buzzer` | Passive buzzer (GPIO14) | [`buzzer`](/plugins/vm-buzzer) |

## Exposed pins

Lua scripts open these pins by name.

| Name | Pin |
| --- | --- |
| `grove-g8` | `GPIO8` |
| `grove-g9` | `GPIO9` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("grove-g8", "up")
print(pin:read())
```
