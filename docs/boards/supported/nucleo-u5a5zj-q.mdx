The NUCLEO-U5A5ZJ-Q is an STM32U5A5ZJ Board from STMicroelectronics.

- Board ID: `nucleo-u5a5zj-q`
- Vendor: STMicroelectronics
- Chip: STM32U5A5ZJ
- Platform: [STM32](/platforms/stm32)
- Rust target: `thumbv8m.main-none-eabihf`
- Profile: [`headless`](/boards/profiles) (the default)
- Flash layout: `boards/configs/nucleo-u5a5zj-q/memory.x`

## Build and run

```bash terminal
cargo board select nucleo-u5a5zj-q
cargo run
cargo image deploy
```

Install the toolchain first; see [STM32](/platforms/stm32).

## Exposed pins

Lua scripts open these pins by name.

| Name | Pin |
| --- | --- |
| `user-button` | `PC13` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("user-button", "up")
print(pin:read())
```

## Plugin settings

- [`imessage-gateway`](/plugins/imessage-gateway) `receive-slots` is `0`: no
  connections are reserved for channel receive loops on this Board.
