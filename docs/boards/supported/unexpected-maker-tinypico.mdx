The TinyPICO is an ESP32 Board from Unexpected Maker.

- Board ID: `unexpected-maker-tinypico`
- Vendor: Unexpected Maker
- Chip: ESP32
- Platform: [ESP32](/platforms/esp32)
- Rust target: `xtensa-esp32-none-elf`
- Profile: [`connected`](/boards/profiles)
- Flash layout: `boards/configs/unexpected-maker-tinypico/partitions.csv`

## Build and run

```bash terminal
cargo board select unexpected-maker-tinypico
cargo run
cargo image deploy
```

Install the toolchain first; see [ESP32](/platforms/esp32).

## Peripherals

| Device | What it is | Lua package |
| --- | --- | --- |
| `led-strip` | LED strip (APA102) | [`light`](/plugins/vm-led-strip) |
| `battery` | Battery voltage (ADC resistor divider) and charge status | [`power_monitor`](/plugins/vm-power-monitor) |
