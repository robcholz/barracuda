Barracuda est un runtime embarqué fondé sur des Plugins et une plateforme
agentique. Chaque capacité d’un appareil est un Plugin, et un agent vous aide à
chaque étape : sur l’appareil, il écrit des scripts qui pilotent le matériel ;
sur votre ordinateur, il écrit des Plugins, des cartes et du firmware. Le même
System tourne sur les microcontrôleurs ESP32 et STM32, ainsi que sur Linux et
macOS.

## L’échelle

Chaque niveau est utile en soi, et chacun vous donne plus de liberté que le
précédent. La documentation suit les mêmes niveaux.

| Niveau | Ce que vous faites | Qui vous aide | Par où commencer |
| --- | --- | --- | --- |
| 01 · Utiliser votre appareil | Demander des choses à la carte | L’Agent embarqué écrit et exécute des scripts | [Portail de l’appareil](/fr/use/device-portal) |
| 02 · Configurer | Choisir les Plugins du firmware, compiler, flasher | Un profil, un fichier de carte ou votre agent de code | [Profils de carte](/fr/boards/profiles) |
| 03 · Applications | Créer des applications pour l’écran de l’appareil | L’Agent du navigateur | [Interface de l’appareil](/fr/architecture/device-ui) |
| 04 · Plugins | Ajouter une capacité au runtime | Votre agent de code avec `create-plugin` | [Écrire un Plugin](/fr/develop/write-a-plugin) |
| 05 · Cartes et plateformes | Démarrer une nouvelle carte ou famille de puces | Votre agent de code | [Cartes](/boards/overview) |
| 06 · Firmware sur mesure | Adapter un firmware à une puce et à un budget | Votre agent de code | [Firmware sur mesure](/fr/develop/custom-firmware) |

Lisez [L’échelle](/fr/product/experience-ladder) pour savoir à quoi sert chaque niveau.

## Qu’est-ce que Barracuda ?

Barracuda place l’IA à trois endroits, chacun choisi pour le travail qu’il fait
le mieux.

| | Où il s’exécute | Ce qu’il fait |
| --- | --- | --- |
| Agent embarqué | Sur l’appareil, en tant que Plugin [Agent](/plugins/agent) | Écrit des scripts Lua et les exécute sur le matériel, immédiatement |
| Agent du navigateur | Dans le navigateur | Génère des applications et leur interface |
| Agents de code | Votre ordinateur : Claude Code, Cursor, Codex | Crée des Plugins, des cartes, des plateformes et du firmware sur mesure |

En dessous se trouvent quatre couches. Comprenez-les et vous saurez lire le dépôt.

| Couche | Possède | Répertoire |
| --- | --- | --- |
| Carte | La puce, la cible de la chaîne d’outils, le plan de la flash, les périphériques et le profil de Plugins | `boards/` |
| Plateforme | Le point d’entrée de l’exécuteur, la pile réseau, le système de fichiers, la flash et les adaptateurs HAL | `platforms/` |
| System | Enregistre chaque Plugin dans l’ordre des dépendances, puis les démarre | `core/system/` |
| Plugins | Capacités, actions et événements de Workflow, outils de l’Agent, pages du portail, tâches | `plugins/` |

<Tip>
  Pas de carte ? Sélectionnez `local-linux` ou `local-macos`. Le même System
  tourne sur votre ordinateur, avec des périphériques virtuels. Consultez le
  [Démarrage rapide](/fr/get-started/quickstart).
</Tip>
