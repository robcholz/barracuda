Les puces STM32 exécutent Barracuda sur la plateforme bare-metal `stm32`. Elle
se compile avec Rust standard et se flashe via une sonde de débogage avec
`probe-rs` ; le plan de la flash est le `memory.x` de l’éditeur de liens dans le
paquet de chaque carte.

| Puce (plateforme) | Cible Rust | Chaîne d’outils | Outil de flashage |
| --- | --- | --- | --- |
| STM32U5A5ZJ (`stm32`) | `thumbv8m.main-none-eabihf` | Rust 1.98.1 | `probe-rs` |

## Installer la chaîne d’outils

```bash terminal
rustup toolchain install 1.98.1 --target thumbv8m.main-none-eabihf
cargo install probe-rs-tools
```

## Compiler, flasher et exécuter

Branchez la sonde de débogage de la carte en USB, puis :

```bash terminal
cargo board select nucleo-u5a5zj-q
cargo run
cargo image deploy
```

- `cargo run` compile le firmware et l’exécute avec `probe-rs run`.
- `cargo image deploy` compile l’image de ressources des Plugins et l’écrit avec
  `probe-rs download`.

## Matériel piloté par la plateforme

La plateforme `stm32` fournit des entrées et sorties numériques, le GPIO, des
périphériques I2C et des bus SPI. Les E/S à l’exécution permettent aux scripts
Lua de réserver ces contrôleurs sur les broches exposées d’une carte :

| I2C | SPI | UART | ADC |
| --- | --- | --- | --- |
| `I2C1` | `SPI1` | `USART1` | `ADC1` |
