`pocketjs-core/` et `microts/` sont copiés depuis
[PocketJS](https://github.com/pocket-nexus/pocketjs) au commit
`e9e417308f094ead706754164acf91436e4d05a8` :

| Répertoire | Chemin en amont |
| --- | --- |
| `pocketjs-core/src` | `engine/core/src` |
| `microts/src` | `engine/crates/microts/src` |

Les deux sont sous licence MIT (`LICENSE` dans chaque répertoire). Les sources
de la bibliothèque ne sont pas modifiées, sauf que trois modules de test sont
supprimés parce qu’ils lisent des fixtures du dépôt PocketJS : les fichiers
séparés `core/src/tests.rs` et `core/src/physics/tests.rs` avec leurs
déclarations `mod tests;`, et le `mod tests` en ligne à la fin de
`core/src/package.rs`. Les sources sont aussi reformatées avec le `rustfmt` de
cet espace de travail. Les manifestes sont réécrits pour être autonomes dans cet
espace de travail et faire taire les lints de style de Clippy.

Pour mettre à jour, copiez les mêmes chemins depuis un commit plus récent et
appliquez de nouveau les trois suppressions. Gardez le code propre à Barracuda
hors de ces répertoires ; il a sa place dans `barracuda-ui-runtime`.
