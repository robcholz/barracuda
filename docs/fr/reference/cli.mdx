Barracuda ajoute ses commandes sous forme d’alias Cargo : elles s’exécutent
depuis n’importe quel endroit du dépôt, sans installation supplémentaire.

## cargo board

| Commande | Ce qu’elle fait |
| --- | --- |
| `cargo board select [NAME]` | Sélectionne une carte, de façon interactive si aucun nom n’est donné. Les `cargo build` et `cargo run` ultérieurs l’utilisent |
| `cargo board target [NAME]` | Affiche le triplet de cible Rust d’une carte ; par défaut, la carte sélectionnée |
| `cargo board sync [--check]` | Valide les cartes et synchronise les implémentations de périphériques dans le registre |

## cargo plugin

| Commande | Ce qu’elle fait |
| --- | --- |
| `cargo plugin info <ID>` | Affiche le manifeste et les dépendances d’un Plugin |
| `cargo plugin select` | Désactive des Plugins activés sur cette machine uniquement, dans `.barracuda/disabled-plugins` |
| `cargo plugin run <TASK> [--plugin <ID>]` | Exécute une tâche déclarée dans `plugin.toml`, comme `build`, pour les Plugins activés |
| `cargo plugin sync [--check]` | Synchronise les Plugins découverts dans le registre du System |

Les Plugins que contient un firmware sont définis par le profil de la carte ;
consultez [Profils de carte](/fr/boards/profiles).

## cargo image

| Commande | Ce qu’elle fait |
| --- | --- |
| `cargo image build` | Compile l’image de ressources des Plugins de la carte sélectionnée |
| `cargo image flash` | Flashe l’image compilée dans la partition `resources` de la carte |
| `cargo image deploy` | Compile et flashe |

Consultez [Image système](/tools/system-image).

## cargo platform

| Commande | Ce qu’elle fait |
| --- | --- |
| `cargo platform sync [--check]` | Synchronise les plateformes découvertes dans le registre |

## cargo cli

Le canal terminal. Il est toujours compilé pour votre ordinateur, quelle que
soit la carte sélectionnée.

| Commande | Ce qu’elle fait |
| --- | --- |
| `cargo cli` | Discute avec un appareil en fonctionnement ; choisissez Local ou Remote |
| `cargo cli configure [ADDRESS]` | Règle les modèles, la recherche web et les canaux depuis le terminal |
| `cargo cli chat ADDRESS < messages.txt` | Envoie des messages depuis un fichier |

## Environnement

| Variable | Utilisée par | Signification |
| --- | --- | --- |
| `BARRACUDA_VIRTUAL_IO_ADDR` | `local-linux`, `local-macos` | Adresse de bouclage des périphériques virtuels, comme `127.0.0.1:7878` |
| `BARRACUDA_LOG_LEVEL` | `cargo build`, `cargo run` | Niveau de journalisation intégré à la compilation : `off`, `error`, `warn`, `info`, `debug` ou `trace` |
