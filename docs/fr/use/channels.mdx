title: "Canaux"

---

Chaque canal joint le même Agent, avec les mêmes sessions. Chaque canal est un
Plugin : un firmware n’embarque donc que les canaux dont il a besoin.

| Canal | Plugin | Comment se connecter |
| --- | --- | --- |
| Chat web | [`imessage-web`](/plugins/imessage-web) | Ouvrez **Web chat** dans le [portail de l’appareil](/fr/use/device-portal) |
| Terminal | `cargo cli` | Lancez `cargo cli` et choisissez Local ou Remote |
| WeChat | [`imessage-wechat`](/plugins/imessage-wechat) | Scannez le QR code sur sa page du portail |
| QQ | [`imessage-qq`](/plugins/imessage-qq) | Scannez le QR code sur sa page du portail |
| Telegram | [`imessage-telegram`](/plugins/imessage-telegram) | Saisissez le jeton de votre bot sur sa page du portail |
| iMessage | [`imessage-bluebubble`](/plugins/imessage-bluebubble) | Connectez votre serveur BlueBubbles sur sa page du portail |
| Inkbox | [`imessage-inkbox`](/plugins/imessage-inkbox) | Saisissez une clé d’API Inkbox, ou créez un compte, sur sa page du portail |

Avant qu’un canal puisse répondre, enregistrez un modèle sur la page **Models**.

## Propriétaires

Un canal de messagerie ne répond qu’à ses propriétaires. Pour en devenir un,
envoyez au canal le code d’appairage à six chiffres affiché sur sa page du
portail. Un code est valable dix minutes ; **New code** le remplace.

## Sessions

Chaque canal gère les sessions avec les mêmes commandes texte :

| Commande | Ce qu’elle fait |
| --- | --- |
| `/sessions` | Liste les sessions enregistrées, de la plus récente à la plus ancienne |
| `/new` | Démarre une nouvelle session |
| `/new temp` | Démarre une session temporaire qui n’est pas enregistrée |
| `/switch N` | Bascule vers la session `N` |
| `/rename N title` | Renomme la session `N` |
| `/delete N` | Demande à supprimer la session `N` ; `/delete N confirm` la supprime |

Le chat web affiche les mêmes sessions sous forme de liste.
