title: "Portail de l’appareil"
description: "Configurez le Wi-Fi, les modèles, les canaux, les fichiers et les applications depuis n’importe quel navigateur du réseau de l’appareil."
---

Le portail de l’appareil est l’application web propre à l’appareil, servie par
celui-ci à `/portal/`. Chaque Plugin activé qui possède des réglages y ajoute sa
page : le portail correspond donc toujours au firmware.

## Ouvrir le portail

| Où se trouve l’appareil | Adresse |
| --- | --- |
| Une carte qui n’a pas encore de Wi-Fi | Rejoignez le réseau ouvert `Barracuda Setup`, puis ouvrez `http://192.168.4.1/portal/` |
| Une carte sur votre réseau | `http://DEVICE_ADDRESS:8787/portal/` |
| `local-linux` | `http://10.42.0.2:8787/portal/` |

Le portail suit la langue de votre navigateur, chinois ou anglais.

## Pages

| Page | Plugin d’origine | Ce que vous réglez |
| --- | --- | --- |
| Wi-Fi | [`wifi`](/plugins/wifi) | Rechercher et rejoindre un réseau ; le point d’accès de configuration |
| Models | [`agent`](/plugins/agent) | Le service de modèles, le modèle et la clé d’API pour chaque usage de l’Agent |
| Web search | [`agent-websearch`](/plugins/agent-websearch) | Le service de recherche utilisé par l’Agent |
| Web chat | [`imessage-web`](/plugins/imessage-web) | Parler à l’Agent dans le navigateur |
| WeChat, QQ, Telegram, BlueBubbles, Inkbox | [Canaux](/fr/use/channels) | Lier le compte, les propriétaires et les codes d’appairage |
| Files | [`files`](/plugins/files) | Parcourir le Workspace et les fichiers des Plugins |
| Apps | [`app-portal`](/plugins/app-portal) | Examiner et installer des applications |

Une page n’apparaît que si son Plugin est dans le firmware. Consultez
[Profils de carte](/fr/boards/profiles).

<Warning>
  Les API HTTP du portail n’ont ni authentification ni chiffrement du
  transport, et le point d’accès de configuration est ouvert. Ne configurez
  l’appareil que sur un réseau de confiance.
</Warning>

Depuis un terminal, `cargo cli configure` renseigne les mêmes réglages de
modèles, de recherche web et de canaux sans navigateur. Consultez
[Compiler et exécuter](/fr/get-started/build-and-run).
