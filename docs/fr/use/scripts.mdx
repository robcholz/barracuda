Quand une demande touche le monde physique, l’Agent embarqué écrit un court
script Lua et l’exécute dans la VM de l’appareil avec son outil `vm_run`. Le
script lit et pilote les vrais périphériques dès son exécution, et sa sortie
revient dans la conversation.

```txt
> Mets la broche vio-0 à l’état haut
```

```lua
local gpio = require("gpio")
local pin = gpio.open_output("vio-0", true, "push-pull")
print("vio-0 is high")
```

## Ce que les scripts peuvent utiliser

Chaque paquet Lua provient de son propre Plugin : un script peut donc utiliser
exactement ce que le firmware embarque.

| Paquet | Plugin | Usage |
| --- | --- | --- |
| `gpio` | [`vm-gpio`](/plugins/vm-gpio) | Entrées et sorties numériques sur les broches exposées de la carte |
| `i2c`, `spi`, `uart` | [`vm-i2c`](/plugins/vm-i2c), [`vm-spi`](/plugins/vm-spi), [`vm-uart`](/plugins/vm-uart) | Bus |
| `pwm`, `analog`, `i2s` | [`vm-pwm`](/plugins/vm-pwm), [`vm-analog`](/plugins/vm-analog), [`vm-i2s`](/plugins/vm-i2s) | Sorties PWM, entrées analogiques et flux audio I2S |
| `display`, `camera`, `audio` | [`vm-display`](/plugins/vm-display), [`vm-camera`](/plugins/vm-camera), [`vm-audio`](/plugins/vm-audio) | Écrans, caméras et son |
| `motion`, `light`, `power_monitor` | [`vm-imu`](/plugins/vm-imu), [`vm-led-strip`](/plugins/vm-led-strip), [`vm-power-monitor`](/plugins/vm-power-monitor) | Détection de mouvement, bandes de LED et alimentation |
| `http`, `filesystem`, `message_queue` | [`vm-http`](/plugins/vm-http), [`vm-filesystem`](/plugins/vm-filesystem), [`vm-message-queue`](/plugins/vm-message-queue) | Requêtes, fichiers et files de messages |
| `agent` | [`vm-agent`](/plugins/vm-agent) | Poser une question à l’Agent depuis un script |
| `time` | [`vm-time`](/plugins/vm-time) | Heure UTC via `os.time` et `os.date` |

La page de chaque paquet détaille son API Lua. La page [VM](/plugins/vm) décrit
le runtime lui-même.

## Scripts de longue durée

`vm_run` s’exécute dans le pool d’arrière-plan de l’Agent : la conversation
continue pendant qu’un script tourne.

- Un script qui appelle `io.read()` se met en pause et vous demande une
  saisie ; votre réponse lui est transmise.
- L’Agent liste, alimente et annule les scripts en cours avec ses outils
  `background_list`, `background_input` et `background_cancel`. Demandez-lui
  d’arrêter un script et il annule l’exécution.

Pour un comportement qui doit survivre à la conversation, comme « tous les
matins à sept heures », l’Agent utilise les
[automatisations](/fr/use/automations).
