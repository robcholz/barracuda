title: "Installation"
description: "Flash Barracuda onto your Board from the browser, or install the toolchain to build it yourself."
---

ESP32 Boards install from the browser in a few minutes, with nothing to set
up. To build your own firmware, or to run an STM32 or a host Board, install the
toolchain instead.

## Install from the browser

Open the [installer](https://barracuda-os.vercel.app/install/) in desktop
Chrome or Edge, with your Board and a USB data cable at hand.

<Steps>
  <Step title="Choose your Board">
    Pick it from the list, or click **Detect chip over USB** to show only the
    Boards with your chip. For an STM32 or a host Board, the installer shows
    the commands from [Build it yourself](#build-it-yourself) instead.
  </Step>
  <Step title="Download the firmware">
    Choose a version and click **Download firmware**. Drop the downloaded
    `barracuda-<version>-<board>.tar.gz` back on the page without unpacking
    it. The installer checks that the file is that Board's and that version's,
    and that it is intact.
  </Step>
  <Step title="Connect the device">
    Click **Connect device** and choose the Board's serial port. The installer
    checks the chip and its flash size, and whether Barracuda is already on the
    Board.
  </Step>
  <Step title="Write the firmware">
    Keep the cable connected until the device restarts.
  </Step>
  <Step title="Connect Wi-Fi">
    Scan the QR code with your phone to join the Board's hotspot,
    `Barracuda-XXXX`, then choose your home network on the page that opens.
  </Step>
  <Step title="Open the Device Portal">
    The installer shows the [Device Portal](/use/device-portal)'s address on
    your network. Open it to set up a model.
  </Step>
</Steps>

When the Board already holds Barracuda with the same partitions, **Update**
keeps its Wi-Fi, model and channel settings, and **Fresh install** erases the
whole flash first. A Board with other firmware always gets a fresh install.

<Note>
  Other browsers and phones cannot reach a USB serial port, so open the
  installer in desktop Chrome or Edge. If the Board does not connect, hold its
  BOOT button while you plug it in.
</Note>

## Build it yourself

Barracuda builds with Cargo. Plugins are compiled into the firmware, so you
build on your own computer with the Rust toolchain of the Platform you target.

### Clone the repository

```bash terminal
git clone https://github.com/robcholz/barracuda
cd barracuda
```

### Install a toolchain

Install [rustup](https://rustup.rs) first. The repository pins Rust 1.98.1 in
`rust-toolchain.toml`, which is all a host Board needs.

<Tabs>
  <Tab title="Linux and macOS">
    Nothing else to install. Select `local-linux` or `local-macos` and run
    Barracuda on your computer, with virtual peripherals standing in for
    hardware.

    ```bash terminal
    rustup show
    ```
  </Tab>
  <Tab title="ESP32">
    ESP32 and ESP32-S3 Boards build with the Espressif Rust toolchain and
    flash with `espflash`:

    ```bash terminal
    cargo install espup espflash
    espup install --toolchain-version 1.98.1.0
    ```

    ESP32-C3, ESP32-C6, and ESP32-P4 need different commands; see
    [ESP32 Platforms](/platforms/esp32).
  </Tab>
  <Tab title="STM32">
    STM32 Boards build with Rust 1.98.1 and the Arm target, and flash through
    a debug probe with `probe-rs`:

    ```bash terminal
    rustup toolchain install 1.98.1 --target thumbv8m.main-none-eabihf
    cargo install probe-rs-tools
    ```
  </Tab>
</Tabs>

You do not have to know which toolchain a Board needs ahead of time. When you
select a Board whose toolchain is missing, `cargo board select` prints the exact
command to install it.

### Select a Board

```bash terminal
cargo board select
```

The list is searchable: type part of a name, such as `cores3`, and press Enter.
Your selection is stored in the working tree, so every later `cargo build` and
`cargo run` uses it. To select without the prompt, name the Board:

```bash terminal
cargo board select local-linux
```

Board names are the directory names under `boards/configs/`.
