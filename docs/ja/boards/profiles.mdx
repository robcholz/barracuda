プロファイルは、ファームウェアに含めるプラグインを指定します。各ボードは 1 つのプロファイルでビルドされます。`board.yml` で指定したプロファイル、指定がなければ `headless` です。どのプロファイルからもボードからも有効にされていないプラグインは、ファームウェアにまったく含まれません。コードも設定もテキストも入りません。

ルール（有効なプラグインの組み合わせの計算方法、失敗する条件、ローカルでの上書き）は [`plugin-api.md`](/architecture/plugin-api#enablement-per-board) にあります。このページでは、どのプロファイルがあるか、どう選び、どう追加するかを説明します。

## プロファイル一覧

プロファイルはレイヤー構造になっています。各プロファイルは拡張元のプロファイルにプラグインを追加し、列挙したプラグインの依存関係は自動的に含まれます。

| プロファイル | 拡張元 | 追加するもの | ネットワーク | Lua |
| --- | --- | --- | --- | --- |
| `minimal` | — | Workflow、時刻、スケジューラー、電源、サウンド | なし | なし |
| `lua` | `minimal` | VM と、ネットワークを必要としない Lua パッケージ（ボードのハードウェア向けのものを含む） | なし | あり |
| `network` | `minimal` | Wi-Fi、Web サーバー、キャプティブポータル、HTTP、ポータルのファイルマネージャー | あり | なし |
| `ai` | `network` | Agent、そのツール、メッセージゲートウェイ | あり | なし |
| `headless` | `lua`、`ai` | ネットワークまたは Agent を必要とする Lua パッケージ | あり | あり |
| `ui` | — | システム UI を持つアプリマネージャー、システムフォント、Files アプリと Workflows アプリ | なし | あり |
| `screen-offline` | `lua`、`ui` | 追加なし | なし | あり |
| `screen` | `headless`、`ui` | システム UI での Wi-Fi、ポータルからのアプリのインストール、Sessions アプリと Settings アプリ | あり | あり |

```text
                 minimal
                /       \
             lua         network
              |  \          |
              |   \         ai
              |    \       /
              |    headless          (the default)
              |        \
              |       screen = headless + ui + …
              |
       screen-offline = lua + ui
```

`ui` はレイヤーであって製品向けのプロファイルではありません。ハードウェア向けの Lua パッケージもオンラインに出る手段も持ちません。画面のあるボードは `screen` または `screen-offline` を指定します。

`screen-offline` には Settings アプリも Sessions アプリもありません。Settings は Wi-Fi に、Sessions は Agent に依存するためです。音量と明るさはコントロールセンターで調整できます。

## プロファイルを選ぶ

ボードは `board.yml` でプロファイルを指定します。

```yaml
profile: screen-offline
plugins:
  camera:
    enabled: false
```

- 画面のある製品は `screen` を指定します。オンラインに出ることがなければ `screen-offline` を指定します。
- 画面のない製品は何も指定せずに `headless` でビルドするか、より狭いレイヤー（`minimal`、`lua`、`network`、`ai`）を指定します。
- プラグインを 1 つだけ増減する場合は、新しいプロファイルを作らず、ボードの `plugins.<id>.enabled` で指定します。

## プロファイルを追加する

新しいプロファイルは、このディレクトリに置くファイル 1 つです。製品の用途に合わせて名前を付け、土台とするレイヤーを拡張し、追加するものだけを列挙します。

```yaml
# boards/profiles/gateway.yml
extends: network
enable:
  - agent
  - imessage-gateway
  - imessage-telegram
```

`extends` には 1 つのプロファイルかリストを指定します。2 回たどり着いたプロファイルは 1 回として数え、自分自身を拡張するプロファイルはエラーになります。`enable` は追加しかできません。より小さな製品を作るときは、プラグインを取り除くのではなく、より狭いレイヤーを拡張します。

プロファイルやボードを変更したら `cargo plugin sync` を実行し、コミット前に `cargo plugin sync --check` を実行してください。
