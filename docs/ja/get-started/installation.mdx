---
title: "インストール"
description: "ボードに合ったツールチェーンをインストールし、Barracuda をクローンします。"
---

Barracuda は Cargo でビルドします。プラグインはファームウェアに組み込まれてコンパイルされるため、対象とするプラットフォームの Rust ツールチェーンを使って自分のコンピューターでビルドします。

## リポジトリをクローンする

```bash terminal
git clone https://github.com/robcholz/barracuda
cd barracuda
```

## ツールチェーンをインストールする

まず [rustup](https://rustup.rs) をインストールします。リポジトリは `rust-toolchain.toml` で Rust 1.98.1 を固定しており、ホスト向けのボードにはこれだけで十分です。

<Tabs>
  <Tab title="Linux と macOS">
    追加でインストールするものはありません。`local-linux` または `local-macos` を選ぶと、ハードウェアの代わりに仮想ペリフェラルを使って、コンピューター上で Barracuda を動かせます。

    ```bash terminal
    rustup show
    ```
  </Tab>
  <Tab title="ESP32">
    ESP32 と ESP32-S3 のボードは Espressif の Rust ツールチェーンでビルドし、`espflash` で書き込みます。

    ```bash terminal
    cargo install espup espflash
    espup install --toolchain-version 1.98.1.0
    ```

    ESP32-C3、ESP32-C6、ESP32-P4 では別のコマンドが必要です。[ESP32 プラットフォーム](/ja/platforms/esp32) を参照してください。
  </Tab>
  <Tab title="STM32">
    STM32 のボードは Rust 1.98.1 と Arm ターゲットでビルドし、`probe-rs` を使ってデバッグプローブ経由で書き込みます。

    ```bash terminal
    rustup toolchain install 1.98.1 --target thumbv8m.main-none-eabihf
    cargo install probe-rs-tools
    ```
  </Tab>
</Tabs>

ボードに必要なツールチェーンを事前に把握しておく必要はありません。ツールチェーンが入っていないボードを選ぶと、`cargo board select` がインストールに必要なコマンドをそのまま表示します。

## ボードを選ぶ

```bash terminal
cargo board select
```

一覧は検索できます。`cores3` のように名前の一部を入力して Enter を押してください。選択内容は作業ツリーに保存され、以降の `cargo build` と `cargo run` はすべてそのボードを使います。プロンプトを使わずに選ぶには、ボード名を指定します。

```bash terminal
cargo board select local-linux
```

ボード名は `boards/configs/` 配下のディレクトリ名です。
