---
title: "クイックスタート"
description: "コンピューター上で Barracuda を動かし、モデルを接続して、Agent にピンを操作させます。"
---

デバイスと同じ System を、ハードウェアの代わりに仮想ペリフェラルを使って Linux または macOS 上で動かします。そのうえでモデルを接続し、オンボード Agent と会話します。

<Info>
  前提条件: Rust がインストールされ、リポジトリをクローンしてあること。[インストール](/ja/get-started/installation) を参照してください。OpenAI 互換または Anthropic 互換のモデルサービスの API キーも必要です。
</Info>

<Steps>
  <Step title="ホスト向けのボードを選ぶ">
    ```bash terminal
    cargo board select local-linux   # or local-macos
    ```

    ホスト向けのボードは `screen` プロファイルでビルドされます。Agent、Lua スクリプト、Web チャット、ポータル、仮想の円形ディスプレイが含まれます。
  </Step>
  <Step title="ネットワークを準備する（Linux のみ）">
    Linux プラットフォームは実際の TUN インターフェースを使います。起動ごとに一度だけ用意します。

    ```bash terminal
    sudo sh platforms/linux/provision.sh barracuda0
    ```

    macOS では準備も `sudo` も不要です。
  </Step>
  <Step title="Barracuda を実行する">
    ```bash terminal
    BARRACUDA_VIRTUAL_IO_ADDR=127.0.0.1:7878 cargo run
    ```

    このターミナルが System とそのログを受け持ちます。`BARRACUDA_VIRTUAL_IO_ADDR` は仮想ペリフェラルが待ち受けるアドレスです。[http://127.0.0.1:7878/](http://127.0.0.1:7878/) を開くとディスプレイを確認できます。
  </Step>
  <Step title="モデルを接続する">
    2 つ目のターミナルで設定ツールを起動し、**Local** を選んでから、モデルの設定（`agent`）を選びます。

    ```bash terminal
    cargo cli configure
    ```

    プロンプトに従って、API 形式（`openai_compatible` または `anthropic_compatible`）、用途 `root_agent`、ベース URL、モデル、API キーを入力します。キーはデバイスに保存されます。同じことは [デバイスポータル](/ja/use/device-portal) の **Models** ページでも行えます。
  </Step>
  <Step title="Agent と会話する">
    ターミナルのチャネルを開き、**Local** を選びます。

    ```bash terminal
    cargo cli
    ```

    物理的な操作を頼んでみます。

    ```txt
    > ピン vio-0 を High にして
    ```

    Agent は短い Lua スクリプトを書き、`vm_run` ツールで実行して、その結果を返します。ホスト向けのボードは仮想ピン `vio-0` から `vio-7` を公開しています。
  </Step>
</Steps>
