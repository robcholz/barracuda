Barracuda は、プラグインベースの組み込みランタイムであり、エージェント型のプラットフォームです。デバイス上のあらゆる機能はプラグインで、あらゆる段階で Agent が手助けします。デバイス上ではハードウェアを動かすスクリプトを書き、あなたのコンピューター上ではプラグイン、ボード、ファームウェアを書きます。同じ System が、ESP32 と STM32 のマイコンでも、Linux と macOS でも動きます。

## 体験のはしご

各段階はそれ自体で役に立ち、上の段階に進むほど自由度が増します。ドキュメントも同じ段階に沿って構成されています。

| 段階 | やること | 手助けするもの | 出発点 |
| --- | --- | --- | --- |
| 01 · デバイスを使う | ボードに作業を頼む | オンボード Agent がスクリプトを書いて実行します | [デバイスポータル](/ja/use/device-portal) |
| 02 · 構成 | ファームウェアに入れるプラグインを選び、ビルドして書き込む | プロファイル、ボードのファイル、またはコーディング Agent | [ボードプロファイル](/ja/boards/profiles) |
| 03 · アプリ | デバイスの画面向けのアプリを作る | ブラウザ内の Agent | [デバイス UI](/ja/architecture/device-ui) |
| 04 · プラグイン | ランタイムに機能を追加する | `create-plugin` を使うコーディング Agent | [プラグインを書く](/ja/develop/write-a-plugin) |
| 05 · ボードとプラットフォーム | 新しいボードやチップファミリーを立ち上げる | コーディング Agent | [ボード](/boards/overview) |
| 06 · カスタムファームウェア | ファームウェアをチップと予算に合わせる | コーディング Agent | [カスタムファームウェア](/ja/develop/custom-firmware) |

各段階の目的については [体験のはしご](/ja/product/experience-ladder) を参照してください。

## Barracuda とは

Barracuda は AI を 3 つの場所に置き、それぞれが最も得意な仕事を担います。

| | 動く場所 | 役割 |
| --- | --- | --- |
| オンボード Agent | デバイス上で [Agent](/plugins/agent) プラグインとして | Lua スクリプトを書き、その場でハードウェアに対して実行します |
| ブラウザ内の Agent | ブラウザ内 | アプリとその UI を生成します |
| コーディング Agent | あなたのコンピューター上: Claude Code、Cursor、Codex | プラグイン、ボード、プラットフォーム、カスタムファームウェアを作成します |

その下には 4 つのレイヤーがあります。これを押さえればリポジトリを読み解けます。

| レイヤー | 受け持つもの | ディレクトリ |
| --- | --- | --- |
| ボード | チップ、ツールチェーンのターゲット、フラッシュのレイアウト、ペリフェラル、プラグインのプロファイル | `boards/` |
| プラットフォーム | エグゼキューターのエントリー、ネットワークスタック、ファイルシステム、フラッシュ、HAL アダプター | `platforms/` |
| System | すべてのプラグインを依存関係の順に登録し、起動します | `core/system/` |
| プラグイン | ケイパビリティ、Workflow の Action と Event、Agent Tool、ポータルのページ、タスク | `plugins/` |

<Tip>
  ボードがなくても大丈夫です。`local-linux` または `local-macos` を選べば、同じ System が仮想ペリフェラルとともにコンピューター上で動きます。[クイックスタート](/ja/get-started/quickstart) を参照してください。
</Tip>
