Barracuda is a plugin-based embedded runtime and an agentic platform. Every
capability on a device is a Plugin, and an agent helps at every step: on the
device it writes scripts that drive the hardware, and on your computer it
writes Plugins, Boards, and firmware. The same System runs on ESP32 and STM32
microcontrollers and on Linux and macOS.

## The ladder

Each level is useful on its own, and each one gives you more freedom than the
one below it. The docs follow the same levels.

| Level | What you do | Who helps | Start here |
| --- | --- | --- | --- |
| 01 · Use your device | Ask the board to do things | The on-board Agent writes and runs scripts | [Device Portal](/use/device-portal) |
| 02 · Configure | Choose the Plugins in the firmware, build, flash | A profile, a Board file, or your coding agent | [Board profiles](/boards/profiles) |
| 03 · Apps | Build apps for the device's screen | The in-browser agent | [Device UI](/architecture/device-ui) |
| 04 · Plugins | Add a capability to the runtime | Your coding agent with `create-plugin` | [Write a Plugin](/develop/write-a-plugin) |
| 05 · Boards and Platforms | Bring up a new board or chip family | Your coding agent | [Boards](/boards/overview) |
| 06 · Custom firmware | Fit a firmware to a chip and a budget | Your coding agent | [Custom firmware](/develop/custom-firmware) |

Read [The ladder](/product/experience-ladder) for what each level is for.

## What is Barracuda?

Barracuda puts AI in three places, each chosen for the work it does best.

| | Where it runs | What it does |
| --- | --- | --- |
| On-board Agent | On the device, as the [Agent](/plugins/agent) Plugin | Writes Lua scripts and runs them against the hardware, now |
| In-browser agent | In the browser | Generates apps and their UI |
| Coding agents | Your computer: Claude Code, Cursor, Codex | Creates Plugins, Boards, Platforms, and custom firmware |

Underneath are four layers. Read these and you can read the repository.

| Layer | Owns | Directory |
| --- | --- | --- |
| Board | The chip, toolchain target, flash layout, peripherals, and Plugin profile | `boards/` |
| Platform | Executor entry, network stack, filesystem, flash, and HAL adapters | `platforms/` |
| System | Registers every Plugin in dependency order, then starts them | `core/system/` |
| Plugins | Capabilities, Workflow Actions and Events, Agent Tools, portal pages, tasks | `plugins/` |

<Tip>
  No board? Select `local-linux` or `local-macos`. The same System runs on your
  computer, with virtual peripherals. See the [Quickstart](/get-started/quickstart).
</Tip>
