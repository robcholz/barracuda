STM32 チップでは、ベアメタルの `stm32` プラットフォーム上で Barracuda が動きます。標準の Rust でビルドし、`probe-rs` を使ってデバッグプローブ経由で書き込みます。フラッシュのレイアウトは、各ボードのバンドルにあるリンカーの `memory.x` で決まります。

| チップ（プラットフォーム） | Rust ターゲット | ツールチェーン | 書き込みツール |
| --- | --- | --- | --- |
| STM32U5A5ZJ (`stm32`) | `thumbv8m.main-none-eabihf` | Rust 1.98.1 | `probe-rs` |

## ツールチェーンをインストールする

```bash terminal
rustup toolchain install 1.98.1 --target thumbv8m.main-none-eabihf
cargo install probe-rs-tools
```

## ビルド、書き込み、実行

ボードのデバッグプローブを USB で接続してから、次を実行します。

```bash terminal
cargo board select nucleo-u5a5zj-q
cargo run
cargo image deploy
```

- `cargo run` はファームウェアをビルドし、`probe-rs run` で実行します。
- `cargo image deploy` はプラグインのリソースイメージをビルドし、`probe-rs download` で書き込みます。

## プラットフォームが制御するハードウェア

`stm32` プラットフォームは、デジタル入出力、GPIO、I2C デバイス、SPI バスを提供します。ランタイム I/O を使うと、Lua スクリプトがボードの公開ピン上でこれらのコントローラーを確保できます。

| I2C | SPI | UART | ADC |
| --- | --- | --- | --- |
| `I2C1` | `SPI1` | `USART1` | `ADC1` |
