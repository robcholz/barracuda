`pocketjs-core/` と `microts/` は、[PocketJS](https://github.com/pocket-nexus/pocketjs) のコミット `e9e417308f094ead706754164acf91436e4d05a8` からコピーしたものです。

| ディレクトリ | 上流のパス |
| --- | --- |
| `pocketjs-core/src` | `engine/core/src` |
| `microts/src` | `engine/crates/microts/src` |

どちらも MIT ライセンスです（各ディレクトリの `LICENSE` を参照）。ライブラリのソースは変更していませんが、PocketJS リポジトリのフィクスチャを読み込む 3 つのテストモジュールだけは削除しています。対象は、別ファイルの `core/src/tests.rs` と `core/src/physics/tests.rs`（およびそれぞれの `mod tests;` 宣言）、そして `core/src/package.rs` 末尾のインラインの `mod tests` です。また、ソースはこのワークスペースの `rustfmt` で整形し直しています。マニフェストは、このワークスペース内で単独で成り立ち、Clippy のスタイル lint を抑止するように書き換えています。

更新するときは、新しいコミットから同じパスをコピーし、3 つの削除をもう一度適用してください。Barracuda 固有のコードはこれらのディレクトリに置かず、`barracuda-ui-runtime` に置いてください。
