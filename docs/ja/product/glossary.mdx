---
title: "用語集"
description: "Agent や App から Board、Plugin まで、Barracuda 全体で使う用語の定義です。"
---

**Agent (on-board agent)（オンボード Agent）。** デバイス上で動く Agent プラグインです。チャネルを通じてユーザーと会話し、セッションとメモリーを保持し、ツールを使い、VM を使ってその場でコーディングします。

**Agent Tool（Agent ツール）。** プラグインがオンボード Agent に提供する、モデル向けの操作です。

**App（アプリ）。** 独自の UI を持つデバイスアプリケーションです。Live Editor で作成し、デバイス上では App Manager プラグインが管理します。

**App Manager（アプリマネージャー）。** デバイス上でアプリのインストール、起動、停止、更新を行うプラグインです。

**Board（ボード）。** YAML で記述された具体的なハードウェアです。チップ、ツールチェーンのターゲット、フラッシュのレイアウト、ペリフェラルを定義します。プラットフォームとは独立して選びます。

**Builder（ビルダー）。** 特定のターゲットと用途に合わせた製品ファームウェアを出荷する人です。通常は `fully-customize` skill を使います。

**Channel（チャネル）。** オンボード Agent に話しかける手段です。WeChat、Telegram、QQ、iMessage、Inkbox、Web チャット、ターミナルがあります。各チャネルはプラグインです。

**Coding agent（コーディング Agent）。** 開発者のマシン上で動く AI コーディングツール（Claude Code、Cursor、Codex）で、Barracuda の skill と組み合わせて使います。

**Device Portal（デバイスポータル）。** 設定、状態表示、プラグインのページ、Web チャットのためにデバイスが配信する Web インターフェースです。

**Experience ladder（体験のはしご）。** Barracuda の使い方の 6 段階です。そのまま使う、構成する、アプリを作る、プラグインを作る、ボードとプラットフォームを追加する、完全にカスタマイズする、の順に進みます。

**In-browser agent（ブラウザ内の Agent）。** Live Editor の中でアプリとその UI を生成する Agent です。

**In-time coding（その場のコーディング）。** 会話の一部として、オンボード Agent が VM スクリプトを書き、すぐにハードウェア上で実行することです。

**Live Editor（ライブエディター）。** デバイスアプリを作成して書き込むための、ブラウザベースのビジュアルかつエージェント型のエディターです。

**Platform（プラットフォーム）。** チップファミリーまたはホスト OS 向けのプラットフォーム契約の実装です。エグゼキューターのエントリー、ネットワークスタック、ファイルシステム、フラッシュ、HAL アダプターを含みます。

**Plugin（プラグイン）。** 機能の基本単位です。型付きケイパビリティ、Workflow の Action と Event、Agent Tool、VM パッケージ、ポータルのページ、リソース、タスクからなる契約を宣言します。

**Skill（skill）。** リポジトリ内にある Agent が読める手順書で、コーディング Agent に Barracuda の作業のやり方を教えます。`create-plugin`、`create-board`、`create-platform`、`fully-customize` があります。

**System（System）。** プラグインの組み合わせを依存関係の順に登録して起動する、移植可能な `no_std` のレイヤーです。同じ System がすべてのプラットフォームで動きます。

**VM（VM）。** デバイス上の Lua ランタイムです。オンボード Agent や Workflow が書いたスクリプトを、ハードウェアを公開するパッケージとともに実行します。

**Web Installer（Web インストーラー）。** USB 経由でボードに Barracuda をインストールし、Wi-Fi に接続するブラウザページです。

**Workflow（Workflow）。** 永続的なオートメーションです。Event が Action を起動するので、デバイスは自律的に動き続けます。
