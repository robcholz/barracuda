Barracuda はコマンドを Cargo のエイリアスとして追加するので、追加のインストールなしでリポジトリ内のどこからでも実行できます。

## cargo board

| コマンド | 動作 |
| --- | --- |
| `cargo board select [NAME]` | ボードを選びます。名前を省略すると対話的に選べます。以降の `cargo build` と `cargo run` はこのボードを使います |
| `cargo board target [NAME]` | ボードの Rust ターゲットトリプルを表示します。省略時は選択中のボードです |
| `cargo board sync [--check]` | ボードを検証し、ペリフェラルの実装をレジストリに同期します |

## cargo plugin

| コマンド | 動作 |
| --- | --- |
| `cargo plugin info <ID>` | プラグインのマニフェストと依存関係を表示します |
| `cargo plugin select` | 有効なプラグインを、このマシンでだけ `.barracuda/disabled-plugins` で無効にします |
| `cargo plugin run <TASK> [--plugin <ID>]` | `plugin.toml` で宣言されたタスク（`build` など）を、有効なプラグインに対して実行します |
| `cargo plugin sync [--check]` | 見つかったプラグインを System のレジストリに同期します |

ファームウェアに含まれるプラグインは、ボードのプロファイルで決まります。[ボードプロファイル](/ja/boards/profiles) を参照してください。

## cargo image

| コマンド | 動作 |
| --- | --- |
| `cargo image build` | 選択中のボードのプラグインリソースイメージをビルドします |
| `cargo image flash` | ビルドしたイメージをボードの `resources` パーティションに書き込みます |
| `cargo image deploy` | ビルドと書き込みを行います |

[System イメージ](/tools/system-image) を参照してください。

## cargo platform

| コマンド | 動作 |
| --- | --- |
| `cargo platform sync [--check]` | 見つかったプラットフォームをレジストリに同期します |

## cargo cli

ターミナルのチャネルです。どのボードを選んでいても、常に自分のコンピューター向けにビルドされます。

| コマンド | 動作 |
| --- | --- |
| `cargo cli` | 動作中のデバイスとチャットします。Local または Remote を選びます |
| `cargo cli configure [ADDRESS]` | ターミナルからモデル、Web 検索、チャネルを設定します |
| `cargo cli chat ADDRESS < messages.txt` | ファイルからメッセージを送信します |

## 環境変数

| 変数 | 使用するもの | 意味 |
| --- | --- | --- |
| `BARRACUDA_VIRTUAL_IO_ADDR` | `local-linux`、`local-macos` | 仮想ペリフェラルのループバックアドレス（例: `127.0.0.1:7878`） |
| `BARRACUDA_LOG_LEVEL` | `cargo build`、`cargo run` | ビルドに組み込むログレベル。`off`、`error`、`warn`、`info`、`debug`、`trace` のいずれか |
