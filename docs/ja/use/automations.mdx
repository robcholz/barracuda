---
title: "オートメーション"
description: "Workflow のオートメーションとスケジュールで、チャットが終わった後もデバイスを動かし続けます。"
---

スクリプトは Agent と会話している間だけ動きます。オートメーションは会話が終わった後も動き続けます。たとえば「毎朝 7 時に」「メッセージが届いたら」「スケジュールの時刻になったら」といったものです。Agent にふだんの言葉で頼めば作成できます。

| 要素 | プラグイン | 役割 |
| --- | --- | --- |
| Workflow | [`workflow`](/plugins/workflow) | オートメーションを永続的に保存し、Event を照合して Action を実行します |
| スケジュール | [`scheduler`](/plugins/scheduler) | 永続的なスケジュールを保持し、時刻になると Event を発行します |
| Agent のツール | [`agent-workflow`](/plugins/agent-workflow)、[`agent-scheduler`](/plugins/agent-scheduler) | Agent がオートメーションを一覧・ロード・アンロード・切り替えし、イベントをスケジュールまたはキャンセルできるようにします |

Agent の Workflow ツールは `workflow_actions`、`workflow_list`、`workflow_load`、`workflow_unload`、`workflow_switch` で、スケジュール用のツールは `scheduler_schedule` と `scheduler_cancel` です。

各プラグインが追加する Workflow の Action と Event は、[プラグイン](/plugins/overview) 配下のそれぞれのページに記載されています。
