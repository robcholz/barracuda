---
title: "チャネル"
description: "Web チャット、ターミナル、WeChat、QQ、Telegram、iMessage、Inkbox からオンボード Agent に話しかけます。"
---

どのチャネルからも同じ Agent に、同じセッションでつながります。チャネルはそれぞれがプラグインなので、ファームウェアには必要なチャネルだけを入れられます。

| チャネル | プラグイン | 接続方法 |
| --- | --- | --- |
| Web チャット | [`imessage-web`](/plugins/imessage-web) | [デバイスポータル](/ja/use/device-portal) で **Web chat** を開きます |
| ターミナル | `cargo cli` | `cargo cli` を実行し、Local または Remote を選びます |
| WeChat | [`imessage-wechat`](/plugins/imessage-wechat) | ポータルページの QR コードをスキャンします |
| QQ | [`imessage-qq`](/plugins/imessage-qq) | ポータルページの QR コードをスキャンします |
| Telegram | [`imessage-telegram`](/plugins/imessage-telegram) | ポータルページでボットトークンを入力します |
| iMessage | [`imessage-bluebubble`](/plugins/imessage-bluebubble) | ポータルページで BlueBubbles サーバーを接続します |
| Inkbox | [`imessage-inkbox`](/plugins/imessage-inkbox) | ポータルページで Inkbox の API キーを入力するか、サインアップします |

どのチャネルも、応答する前に **Models** ページでモデルを登録しておく必要があります。

## オーナー

メッセージングのチャネルは、オーナーにだけ応答します。オーナーになるには、そのチャネルのポータルページに表示される 6 桁のペアリングコードをチャネルに送信します。コードの有効期限は 10 分で、**New code** を押すと新しいコードに置き換わります。

## セッション

どのチャネルでも、同じテキストコマンドでセッションを管理します。

| コマンド | 動作 |
| --- | --- |
| `/sessions` | 保存済みセッションを新しい順に一覧表示します |
| `/new` | 新しいセッションを開始します |
| `/new temp` | 保存しない一時セッションを開始します |
| `/switch N` | セッション `N` に切り替えます |
| `/rename N title` | セッション `N` の名前を変更します |
| `/delete N` | セッション `N` の削除を確認します。`/delete N confirm` で削除します |

Web チャットでは、同じセッションが一覧で表示されます。
