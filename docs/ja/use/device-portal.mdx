---
title: "デバイスポータル"
description: "デバイスと同じネットワーク上のブラウザから、Wi-Fi、モデル、チャネル、ファイル、アプリを設定します。"
---

デバイスポータルは、デバイス自身が `/portal/` で配信する Web アプリです。設定を持つ有効なプラグインがそれぞれページを追加するので、ポータルの内容は常にファームウェアと一致します。

## ポータルを開く

| デバイスの状態 | アドレス |
| --- | --- |
| まだ Wi-Fi に接続していないボード | オープンネットワーク `Barracuda Setup` に参加し、`http://192.168.4.1/portal/` を開きます |
| ネットワークに接続済みのボード | `http://DEVICE_ADDRESS:8787/portal/` |
| `local-linux` | `http://10.42.0.2:8787/portal/` |

ポータルはブラウザの言語設定に合わせて、中国語または英語で表示されます。

## ページ

| ページ | 提供元プラグイン | 設定する内容 |
| --- | --- | --- |
| Wi-Fi | [`wifi`](/plugins/wifi) | ネットワークのスキャンと接続、セットアップ用ホットスポット |
| Models | [`agent`](/plugins/agent) | Agent の用途ごとのモデルサービス、モデル、API キー |
| Web search | [`agent-websearch`](/plugins/agent-websearch) | Agent が使う検索サービス |
| Web chat | [`imessage-web`](/plugins/imessage-web) | ブラウザで Agent と会話します |
| WeChat、QQ、Telegram、BlueBubbles、Inkbox | [チャネル](/ja/use/channels) | アカウントの紐付け、オーナー、ペアリングコード |
| Files | [`files`](/plugins/files) | Workspace とプラグインのファイルを閲覧します |
| Apps | [`app-portal`](/plugins/app-portal) | アプリを確認してインストールします |

各ページは、そのプラグインがファームウェアに含まれている場合にだけ表示されます。[ボードプロファイル](/ja/boards/profiles) を参照してください。

<Warning>
  ポータルの HTTP API には認証も通信の暗号化もなく、セットアップ用ホットスポットはオープンです。デバイスの設定は信頼できるネットワーク上でのみ行ってください。
</Warning>

ターミナルからは、`cargo cli configure` でブラウザを使わずに同じモデル、Web 検索、チャネルの設定を入力できます。[ビルドと実行](/ja/get-started/build-and-run) を参照してください。
