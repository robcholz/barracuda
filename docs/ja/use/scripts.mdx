依頼が物理的な世界に関わるとき、オンボード Agent は短い Lua スクリプトを書き、`vm_run` ツールでデバイスの VM 上で実行します。スクリプトは実行した瞬間に実際のペリフェラルを読み取り、操作し、その出力が会話に返ってきます。

```txt
> ピン vio-0 を High にして
```

```lua
local gpio = require("gpio")
local pin = gpio.open_output("vio-0", true, "push-pull")
print("vio-0 is high")
```

## スクリプトで使えるもの

Lua パッケージはそれぞれ専用のプラグインが提供するので、スクリプトはファームウェアに含まれているものをそのまま使えます。

| パッケージ | プラグイン | 用途 |
| --- | --- | --- |
| `gpio` | [`vm-gpio`](/plugins/vm-gpio) | ボードの公開ピンでのデジタル入出力 |
| `i2c`、`spi`、`uart` | [`vm-i2c`](/plugins/vm-i2c)、[`vm-spi`](/plugins/vm-spi)、[`vm-uart`](/plugins/vm-uart) | バス |
| `pwm`、`analog`、`i2s` | [`vm-pwm`](/plugins/vm-pwm)、[`vm-analog`](/plugins/vm-analog)、[`vm-i2s`](/plugins/vm-i2s) | PWM 出力、アナログ入力、I2S オーディオストリーム |
| `display`、`camera`、`audio` | [`vm-display`](/plugins/vm-display)、[`vm-camera`](/plugins/vm-camera)、[`vm-audio`](/plugins/vm-audio) | 画面、カメラ、サウンド |
| `motion`、`light`、`power_monitor` | [`vm-imu`](/plugins/vm-imu)、[`vm-led-strip`](/plugins/vm-led-strip)、[`vm-power-monitor`](/plugins/vm-power-monitor) | モーション検知、LED ストリップ、電源 |
| `http`、`filesystem`、`message_queue` | [`vm-http`](/plugins/vm-http)、[`vm-filesystem`](/plugins/vm-filesystem)、[`vm-message-queue`](/plugins/vm-message-queue) | リクエスト、ファイル、キュー |
| `agent` | [`vm-agent`](/plugins/vm-agent) | スクリプトの中から Agent に質問します |
| `time` | [`vm-time`](/plugins/vm-time) | `os.time` と `os.date` による UTC 時刻 |

各パッケージのページに、その Lua API が記載されています。ランタイム自体については [VM](/plugins/vm) ページを参照してください。

## 長時間動くスクリプト

`vm_run` は Agent のバックグラウンドプールで実行されるので、スクリプトの実行中も会話を続けられます。

- `io.read()` を呼び出すスクリプトは一時停止して入力を求めます。あなたの返信がスクリプトに渡されます。
- Agent は `background_list`、`background_input`、`background_cancel` ツールで、実行中のスクリプトの一覧表示、入力への応答、キャンセルを行います。スクリプトを止めるよう頼めば、Agent が実行をキャンセルします。

「毎朝 7 時に」のように会話が終わった後も続ける必要がある動作には、Agent は [オートメーション](/ja/use/automations) を使います。
