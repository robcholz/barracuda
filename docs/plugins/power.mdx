Owns the Board's primary power monitor and publishes its readings and the
battery's charge to other Plugins as `Power`.

- Plugin ID: `power`
- Dependencies: none
- Settings: none
- Context resources: peripheral slot `power-monitor.device` (`primary`, optional)
- Provided capabilities: `Power`
- Required capabilities: none
- Workflow: none
- Agent Tools: none
- Lua packages: none
- Web: none
- Tasks: none
- Storage: none

This Plugin takes the Board's primary `PowerMonitor` exactly once and keeps
it behind a lock. `Power` is cheap to clone, and every clone reads the same
monitor, so the system UI's battery and a Lua handle read it side by side:

- `Power::is_present()`: whether the Board has a power monitor.
- `Power::measure()`: one coherent sample (`PowerMeasurement`), or
  `PowerError` without a monitor or when the reading fails.
- `Power::battery()`: the battery's charge (`BatteryState` with `percent`
  and `charging`) from a monitor that is a battery fuel gauge, such as the
  BQ27220; `None` from others or when the reading fails.

I2C ownership, chip initialization, calibration, and conversion to integer
SI subunits stay in the selected implementation and generated Board HAL.
The Plugin performs no background sampling and owns no long-running tasks.
