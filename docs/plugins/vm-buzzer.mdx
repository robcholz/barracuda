Installs the `buzzer` Lua package over the Board's primary buzzer.

- Plugin ID: `buzzer`
- Dependencies: `vm`
- Settings: none
- Context resources: peripheral slot `buzzer.device` (`primary`, optional)
- Provided capabilities: none
- Required capabilities: `LuaPackageRegistry` from `vm`
- Workflow: none
- Agent Tools: none
- Lua packages: `buzzer`
- Web: none
- Tasks: none
- Storage: none

This Plugin takes the Board's primary `Buzzer` capability exactly once and
installs the `buzzer` Lua package. It consumes the semantic peripheral and
never reaches its PWM output.

Lua API:

- `buzzer.available() -> boolean`
- `buzzer.range() -> lowest_hz, highest_hz`
- `buzzer.tone(frequency_hz, duration_ms[, volume]) -> true` sounds one tone
  and returns when it ends; a zero frequency rests
- `buzzer.play(notes[, volume]) -> true` plays `\{ \{frequency_hz, duration_ms\}, ... \}`,
  at most 256 notes, and returns when the melody ends
- `buzzer.start(frequency_hz[, volume]) -> true` sounds a tone until `stop`
- `buzzer.stop() -> true`

`volume` is 0 through 100 percent and defaults to 50. A frequency outside
`range`, a volume above 100, or a call while another is playing returns
`nil, error`. Cancelling `tone` or `play`, for example by stopping the script,
silences the buzzer.

While the Board has the device, the package declares a stable interface
(`PackageInterface::Stable`), version 1. Boards without a buzzer still install
the package; `available` returns false and every other call returns
`nil, error`. Plugin revocation prevents every further call.

```lua
local buzzer = require("buzzer")
buzzer.play({ { 523, 150 }, { 659, 150 }, { 784, 300 } }, 40)
```
