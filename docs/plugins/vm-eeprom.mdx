Installs the `eeprom` Lua package over the Board's primary EEPROM.

- Plugin ID: `eeprom`
- Dependencies: `vm`
- Settings: none
- Context resources: peripheral slot `eeprom.device` (`primary`, optional)
- Provided capabilities: none
- Required capabilities: `LuaPackageRegistry` from `vm`
- Workflow: none
- Agent Tools: none
- Lua packages: `eeprom`
- Web: none
- Tasks: none
- Storage: none

This Plugin takes the Board's primary `Eeprom` capability exactly once and
installs the `eeprom` Lua package. It consumes the semantic peripheral, which
splits writes at the memory's page boundaries and waits out each page's write
cycle, so scripts address bytes and never pages.

Lua API:

- `eeprom.available() -> boolean`
- `eeprom.size() -> bytes`, the memory's capacity
- `eeprom.page_size() -> bytes`, the most bytes one write cycle programs
- `eeprom.read(offset, length) -> binary string`
- `eeprom.write(offset, binary_string) -> true` returns once every byte is
  programmed

Offsets count bytes from 0. A range past the end of the memory, a negative
offset or length, or a call while another is running returns `nil, error`
without touching the memory. Cancelling a write leaves the pages written so
far programmed.

An EEPROM endures a limited number of write cycles per page (typically one
million); keep frequently changing values in RAM and write them back
occasionally.

While the Board has the device, the package declares a stable interface
(`PackageInterface::Stable`), version 1. Boards without an EEPROM still
install the package; `available` returns false and every other call returns
`nil, error`. Plugin revocation prevents every further call.

```lua
local eeprom = require("eeprom")
eeprom.write(0, string.pack("<I4", 42))
local value = string.unpack("<I4", eeprom.read(0, 4))
```
