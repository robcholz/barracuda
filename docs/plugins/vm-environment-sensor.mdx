Installs the `environment` Lua package over the Board's primary environment sensor.

- Plugin ID: `environment-sensor`
- Dependencies: `vm`
- Settings: none
- Context resources: peripheral slot `environment-sensor.device` (`primary`, optional)
- Provided capabilities: none
- Required capabilities: `LuaPackageRegistry` from `vm`
- Workflow: none
- Agent Tools: none
- Lua packages: `environment`
- Web: none
- Tasks: none
- Storage: none

This Plugin takes the Board's primary `EnvironmentSensor` capability exactly
once and installs the `environment` Lua package. An environment sensor reports
whichever ambient quantities its chips measure. A product with several such
chips, such as the M5Stack AirQ with its SEN55 and SCD40, presents them as one
device, so a script sees one sensor with the union of their quantities. I2C
ownership, chip start-up, and integer unit conversion remain with the selected
implementation and the generated Board HAL.

Lua API:

- `environment.available() -> boolean`
- `environment.open() -> handle`
- `handle:quantities() -> name, ...`: the quantities this sensor reports
- `handle:read(name, ...) -> value, ...`: one sample; the value of each named
  quantity in order, or of every reported quantity when no name is given
- `handle:is_open() -> boolean`
- `handle:close()`

Values are integers in these units:

| Quantity | Unit |
| --- | --- |
| `temperature` | milli-degrees Celsius |
| `relative_humidity` | thousandths of a percent |
| `co2` | parts per million |
| `pm1_0`, `pm2_5`, `pm4_0`, `pm10` | nanograms per cubic metre |
| `voc_index`, `nox_index` | thousandths of a Sensirion index point (1 to 500) |
| `illuminance` | millilux |
| `proximity` | the sensor's raw counts; larger is nearer |

A value is `nil` while its quantity has no valid reading yet, such as CO2
during the first five seconds or the NOx index during its warm-up, and for a
quantity the sensor does not report. A read with an unknown quantity name, or
one that fails on the bus, returns `nil, error`.

```lua
local environment = require("environment")
local sensor <close> = environment.open()
local temperature, co2 = sensor:read("temperature", "co2")
```

While the Board has the device, the package declares a stable interface
(`PackageInterface::Stable`), version 1.

Boards without an environment sensor report unavailable, and `open` returns
`nil, error`. The move-only
built-in capability permits one handle per boot; explicit close, lexical
`<close>`, collection, and Plugin revocation prevent further operations. The
Plugin performs no background sampling and owns no long-running tasks.
