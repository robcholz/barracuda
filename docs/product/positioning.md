# Positioning and messaging

## Positioning statement

For developers, educators, and development-board companies who want AI-native
devices without the weight of embedded tooling, Barracuda is a plugin-based
embedded runtime and agentic platform. Unlike cloud assistants that treat the
device as a speaker and a microphone, and unlike traditional embedded SDKs that
leave every project to start from scratch, Barracuda puts an agent on the device
that codes the hardware in real time, and gives builders agents for everything
else — apps in the browser; Plugins, Boards, and firmware on their own machine.

## One-liner

**Barracuda is the agentic platform for embedded devices: everything is a
Plugin, and an agent helps at every step.**

## Headline options

- Every board, agentic.
- The agentic platform for embedded.
- From a sentence to a firmware, with an agent at every step.
- An agent on every device. Agents for everything you build for it.

## Message pillars

1. **An agent on the device.** Every Barracuda device carries a lightweight
   agent that codes its own hardware in real time: ask for something physical,
   watch it write the script and run it.
2. **Plugins are the primitive.** Every capability is a Plugin. Choose them,
   build with them, write your own, and ship only what you need.
3. **Agentic at every level.** The in-browser agent builds apps; coding agents
   create Plugins, Boards, Platforms, and custom firmware with Barracuda's skills.
4. **A modern developer experience on embedded.** Install from a browser,
   configure from a web page, chat from your phone; when you go deeper, it is one
   repository, one command, and the coding agent you already use.
5. **Runs where you need it.** The same System runs on ESP32 and STM32
   microcontrollers and on Linux and macOS, fitted to each target's resources.

## Proof points

- One portable System across microcontrollers and desktop hosts.
- Dozens of first-party Plugins: networking, portal, agent, scripting VM,
  Workflow, message channels, and peripherals from GPIO to camera.
- Boards from M5Stack, Espressif, ST, and others, installable from a browser.
- Skills for Claude Code, Cursor, and Codex in the repository.
- Every Plugin documented for people and agents.

## Talking to each audience

| Audience | Lead with | Then |
| --- | --- | --- |
| Makers | "Talk to your board; it writes the code and runs it." | Browser install, choosing Plugins |
| App developers | "Describe a device app; get it with its UI; flash it from the browser." | Live Editor, App Manager |
| Plugin and runtime developers | "Your coding agent builds Barracuda the Barracuda way." | Skills, Plugin contract, one System on every target |
| Builders | "Ship firmware sized to your chip and your job." | `fully-customize`, removable Plugins |
| Education | "From a sentence to hardware on day one, from scripts to systems by the end of term." | No setup, the ladder as curriculum |
| Board companies | "Make your board AI-ready and installable from a browser." | `create-board`, Web Installer listing |

## Vocabulary

| Say | Avoid | Why |
| --- | --- | --- |
| agentic platform, embedded runtime | AI assistant, chatbot, smart speaker | Barracuda is a platform for building, not a single assistant |
| on-board agent | cloud AI, voice assistant | The agent runs on the device |
| in-time coding, writes a script and runs it | generates code (unqualified) | Distinguishes run-time scripts from build-time generation |
| Plugin | module, add-on, extension | Plugin is the primitive and a defined term |
| install from the browser | flash firmware (on outward pages) | Outcome language for newcomers; "flash" is fine in developer docs |
| Board, Platform | device type, SDK | Defined terms; Board and Platform are selected independently |
| skills for Claude Code, Cursor, and Codex | AI integration | Names the tools developers already use |

On outward-facing pages (website, installer, portal), describe outcomes. Keep
internals — Lua, the app runtime's language, executor and stack details — in the
developer docs, where they help.
