---
title: "Channels"
description: "Reach the on-board Agent from web chat, the terminal, WeChat, QQ, Telegram, iMessage, and Inkbox."
---

Every channel reaches the same Agent, with the same sessions. Each channel is a
Plugin, so a firmware carries only the channels it needs.

| Channel | Plugin | How to connect |
| --- | --- | --- |
| Web chat | [`imessage-web`](/plugins/imessage-web) | Open **Web chat** in the [Device Portal](/use/device-portal) |
| Terminal | `cargo cli` | Run `cargo cli` and choose Local or Remote |
| WeChat | [`imessage-wechat`](/plugins/imessage-wechat) | Scan the QR code on its portal page |
| QQ | [`imessage-qq`](/plugins/imessage-qq) | Scan the QR code on its portal page |
| Telegram | [`imessage-telegram`](/plugins/imessage-telegram) | Enter your bot token on its portal page |
| iMessage | [`imessage-bluebubble`](/plugins/imessage-bluebubble) | Connect your BlueBubbles server on its portal page |
| Inkbox | [`imessage-inkbox`](/plugins/imessage-inkbox) | Enter an Inkbox API key, or sign up, on its portal page |

Before any channel can answer, register a model on the **Models** page.

## Owners

A messaging channel answers only its owners. To become one, send the channel
the six-digit pairing code shown on its portal page. A code is valid for ten
minutes; **New code** replaces it.

## Sessions

Every channel manages sessions with the same text commands:

| Command | What it does |
| --- | --- |
| `/sessions` | List saved sessions, newest first |
| `/new` | Start a new session |
| `/new temp` | Start a temporary session that is not saved |
| `/switch N` | Switch to session `N` |
| `/rename N title` | Rename session `N` |
| `/delete N` | Ask to delete session `N`; `/delete N confirm` deletes it |

Web chat shows the same sessions as a list.
