ESP32-DevKitC V4 是 Espressif 推出的 ESP32 开发板。

- 开发板 ID：`esp32-devkitc-v4`
- 厂商：Espressif
- 芯片：ESP32
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`xtensa-esp32-none-elf`
- Profile：[`headless`](/zh/boards/profiles)（默认）
- Flash 布局：`boards/configs/esp32-devkitc-v4/partitions.csv`

## 构建和运行

```bash terminal
cargo board select esp32-devkitc-v4
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。

## 外设

这块开发板目前还没有声明外设。网络、Agent 和门户可以在它上面运行；把它的设备添加到 `boards/configs/esp32-devkitc-v4/board.yml` 中即可驱动它们。参见[外设组合](/zh/boards/peripherals)。
