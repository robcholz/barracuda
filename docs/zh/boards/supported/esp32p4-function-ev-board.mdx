ESP32-P4-Function-EV-Board 是 Espressif 推出的 ESP32-P4 开发板。

- 开发板 ID：`esp32p4-function-ev-board`
- 厂商：Espressif
- 芯片：ESP32-P4
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`riscv32imafc-unknown-none-elf`
- Profile：[`headless`](/zh/boards/profiles)（默认）
- Flash 布局：`boards/configs/esp32p4-function-ev-board/partitions.csv`

## 构建和运行

```bash terminal
cargo board select esp32p4-function-ev-board
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。

| 设备 | 说明 | Lua 包 |

| `audio-codec` | 音频编解码器（ES8311） | [`audio`](/zh/plugins/vm-audio) |
| `micro-sd` | microSD 卡槽（FAT） | — |

显示屏、触摸和摄像头接口尚未声明；把它们的设备添加到 `boards/configs/esp32p4-function-ev-board/board.yml` 中即可驱动它们。参见[外设组合](/zh/boards/peripherals)。

## microSD 卡

microSD 卡槽位于 ESP32-P4 SD 主机的槽位 0，接在该槽位固定的引脚上。Wi-Fi 协处理器使用同一主机的槽位 1。[ESP32-P4 平台](/zh/platforms/esp32)拥有这个 SD 主机，并把槽位 0 交给 `micro-sd` 设备。它以 4 线、40 MHz 驱动存储卡，并由芯片的 LDO VO4 以 3.3 V 为卡的 I/O 供电。FAT 格式的卡会出现在 `/removable/micro-sd`。卡槽没有插卡检测线，所以拔出或更换存储卡会在下次读取卡槽时发现，约在一秒之内。

| 信号 | 引脚 |
| --- | --- |
| SD CLK / CMD | `GPIO43` / `GPIO44` |
| SD D0 / D1 / D2 / D3 | `GPIO39` / `GPIO40` / `GPIO41` / `GPIO42` |
| 插卡检测 | 无 |
| I/O 供电 | 片上 LDO VO4，3.3 V |

存储卡和 Wi-Fi 按请求的先后轮流使用 SD 主机唯一的传输引擎。一次存储卡传输最多 4 KiB，所以无论文件多大，Wi-Fi 等待存储卡的时间最多约 0.2 ms。

这张存储卡还没有在实机上试过。

## 有线以太网

这块开发板的 IP101GRI PHY 在 `board.yml` 的 `hardware.ethernet` 下声明，[ESP32-P4 平台](/zh/platforms/esp32)在它上面运行 IP 协议栈：EMAC 接在 RMII 引脚上，PHY 地址为 1，复位接 `GPIO51`，并运行 DHCP 客户端。插上网线后，控制台会输出 `network is up at <地址>`；门户在该地址的 8787 端口上应答。

`GPIO35`（BOOT 按键）是 RMII TXD1：以太网运行时该按键不可用。

| 信号 | 引脚 |
| --- | --- |
| 参考时钟输入（来自 PHY） | `GPIO50` |
| MDC / MDIO | `GPIO31` / `GPIO52` |
| TX_EN / TXD0 / TXD1 | `GPIO49` / `GPIO34` / `GPIO35` |
| CRS_DV / RXD0 / RXD1 | `GPIO28` / `GPIO29` / `GPIO30` |
| PHY 复位 | `GPIO51` |

## Wi-Fi

Wi-Fi 射频是 ESP32-C6-MINI-1 协处理器，在 `board.yml` 的 `hardware.wifi-coprocessor` 下声明，运行 Espressif 出厂的 ESP-Hosted-MCU 固件，据 ESP-Hosted 文档其版本为 0.0.6。平台复位协处理器，并以 40 MHz 的 SDIO 与它通信。[Wi-Fi 插件](/zh/plugins/wifi)在协处理器上打开配置热点。

| 信号 | 引脚 |
| --- | --- |
| SDIO CLK / CMD | `GPIO18` / `GPIO19` |
| SDIO D0 / D1 / D2 / D3 | `GPIO14` / `GPIO15` / `GPIO16` / `GPIO17` |
| 协处理器复位 | `GPIO54` |

协处理器没有启动，或运行平台无法驱动的固件时，控制台会输出 `Wi-Fi is unavailable: <原因>`，开发板只保留以太网。

## 两条链路，一个 IP 协议栈

这块开发板在两条链路上只有一个 IP 协议栈。网线链路连通时协议栈使用以太网，否则使用 Wi-Fi 站点。每次切换都会让它重新运行 DHCP，所以设备的地址随链路改变。每拿到一个地址，控制台都会输出 `network is up at <地址>`。

## 插件设置

- [`imessage-gateway`](/zh/plugins/imessage-gateway) 的 `receive-slots` 为 `0`：这块开发板不为消息通道接收循环预留连接。
