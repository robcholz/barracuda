ESP32-S3-BOX-3 是 Espressif 推出的 ESP32-S3 开发板。

- 开发板 ID：`esp32s3-box-3`
- 厂商：Espressif
- 芯片：ESP32-S3
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`xtensa-esp32s3-none-elf`
- Profile：[`screen`](/zh/boards/profiles)
- Flash 布局：`boards/configs/esp32s3-box-3/partitions.csv`

## 构建和运行

```bash terminal
cargo board select esp32s3-box-3
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。

## 外设

| 设备 | 说明 | Lua 包 |
| --- | --- | --- |
| `display` | 显示屏（MIPI DBI） | [`display`](/zh/plugins/vm-display) |
| `touch` | 触摸控制器（GT911 或 TT21100，启动时识别） | — |
| `inertial-measurement` | 运动传感器（ICM-42607-P） | [`motion`](/zh/plugins/vm-imu) |
| `buttons` | BOOT 按键（GPIO0） | — |

与乐鑫 BSP 一样，触摸实现先在 `5Dh` 和 `14h` 查找 GT911，再在 `24h` 查找 TT21100；两者都由显示屏的复位线（GPIO48）复位。静音开关的状态线（GPIO1）不是按键，没有声明。
