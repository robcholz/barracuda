ESP32-S3-EYE 是 Espressif 推出的 ESP32-S3 开发板。

- 开发板 ID：`esp32s3-eye`
- 厂商：Espressif
- 芯片：ESP32-S3
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`xtensa-esp32s3-none-elf`
- Profile：[`screen`](/zh/boards/profiles)
- Flash 布局：`boards/configs/esp32s3-eye/partitions.csv`

## 构建和运行

```bash terminal
cargo board select esp32s3-eye
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。

## 外设

| 设备 | 说明 | Lua 包 |
| --- | --- | --- |
| `camera` | 摄像头（OV2640） | [`camera`](/zh/plugins/vm-camera) |
| `display` | 显示屏（MIPI DBI） | [`display`](/zh/plugins/vm-display) |
| `buttons` | 按键（ADC 电阻阶梯） | [`buttons`](/zh/plugins/vm-buttons) |
| `boot-button` | BOOT 按键（GPIO0） | [`buttons`](/zh/plugins/vm-buttons) |

正面的四个按键共用 GPIO1 上的一条 ADC 电阻阶梯，是主 `buttons` 设备。
