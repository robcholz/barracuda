M5Stack ATOM Echo 是 M5Stack 推出的 ESP32 开发板。

- 开发板 ID：`m5stack-atom-echo`
- 厂商：M5Stack
- 芯片：ESP32
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`xtensa-esp32-none-elf`
- Profile：[`headless`](/zh/boards/profiles)（默认）
- Flash 布局：`boards/configs/m5stack-atom-echo/partitions.csv`

## 构建和运行

```bash terminal
cargo board select m5stack-atom-echo
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。

## 可用引脚

Lua 脚本按名称打开这些引脚。

| 名称 | 引脚 |
| --- | --- |
| `grove-g26` | `GPIO26` |
| `grove-g32` | `GPIO32` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("grove-g26", "up")
print(pin:read())
```
