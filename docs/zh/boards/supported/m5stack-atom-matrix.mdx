M5Stack ATOM Matrix 是 M5Stack 推出的 ESP32 开发板。

- 开发板 ID：`m5stack-atom-matrix`
- 厂商：M5Stack
- 芯片：ESP32
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`xtensa-esp32-none-elf`
- Profile：[`headless`](/zh/boards/profiles)（默认）
- Flash 布局：`boards/configs/m5stack-atom-matrix/partitions.csv`

## 构建和运行

```bash terminal
cargo board select m5stack-atom-matrix
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。

## 外设

| 设备 | 说明 | Lua 包 |
| --- | --- | --- |
| `led-strip` | LED 灯带（WS2812） | [`light`](/zh/plugins/vm-led-strip) |
| `inertial-measurement` | 运动传感器（MPU6886，较新单元为 BMI270） | [`motion`](/zh/plugins/vm-imu) |
| `buttons` | 按键（GPIO39） | — |
| `infrared` | 红外发射器（GPIO12） | [`infrared`](/zh/plugins/vm-infrared) |

运动传感器实现先读取 MPU6886 的标识，读不到时改用 BMI270，与 M5Unified 相同；两者的 X 轴和 Z 轴都反向安装。

## 可用引脚

Lua 脚本按名称打开这些引脚。

| 名称 | 引脚 |
| --- | --- |
| `grove-g26` | `GPIO26` |
| `grove-g32` | `GPIO32` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("grove-g26", "up")
print(pin:read())
```
