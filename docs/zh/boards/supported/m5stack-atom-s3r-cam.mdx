M5Stack AtomS3R-CAM 是 M5Stack 推出的 ESP32-S3 开发板。

- 开发板 ID：`m5stack-atom-s3r-cam`
- 厂商：M5Stack
- 芯片：ESP32-S3
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`xtensa-esp32s3-none-elf`
- Profile：[`headless`](/zh/boards/profiles)（默认）
- Flash 布局：`boards/configs/m5stack-atom-s3r-cam/partitions.csv`

## 构建和运行

```bash terminal
cargo board select m5stack-atom-s3r-cam
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。

## 外设

| 设备 | 说明 | Lua 包 |
| --- | --- | --- |
| `inertial-measurement` | 运动传感器（BMI270） | [`motion`](/zh/plugins/vm-imu) |
| `infrared` | 红外发射器（GPIO47） | [`infrared`](/zh/plugins/vm-infrared) |

## 可用引脚

Lua 脚本按名称打开这些引脚。

| 名称 | 引脚 |
| --- | --- |
| `grove-g1` | `GPIO1` |
| `grove-g2` | `GPIO2` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("grove-g1", "up")
print(pin:read())
```
