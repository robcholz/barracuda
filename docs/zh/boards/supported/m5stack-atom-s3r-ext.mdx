M5Stack AtomS3R-Ext 是 M5Stack 推出的 ESP32-S3 开发板。

- 开发板 ID：`m5stack-atom-s3r-ext`
- 厂商：M5Stack
- 芯片：ESP32-S3
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`xtensa-esp32s3-none-elf`
- Profile：[`headless`](/zh/boards/profiles)（默认）
- Flash 布局：`boards/configs/m5stack-atom-s3r-ext/partitions.csv`

## 构建和运行

```bash terminal
cargo board select m5stack-atom-s3r-ext
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。

## 可用引脚

Lua 脚本按名称打开这些引脚。

| 名称 | 引脚 |
| --- | --- |
| `grove-g1` | `GPIO1` |
| `grove-g2` | `GPIO2` |
| `header-g3` | `GPIO3` |
| `header-g4` | `GPIO4` |
| `header-g9` | `GPIO9` |
| `header-g10` | `GPIO10` |
| `header-g11` | `GPIO11` |
| `header-g12` | `GPIO12` |
| `header-g13` | `GPIO13` |
| `header-g17` | `GPIO17` |
| `header-g21` | `GPIO21` |
| `header-g40` | `GPIO40` |
| `header-g42` | `GPIO42` |
| `header-g46` | `GPIO46` |
| `header-g48` | `GPIO48` |

`header-*` 引脚位于 2.54 mm 原型排针上。

```lua
local gpio = require("gpio")
local pin = gpio.open_input("grove-g1", "up")
print(pin:read())
```
