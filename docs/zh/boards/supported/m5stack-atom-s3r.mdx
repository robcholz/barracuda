M5Stack AtomS3R 是 M5Stack 推出的 ESP32-S3 开发板。

- 开发板 ID：`m5stack-atom-s3r`
- 厂商：M5Stack
- 芯片：ESP32-S3
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`xtensa-esp32s3-none-elf`
- Profile：[`screen`](/zh/boards/profiles)
- Flash 布局：`boards/configs/m5stack-atom-s3r/partitions.csv`

## 构建和运行

```bash terminal
cargo board select m5stack-atom-s3r
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。

## 外设

| 设备 | 说明 | Lua 包 |
| --- | --- | --- |
| `display` | 显示屏（GC9107 或 ST7735S，启动时识别；LP5562 背光） | [`display`](/zh/plugins/vm-display) |
| `inertial-measurement` | 运动传感器（BMI270，其辅助总线上带 BMM150 磁力计） | [`motion`](/zh/plugins/vm-imu) |
| `buttons` | 按键（GPIO41） | — |

## 可用引脚

Lua 脚本按名称打开这些引脚。

| 名称 | 引脚 |
| --- | --- |
| `grove-g1` | `GPIO1` |
| `grove-g2` | `GPIO2` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("grove-g1", "up")
print(pin:read())
```
