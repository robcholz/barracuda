M5Stack ATOM U 是 M5Stack 推出的 ESP32 开发板。

- 开发板 ID：`m5stack-atom-u`
- 厂商：M5Stack
- 芯片：ESP32
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`xtensa-esp32-none-elf`
- Profile：[`headless`](/zh/boards/profiles)（默认）
- Flash 布局：`boards/configs/m5stack-atom-u/partitions.csv`

## 构建和运行

```bash terminal
cargo board select m5stack-atom-u
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。

## 外设

| 设备 | 说明 | Lua 包 |
| --- | --- | --- |
| `led-strip` | RGB LED（SK6812） | [`light`](/zh/plugins/vm-led-strip) |
| `buttons` | 按键（GPIO39） | [`buttons`](/zh/plugins/vm-buttons) |
| `microphone` | 麦克风（SPM1423 PDM） | [`audio`](/zh/plugins/vm-audio) |
| `infrared` | 红外发射器（GPIO12） | [`infrared`](/zh/plugins/vm-infrared) |
