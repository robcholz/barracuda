M5Stack Capsule 是 M5Stack 推出的 ESP32-S3 开发板。

- 开发板 ID：`m5stack-capsule`
- 厂商：M5Stack
- 芯片：ESP32-S3
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`xtensa-esp32s3-none-elf`
- Profile：[`headless`](/zh/boards/profiles)（默认）
- Flash 布局：`boards/configs/m5stack-capsule/partitions.csv`

## 构建和运行

```bash terminal
cargo board select m5stack-capsule
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。

| `buzzer` | 无源蜂鸣器（GPIO2） | [`buzzer`](/zh/plugins/vm-buzzer) |

## 可用引脚

Lua 脚本按名称打开这些引脚。

| 名称 | 引脚 |
| --- | --- |
| `grove-g13` | `GPIO13` |
| `grove-g15` | `GPIO15` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("grove-g13", "up")
print(pin:read())
```
