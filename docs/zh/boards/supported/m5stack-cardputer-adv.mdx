M5Stack Cardputer-Adv 是 M5Stack 推出的 ESP32-S3 开发板。

- 开发板 ID：`m5stack-cardputer-adv`
- 厂商：M5Stack
- 芯片：ESP32-S3
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`xtensa-esp32s3-none-elf`
- Profile：[`screen`](/zh/boards/profiles)
- Flash 布局：`boards/configs/m5stack-cardputer-adv/partitions.csv`

## 构建和运行

```bash terminal
cargo board select m5stack-cardputer-adv
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。

## 可用引脚

Lua 脚本按名称打开这些引脚。

| 名称 | 引脚 |
| --- | --- |
| `grove-g1` | `GPIO1` |
| `grove-g2` | `GPIO2` |
| `header-g3` | `GPIO3` |
| `header-g4` | `GPIO4` |
| `header-g5` | `GPIO5` |
| `header-g6` | `GPIO6` |
| `header-g13` | `GPIO13` |
| `header-g15` | `GPIO15` |

`header-*` 引脚位于 EXT 2.54-14P 排针上。该排针的 SPI 引脚是 microSD 总线，I2C 引脚是内部总线，所以没有开放。

```lua
local gpio = require("gpio")
local pin = gpio.open_input("grove-g1", "up")
print(pin:read())
```
