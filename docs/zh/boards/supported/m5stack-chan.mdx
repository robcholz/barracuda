M5Stack Chan 是 M5Stack 推出的 ESP32-S3 开发板。

- 开发板 ID：`m5stack-chan`
- 厂商：M5Stack
- 芯片：ESP32-S3
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`xtensa-esp32s3-none-elf`
- Profile：[`screen`](/zh/boards/profiles)
- Flash 布局：`boards/configs/m5stack-chan/partitions.csv`

## 构建和运行

```bash terminal
cargo board select m5stack-chan
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。

## 外设

| 设备 | 说明 | Lua 包 |
| --- | --- | --- |
| `display` | 显示屏（MIPI DBI） | [`display`](/zh/plugins/vm-display) |
| `touch` | 触摸控制器（FT6336U） | — |
| `inertial-measurement` | 运动传感器（BMI270，其辅助总线上带 BMM150 磁力计） | [`motion`](/zh/plugins/vm-imu) |
| `environment-sensor` | 环境光和接近传感器（LTR-553ALS） | [`environment`](/zh/plugins/vm-environment-sensor) |
| `real-time-clock` | 实时时钟（BM8563） | — |
| `power-monitor` | 电量计（AXP2101） | [`power_monitor`](/zh/plugins/vm-power-monitor) |
| `audio-codec` | 音频编解码器（AW88298 功放、ES7210 麦克风 ADC） | [`audio`](/zh/plugins/vm-audio) |
| `nfc-reader` | 机身中的 NFC 读卡器（ST25R3916，`50h`） | [`nfc`](/zh/plugins/vm-nfc) |

触摸实现通过 `58h` 处 AW9523B 扩展芯片的 P0_0 释放控制器的复位，该扩展芯片本身不是设备。

电量计与显示屏共用 PMIC：电量计只读取 PMIC 的测量寄存器，稳压器仍归显示屏使用。

AXP2101 不测量电池电流，所以 `measure` 报告电池电压，电流为零。

microSD 卡槽没有声明：它的 MISO（GPIO35）同时是显示屏的 D/C 线，共享的 SPI 总线无法在两者之间切换。
