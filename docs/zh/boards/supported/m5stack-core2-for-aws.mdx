M5Stack Core2 for AWS 是 M5Stack 推出的 ESP32 开发板。

- 开发板 ID：`m5stack-core2-for-aws`
- 厂商：M5Stack
- 芯片：ESP32
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`xtensa-esp32-none-elf`
- Profile：[`screen`](/zh/boards/profiles)
- Flash 布局：`boards/configs/m5stack-core2-for-aws/partitions.csv`

## 构建和运行

```bash terminal
cargo board select m5stack-core2-for-aws
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。

## 外设

| 设备 | 说明 | Lua 包 |
| --- | --- | --- |
| `display` | 显示屏（MIPI DBI） | [`display`](/zh/plugins/vm-display) |
| `touch` | 触摸控制器（FT6336U） | — |
| `audio` | 音频（NS4168 功放、SPM1423 PDM 麦克风） | [`audio`](/zh/plugins/vm-audio) |
| `micro-sd` | microSD 卡槽（FAT，SPI） | — |

触摸屏报告的范围是 320x280：屏幕下方的一条区域是三个触摸按键。显示屏实现的 PMIC 上电过程会连同面板一起复位触摸控制器。

microSD 卡通过自己的片选与显示屏共用 SPI 总线。

## 可用引脚

Lua 脚本按名称打开这些引脚。

| 名称 | 引脚 |
| --- | --- |
| `port-a-scl` | `GPIO33` |
| `port-a-sda` | `GPIO32` |
| `port-b-g26` | `GPIO26` |
| `port-b-g36` | `GPIO36` |
| `port-c-g13` | `GPIO13` |
| `port-c-g14` | `GPIO14` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("port-a-scl", "up")
print(pin:read())
```
