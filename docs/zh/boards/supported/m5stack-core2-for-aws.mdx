M5Stack Core2 for AWS 是 M5Stack 推出的 ESP32 开发板。

- 开发板 ID：`m5stack-core2-for-aws`
- 厂商：M5Stack
- 芯片：ESP32
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`xtensa-esp32-none-elf`
- Profile：[`screen`](/zh/boards/profiles)
- Flash 布局：`boards/configs/m5stack-core2-for-aws/partitions.csv`

## 构建和运行

```bash terminal
cargo board select m5stack-core2-for-aws
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。

## 外设

| 设备 | 说明 | Lua 包 |
| --- | --- | --- |
| `display` | 显示屏（MIPI DBI） | [`display`](/zh/plugins/vm-display) |
| `touch` | 触摸控制器（FT6336U） | — |
| `real-time-clock` | 实时时钟（BM8563） | — |
| `inertial-measurement` | 运动传感器（MPU6886） | [`motion`](/zh/plugins/vm-imu) |
| `power-monitor` | 电量计（AXP192 或 AXP2101） | [`power_monitor`](/zh/plugins/vm-power-monitor) |

触摸屏报告的范围是 320x280：屏幕下方的一条区域是三个触摸按键。显示屏实现的 PMIC 上电过程会连同面板一起复位触摸控制器。

电量计与显示屏共用 PMIC：电量计只读取 PMIC 的测量寄存器，稳压器仍归显示屏使用。

v1.1 单元的 AXP2101 不测量电流，改由 `40h` 的 INA3221 检测电池电流。
