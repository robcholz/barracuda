M5Stack CoreInk 是 M5Stack 推出的 ESP32 开发板。

- 开发板 ID：`m5stack-coreink`
- 厂商：M5Stack
- 芯片：ESP32
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`xtensa-esp32-none-elf`
- Profile：[`screen`](/zh/boards/profiles)
- Flash 布局：`boards/configs/m5stack-coreink/partitions.csv`

## 构建和运行

```bash terminal
cargo board select m5stack-coreink
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。

## 外设

| 设备 | 说明 | Lua 包 |
| --- | --- | --- |
| `display` | 电子墨水屏，1.54 英寸 200 x 200（GDEH0154D67 或 GDEW0154M09，启动时识别） | [`display`](/zh/plugins/vm-display) |

平台入口在构建任何其他部分之前就把电池电源锁存脚 `GPIO12`（`hardware.power-hold`）驱动为高电平，因此不接 USB 时松开电源键后开发板也会保持开机。
