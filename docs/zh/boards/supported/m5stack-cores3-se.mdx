M5Stack CoreS3 SE 是 M5Stack 推出的 ESP32-S3 开发板。

- 开发板 ID：`m5stack-cores3-se`
- 厂商：M5Stack
- 芯片：ESP32-S3
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`xtensa-esp32s3-none-elf`
- Profile：[`screen`](/zh/boards/profiles)
- Flash 布局：`boards/configs/m5stack-cores3-se/partitions.csv`

## 构建和运行

```bash terminal
cargo board select m5stack-cores3-se
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。

## 外设

| 设备 | 说明 | Lua 包 |
| --- | --- | --- |
| `display` | 显示屏（MIPI DBI） | [`display`](/zh/plugins/vm-display) |
| `touch` | 触摸控制器（FT6336U） | — |
| `real-time-clock` | 实时时钟（BM8563） | — |
| `power-monitor` | 电量计（AXP2101） | [`power_monitor`](/zh/plugins/vm-power-monitor) |
| `power-button` | 电源键（AXP2101） | [`buttons`](/zh/plugins/vm-buttons) |
| `audio-codec` | 音频编解码器（AW88298 功放、ES7210 麦克风 ADC） | [`audio`](/zh/plugins/vm-audio) |

触摸实现通过 `58h` 处 AW9523B 扩展芯片的 P0_0 释放控制器的复位，该扩展芯片本身不是设备。

电量计与显示屏共用 PMIC：电量计只读取 PMIC 的测量寄存器，稳压器仍归显示屏使用。

AXP2101 不测量电池电流，所以 `measure` 报告电池电压，电流为零。

microSD 卡槽没有声明：它的 MISO（GPIO35）同时是显示屏的 D/C 线，共享的 SPI 总线无法在两者之间切换。

电源键通过 PMIC 读取：按键松开时 PMIC 锁存一次短按，按住达到长按时间时锁存一次长按；每次按下，按键在一次采样中读为按下。它只设置和清除 PMIC 中电源键自己的中断位。

## 可用引脚

Lua 脚本按名称打开这些引脚。

| 名称 | 引脚 |
| --- | --- |
| `port-a-scl` | `GPIO1` |
| `port-a-sda` | `GPIO2` |
| `port-b-g8` | `GPIO8` |
| `port-b-g9` | `GPIO9` |
| `port-c-g17` | `GPIO17` |
| `port-c-g18` | `GPIO18` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("port-a-scl", "up")
print(pin:read())
```
