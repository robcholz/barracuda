M5Stack CoreS3 是 M5Stack 推出的 ESP32-S3 开发板。

- 开发板 ID：`m5stack-cores3`
- 厂商：M5Stack
- 芯片：ESP32-S3
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`xtensa-esp32s3-none-elf`
- Profile：[`screen`](/zh/boards/profiles)
- Flash 布局：`boards/configs/m5stack-cores3/partitions.csv`

## 构建和运行

```bash terminal
cargo board select m5stack-cores3
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。

## 外设

| 设备 | 说明 | Lua 包 |
| --- | --- | --- |
| `display` | 显示屏（MIPI DBI） | [`display`](/zh/plugins/vm-display) |
| `touch` | 触摸控制器（FT6336U） | — |
| `inertial-measurement` | IMU（BMI270） | [`motion`](/zh/plugins/vm-imu) |

触摸实现通过 `58h` 处 AW9523B 扩展芯片的 P0_0 释放控制器的复位，该扩展芯片本身不是设备。

## 可用引脚

Lua 脚本按名称打开这些引脚。

| 名称 | 引脚 |
| --- | --- |
| `port-a-scl` | `GPIO1` |
| `port-a-sda` | `GPIO2` |
| `port-b-g8` | `GPIO8` |
| `port-b-g9` | `GPIO9` |
| `port-c-g17` | `GPIO17` |
| `port-c-g18` | `GPIO18` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("port-a-scl", "up")
print(pin:read())
```
