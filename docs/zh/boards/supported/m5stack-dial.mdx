M5Stack Dial 是 M5Stack 推出的 ESP32-S3 开发板。

- 开发板 ID：`m5stack-dial`
- 厂商：M5Stack
- 芯片：ESP32-S3
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`xtensa-esp32s3-none-elf`
- Profile：[`screen`](/zh/boards/profiles)
- Flash 布局：`boards/configs/m5stack-dial/partitions.csv`

## 构建和运行

```bash terminal
cargo board select m5stack-dial
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。

## 外设

| 设备 | 说明 | Lua 包 |
| --- | --- | --- |
| `led-strip` | RGB LED（WS2812，GPIO21） | [`light`](/zh/plugins/vm-led-strip) |
| `display` | 显示屏（MIPI DBI） | [`display`](/zh/plugins/vm-display) |
| `touch` | 触摸控制器（FT3267） | — |
| `real-time-clock` | 实时时钟（BM8563） | — |
| `buttons` | 按键 A（旋钮按下）和 B（GPIO42、GPIO0） | — |
| `rotary-encoder` | 旋钮编码器（A GPIO41、B GPIO40，脉冲计数器） | [`encoder`](/zh/plugins/vm-rotary-encoder) |

此 Board 描述搭载 StampS3 的 Dial。Dial v1.1 搭载 Stamp-S3A，其 RGB LED 经 GPIO38 供电；此 Board 不驱动 GPIO38，因此 v1.1 上该 LED 不亮。

## 可用引脚

Lua 脚本按名称打开这些引脚。

| 名称 | 引脚 |
| --- | --- |
| `port-a-scl` | `GPIO15` |
| `port-a-sda` | `GPIO13` |
| `port-b-g1` | `GPIO1` |
| `port-b-g2` | `GPIO2` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("port-a-scl", "up")
print(pin:read())
```
