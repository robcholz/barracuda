M5Stack Fire 是 M5Stack 推出的 ESP32 开发板。

- 开发板 ID：`m5stack-fire`
- 厂商：M5Stack
- 芯片：ESP32
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`xtensa-esp32-none-elf`
- Profile：[`screen`](/zh/boards/profiles)
- Flash 布局：`boards/configs/m5stack-fire/partitions.csv`

## 构建和运行

```bash terminal
cargo board select m5stack-fire
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。

## 可用引脚

Lua 脚本按名称打开这些引脚。

| 名称 | 引脚 |
| --- | --- |
| `port-b-g26` | `GPIO26` |
| `port-b-g36` | `GPIO36` |

Port A 就是内部 I2C 总线，Port C 的 `GPIO16` / `GPIO17` 接 PSRAM，所以两者都没有开放。

```lua
local gpio = require("gpio")
local pin = gpio.open_input("port-b-g26", "up")
print(pin:read())
```
