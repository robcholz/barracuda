M5Stack Fire 是 M5Stack 推出的 ESP32 开发板。

- 开发板 ID：`m5stack-fire`
- 厂商：M5Stack
- 芯片：ESP32
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`xtensa-esp32-none-elf`
- Profile：[`screen`](/zh/boards/profiles)
- Flash 布局：`boards/configs/m5stack-fire/partitions.csv`

## 构建和运行

```bash terminal
cargo board select m5stack-fire
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。

## 外设

| 设备 | 说明 | Lua 包 |
| --- | --- | --- |
| `display` | 显示屏（MIPI DBI） | [`display`](/zh/plugins/vm-display) |
| `power-monitor` | 电池电量（IP5306） | [`power_monitor`](/zh/plugins/vm-power-monitor) |
| `inertial-measurement` | 运动传感器（MPU6886，早期单元为 MPU9250） | [`motion`](/zh/plugins/vm-imu) |
| `buttons` | 按键 A、B、C（GPIO39、GPIO38、GPIO37） | — |

IP5306 只以 25% 的步长报告电池电量和是否在充电；它不测量电压和电流，所以在这块开发板上 `measure` 会失败。

电池芯片和运动传感器所在的内部 I2C 总线同时也是 Port A（GPIO21、GPIO22），所以 Port A 不作为可用引脚。
