M5Stack NanoC6 是 M5Stack 推出的 ESP32-C6 开发板。

- 开发板 ID：`m5stack-nanoc6`
- 厂商：M5Stack
- 芯片：ESP32-C6
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`riscv32imac-unknown-none-elf`
- Profile：[`connected`](/zh/boards/profiles)
- Flash 布局：`boards/configs/m5stack-nanoc6/partitions.csv`

## 构建和运行

```bash terminal
cargo board select m5stack-nanoc6
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。

## 外设

| 设备 | 说明 | Lua 包 |
| --- | --- | --- |
| `status-led` | 指示 LED | — |
| `buttons` | 按键（GPIO9） | [`buttons`](/zh/plugins/vm-buttons) |
| `led-strip` | RGB LED（WS2812，GPIO20） | [`light`](/zh/plugins/vm-led-strip) |
| `infrared` | 红外发射器（GPIO3） | [`infrared`](/zh/plugins/vm-infrared) |

GPIO19 控制 RGB LED 的供电；LED 在启动时将其打开。

## 可用引脚

Lua 脚本按名称打开这些引脚。

| 名称 | 引脚 |
| --- | --- |
| `grove-g1` | `GPIO1` |
| `grove-g2` | `GPIO2` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("grove-g1", "up")
print(pin:read())
```
