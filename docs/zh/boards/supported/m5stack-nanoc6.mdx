M5Stack NanoC6 是 M5Stack 推出的 ESP32-C6 开发板。

- 开发板 ID：`m5stack-nanoc6`
- 厂商：M5Stack
- 芯片：ESP32-C6
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`riscv32imac-unknown-none-elf`
- Profile：[`headless`](/zh/boards/profiles)（默认）
- Flash 布局：`boards/configs/m5stack-nanoc6/partitions.csv`

## 构建和运行

```bash terminal
cargo board select m5stack-nanoc6
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。
