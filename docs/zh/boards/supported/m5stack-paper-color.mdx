M5Stack Paper Color 是 M5Stack 推出的 ESP32-S3 开发板。

- 开发板 ID：`m5stack-paper-color`
- 厂商：M5Stack
- 芯片：ESP32-S3
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`xtensa-esp32s3-none-elf`
- Profile：[`screen`](/zh/boards/profiles)
- Flash 布局：`boards/configs/m5stack-paper-color/partitions.csv`

## 构建和运行

```bash terminal
cargo board select m5stack-paper-color
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。

## 外设

| 设备 | 说明 | Lua 包 |
| --- | --- | --- |
| `display` | 彩色电子墨水屏，4 英寸 400 x 600，六色（E Ink Spectra 6，ED2208 控制器） | [`display`](/zh/plugins/vm-display) |
| `audio-codec` | 音频编解码器（ES8311 和 ES7210） | [`audio`](/zh/plugins/vm-audio) |
| `environment-sensor` | 温湿度传感器（SHT40） | [`environment`](/zh/plugins/vm-environment-sensor) |
| `real-time-clock` | 实时时钟（RX8130CE） | — |
| `power-monitor` | 电量计（M5PM1） | [`power_monitor`](/zh/plugins/vm-power-monitor) |
| `buttons` | 按键 A、B、C（GPIO10、GPIO9、GPIO1） | — |
| `micro-sd` | microSD 卡槽（FAT，SPI） | — |
| `infrared` | 红外发射器（GPIO48） | [`infrared`](/zh/plugins/vm-infrared) |

Spectra 6 不支持局部刷新：每次刷新都会重绘整块屏幕，耗时 10 到 20 秒。

M5PM1 只测量电池电压。这块开发板没有把充电器的状态线接到 M5PM1，所以只要有 VIN 输入且电池低于 4.1 V，电池就显示为正在充电。

microSD 卡通过自己的片选与电子纸面板共用 SPI 总线。

## 可用引脚

Lua 脚本按名称打开这些引脚。

| 名称 | 引脚 |
| --- | --- |
| `port-a-scl` | `GPIO5` |
| `port-a-sda` | `GPIO4` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("port-a-scl", "up")
print(pin:read())
```
