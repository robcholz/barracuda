M5Stack Paper Mono 是 M5Stack 推出的 ESP32-S3 开发板。

- 开发板 ID：`m5stack-paper-mono`
- 厂商：M5Stack
- 芯片：ESP32-S3
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`xtensa-esp32s3-none-elf`
- Profile：[`screen`](/zh/boards/profiles)
- Flash 布局：`boards/configs/m5stack-paper-mono/partitions.csv`

## 构建和运行

```bash terminal
cargo board select m5stack-paper-mono
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。

## 外设

| 设备 | 说明 | Lua 包 |
| --- | --- | --- |
| `display` | 电子墨水屏，3.97 英寸 480 x 800，4 级灰度，带前光（SSD1677） | [`display`](/zh/plugins/vm-display) |
| `inertial-measurement` | 运动传感器（BMI270） | [`motion`](/zh/plugins/vm-imu) |
| `real-time-clock` | 实时时钟（RX8130CE） | — |
| `power-monitor` | 电量计（M5PM1） | [`power_monitor`](/zh/plugins/vm-power-monitor) |
| `buttons` | 按键 A 和 B（GPIO2、GPIO3） | — |
| `buzzer` | 无源蜂鸣器（GPIO42） | [`buzzer`](/zh/plugins/vm-buzzer) |

M5PM1 只测量电池电压。这块开发板没有把充电器的状态线接到 M5PM1，所以只要有 VIN 输入且电池低于 4.1 V，电池就显示为正在充电。
