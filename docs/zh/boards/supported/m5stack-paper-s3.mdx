M5Stack PaperS3 是 M5Stack 推出的 ESP32-S3 开发板。

- 开发板 ID：`m5stack-paper-s3`
- 厂商：M5Stack
- 芯片：ESP32-S3
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`xtensa-esp32s3-none-elf`
- Profile：[`screen`](/zh/boards/profiles)
- Flash 布局：`boards/configs/m5stack-paper-s3/partitions.csv`

## 构建和运行

```bash terminal
cargo board select m5stack-paper-s3
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。

## 外设

| 设备 | 说明 | Lua 包 |
| --- | --- | --- |
| `display` | 电子墨水屏，4.7 英寸 540 x 960 竖屏，16 级灰度（ED047TC1，由 ESP32-S3 并行总线直接驱动） | [`display`](/zh/plugins/vm-display) |
| `inertial-measurement` | IMU（BMI270） | [`motion`](/zh/plugins/vm-imu) |
| `battery` | 电池电压（ADC 电阻分压）和充电状态 | [`power_monitor`](/zh/plugins/vm-power-monitor) |
| `micro-sd` | microSD 卡槽（FAT，SPI） | — |

这块屏幕没有控制器：Barracuda 在 CPU 上运行 M5GFX 的波形，并逐行输出每一帧，所以刷新完成之前显示屏一直被占用。

## 可用引脚

Lua 脚本按名称打开这些引脚。

| 名称 | 引脚 |
| --- | --- |
| `grove-g1` | `GPIO1` |
| `grove-g2` | `GPIO2` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("grove-g1", "up")
print(pin:read())
```
