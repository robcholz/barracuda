M5Stack Paper 是 M5Stack 推出的 ESP32 开发板。

- 开发板 ID：`m5stack-paper`
- 厂商：M5Stack
- 芯片：ESP32
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`xtensa-esp32-none-elf`
- Profile：[`screen`](/zh/boards/profiles)
- Flash 布局：`boards/configs/m5stack-paper/partitions.csv`

## 构建和运行

```bash terminal
cargo board select m5stack-paper
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。

## 外设

| 设备 | 说明 | Lua 包 |
| --- | --- | --- |
| `display` | 电子墨水屏，4.7 英寸 540 x 960 竖屏，16 级灰度（IT8951E 控制器） | [`display`](/zh/plugins/vm-display) |
| `touch` | 触摸控制器（GT911） | — |
| `real-time-clock` | 实时时钟（BM8563） | — |
| `buttons` | 拨轮上、按下、下（GPIO37、GPIO38、GPIO39） | — |

平台入口在构建任何其他部分之前就把主电源锁存脚 `GPIO2`（`hardware.power-hold`）驱动为高电平，因此不接 USB 时松开电源键后开发板也会保持开机。
