M5Stack PowerHub 是 M5Stack 推出的 ESP32-S3 开发板。

- 开发板 ID：`m5stack-powerhub`
- 厂商：M5Stack
- 芯片：ESP32-S3
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`xtensa-esp32s3-none-elf`
- Profile：[`headless`](/zh/boards/profiles)（默认）
- Flash 布局：`boards/configs/m5stack-powerhub/partitions.csv`

## 构建和运行

```bash terminal
cargo board select m5stack-powerhub
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。

## 可用引脚

Lua 脚本按名称打开这些引脚。

| 名称 | 引脚 |
| --- | --- |
| `port-a-scl` | `GPIO16` |
| `port-a-sda` | `GPIO15` |
| `port-c-g1` | `GPIO1` |
| `port-c-g2` | `GPIO2` |
| `header-g4` | `GPIO4` |
| `header-g5` | `GPIO5` |
| `header-g6` | `GPIO6` |
| `header-g7` | `GPIO7` |
| `header-g41` | `GPIO41` |
| `header-g42` | `GPIO42` |
| `header-g43` | `GPIO43` |
| `header-g44` | `GPIO44` |
| `rs485-tx` | `GPIO8` |
| `rs485-rx` | `GPIO17` |
| `rs485-dir` | `GPIO18` |

`header-*` 引脚位于 EXT 2.54-16P 排针上。`rs485-tx`、`rs485-rx` 和 `rs485-dir` 是板载 RS485 收发器的 UART 和方向引脚。

```lua
local gpio = require("gpio")
local pin = gpio.open_input("port-a-scl", "up")
print(pin:read())
```
