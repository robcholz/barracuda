M5Stack Stamp C3 是 M5Stack 推出的 ESP32-C3 开发板。

- 开发板 ID：`m5stack-stamp-c3`
- 厂商：M5Stack
- 芯片：ESP32-C3
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`riscv32imc-unknown-none-elf`
- Profile：[`connected`](/zh/boards/profiles)
- Flash 布局：`boards/configs/m5stack-stamp-c3/partitions.csv`

## 构建和运行

```bash terminal
cargo board select m5stack-stamp-c3
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。

## 外设

| 设备 | 说明 | Lua 包 |
| --- | --- | --- |
| `led-strip` | RGB LED（SK6812，GPIO2） | [`light`](/zh/plugins/vm-led-strip) |
| `buttons` | 按键（GPIO3） | [`buttons`](/zh/plugins/vm-buttons) |

## 可用引脚

Lua 脚本按名称打开这些引脚。

| 名称 | 引脚 |
| --- | --- |
| `grove-g0` | `GPIO0` |
| `grove-g1` | `GPIO1` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("grove-g0", "up")
print(pin:read())
```
