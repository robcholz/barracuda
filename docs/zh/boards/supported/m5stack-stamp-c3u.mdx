M5Stack Stamp C3U 是 M5Stack 推出的 ESP32-C3 开发板。

- 开发板 ID：`m5stack-stamp-c3u`
- 厂商：M5Stack
- 芯片：ESP32-C3
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`riscv32imc-unknown-none-elf`
- Profile：[`headless`](/zh/boards/profiles)（默认）
- Flash 布局：`boards/configs/m5stack-stamp-c3u/partitions.csv`

## 构建和运行

```bash terminal
cargo board select m5stack-stamp-c3u
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。
