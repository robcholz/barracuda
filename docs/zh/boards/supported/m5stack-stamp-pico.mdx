M5Stack Stamp Pico 是 M5Stack 推出的 ESP32 开发板。

- 开发板 ID：`m5stack-stamp-pico`
- 厂商：M5Stack
- 芯片：ESP32
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`xtensa-esp32-none-elf`
- Profile：[`connected`](/zh/boards/profiles)
- Flash 布局：`boards/configs/m5stack-stamp-pico/partitions.csv`

## 构建和运行

```bash terminal
cargo board select m5stack-stamp-pico
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。

## 外设

| 设备 | 说明 | Lua 包 |
| --- | --- | --- |
| `led-strip` | RGB LED（SK6812，GPIO27） | [`light`](/zh/plugins/vm-led-strip) |
| `buttons` | 按键（GPIO39） | [`buttons`](/zh/plugins/vm-buttons) |

## 可用引脚

Lua 脚本按名称打开这些引脚。

| 名称 | 引脚 |
| --- | --- |
| `grove-g32` | `GPIO32` |
| `grove-g33` | `GPIO33` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("grove-g32", "up")
print(pin:read())
```
