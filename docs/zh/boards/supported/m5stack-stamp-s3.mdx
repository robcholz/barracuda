M5Stack StampS3 是 M5Stack 推出的 ESP32-S3 开发板。

- 开发板 ID：`m5stack-stamp-s3`
- 厂商：M5Stack
- 芯片：ESP32-S3
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`xtensa-esp32s3-none-elf`
- Profile：[`headless`](/zh/boards/profiles)（默认）
- Flash 布局：`boards/configs/m5stack-stamp-s3/partitions.csv`

## 构建和运行

```bash terminal
cargo board select m5stack-stamp-s3
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。
