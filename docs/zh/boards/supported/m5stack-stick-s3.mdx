M5Stack StickS3 是 M5Stack 推出的 ESP32-S3 开发板。

- 开发板 ID：`m5stack-stick-s3`
- 厂商：M5Stack
- 芯片：ESP32-S3
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`xtensa-esp32s3-none-elf`
- Profile：[`screen`](/zh/boards/profiles)
- Flash 布局：`boards/configs/m5stack-stick-s3/partitions.csv`

## 构建和运行

```bash terminal
cargo board select m5stack-stick-s3
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。

## 外设

| 设备 | 说明 | Lua 包 |
| --- | --- | --- |
| `display` | 显示屏（MIPI DBI） | [`display`](/zh/plugins/vm-display) |
| `inertial-measurement` | 运动传感器（BMI270） | [`motion`](/zh/plugins/vm-imu) |
| `power-monitor` | 电量计（M5PM1） | [`power_monitor`](/zh/plugins/vm-power-monitor) |
| `buttons` | 按键 A 和 B（GPIO11、GPIO12） | — |
| `power-button` | 电源键（M5PM1） | — |
| `audio-codec` | 音频编解码器（ES8311） | [`audio`](/zh/plugins/vm-audio) |
| `infrared` | 红外发射器和接收器（GPIO46、GPIO42） | [`infrared`](/zh/plugins/vm-infrared) |

M5PM1 只测量电池电压；是否在充电取自接在 M5PM1 引脚上的充电器状态线。

电源键从 M5PM1 的按键状态读取，按住时读为按下。M5PM1 保持出厂行为：单击会复位开发板，双击会关机；除非开发板在该设备上设置 `single-click-reset: disable`，单击不会交给应用。`buttons` 是主 `buttons` 设备。

## 可用引脚

Lua 脚本按名称打开这些引脚。

| 名称 | 引脚 |
| --- | --- |
| `port-a-scl` | `GPIO10` |
| `port-a-sda` | `GPIO9` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("port-a-scl", "up")
print(pin:read())
```
