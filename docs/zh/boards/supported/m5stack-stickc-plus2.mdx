M5Stack StickC Plus2 是 M5Stack 推出的 ESP32 开发板。

- 开发板 ID：`m5stack-stickc-plus2`
- 厂商：M5Stack
- 芯片：ESP32
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`xtensa-esp32-none-elf`
- Profile：[`screen`](/zh/boards/profiles)
- Flash 布局：`boards/configs/m5stack-stickc-plus2/partitions.csv`

## 构建和运行

```bash terminal
cargo board select m5stack-stickc-plus2
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。

## 外设

| 设备 | 说明 | Lua 包 |
| --- | --- | --- |
| `display` | 显示屏（MIPI DBI） | [`display`](/zh/plugins/vm-display) |

显示屏还会在固件运行期间把电池电源锁存脚 `GPIO4` 保持为高电平，因此不接 USB 时开发板也会保持开机。
