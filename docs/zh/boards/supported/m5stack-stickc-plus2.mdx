M5Stack StickC Plus2 是 M5Stack 推出的 ESP32 开发板。

- 开发板 ID：`m5stack-stickc-plus2`
- 厂商：M5Stack
- 芯片：ESP32
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`xtensa-esp32-none-elf`
- Profile：[`screen`](/zh/boards/profiles)
- Flash 布局：`boards/configs/m5stack-stickc-plus2/partitions.csv`

## 构建和运行

```bash terminal
cargo board select m5stack-stickc-plus2
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。

## 外设

| 设备 | 说明 | Lua 包 |
| --- | --- | --- |
| `display` | 显示屏（MIPI DBI） | [`display`](/zh/plugins/vm-display) |
| `status-led` | 指示 LED | — |
| `real-time-clock` | 实时时钟（BM8563） | — |
| `inertial-measurement` | 运动传感器（MPU6886） | [`motion`](/zh/plugins/vm-imu) |
| `buttons` | 按键 A、B 和电源键（GPIO37、GPIO39、GPIO35） | — |

平台入口在构建任何其他部分之前就把电池电源锁存脚 `GPIO4`（`hardware.power-hold`）驱动为高电平，因此不接 USB 时松开电源键后开发板也会保持开机。

GPIO34 到 GPIO39 没有内部上拉；按键使用开发板上的电阻。

## 可用引脚

Lua 脚本按名称打开这些引脚。

| 名称 | 引脚 |
| --- | --- |
| `grove-g32` | `GPIO32` |
| `grove-g33` | `GPIO33` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("grove-g32", "up")
print(pin:read())
```
