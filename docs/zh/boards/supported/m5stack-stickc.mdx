M5Stack StickC 是 M5Stack 推出的 ESP32 开发板。

- 开发板 ID：`m5stack-stickc`
- 厂商：M5Stack
- 芯片：ESP32
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`xtensa-esp32-none-elf`
- Profile：[`screen`](/zh/boards/profiles)
- Flash 布局：`boards/configs/m5stack-stickc/partitions.csv`

## 构建和运行

```bash terminal
cargo board select m5stack-stickc
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。

## 外设

| 设备 | 说明 | Lua 包 |
| --- | --- | --- |
| `display` | 显示屏（MIPI DBI） | [`display`](/zh/plugins/vm-display) |
| `status-led` | 指示 LED | — |
| `real-time-clock` | 实时时钟（BM8563） | — |
| `power-monitor` | 电量计（AXP192） | [`power_monitor`](/zh/plugins/vm-power-monitor) |
| `buttons` | 按键 A 和 B（GPIO37、GPIO39） | — |
| `power-button` | 电源键（AXP192） | — |
| `microphone` | 麦克风（SPM1423 PDM） | [`audio`](/zh/plugins/vm-audio) |
| `infrared` | 红外发射器（GPIO9） | [`infrared`](/zh/plugins/vm-infrared) |

电量计与显示屏共用 PMIC：电量计只读取 PMIC 的测量寄存器，稳压器仍归显示屏使用。

运动传感器没有声明：早期单元装的是 SH200Q 而不是 MPU6886，目前还没有驱动它的实现。

电源键通过 PMIC 读取：按键松开时 PMIC 锁存一次短按，按住达到长按时间时锁存一次长按；每次按下，按键在一次采样中读为按下。它只设置和清除 PMIC 中电源键自己的中断位。`buttons` 是主 `buttons` 设备。

## 可用引脚

Lua 脚本按名称打开这些引脚。

| 名称 | 引脚 |
| --- | --- |
| `grove-g32` | `GPIO32` |
| `grove-g33` | `GPIO33` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("grove-g32", "up")
print(pin:read())
```
