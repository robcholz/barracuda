M5Stack Tab5 是 M5Stack 推出的 ESP32-P4 开发板。

- 开发板 ID：`m5stack-tab5`
- 厂商：M5Stack
- 芯片：ESP32-P4
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`riscv32imafc-unknown-none-elf`
- Profile：[`screen`](/zh/boards/profiles)
- Flash 布局：`boards/configs/m5stack-tab5/partitions.csv`

## 构建和运行

```bash terminal
cargo board select m5stack-tab5
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。

## 外设

| 设备 | 说明 | Lua 包 |
| --- | --- | --- |
| `audio-codec` | 音频编解码器（ES8388 扬声器 DAC、ES7210 麦克风 ADC） | [`audio`](/zh/plugins/vm-audio) |
| `display` | 720x1280 MIPI DSI 显示屏（ILI9881C、ST7123 或 ST7121，启动时识别） | [`display`](/zh/plugins/vm-display) |
| `touch` | 触摸控制器（GT911 或面板自带的 ST712x） | — |
| `real-time-clock` | 实时时钟（RX8130CE） | — |
| `inertial-measurement` | 运动传感器（BMI270） | [`motion`](/zh/plugins/vm-imu) |
| `power-monitor` | 电源监测（INA226） | [`power_monitor`](/zh/plugins/vm-power-monitor) |
| `micro-sd` | microSD 卡槽（FAT） | — |

显示屏实现通过 `43h` 处的 PI4IOE5V6408 扩展芯片复位面板和触摸控制器，该扩展芯片本身不是设备。与 M5GFX 一样，复位期间它把触摸中断线（GPIO23）保持为高电平，使 GT911 应答于 `14h`，然后根据应答的触摸控制器识别面板。音频编解码器实现通过同一个扩展芯片打开扬声器功放。SC202CS 摄像头尚未声明：ESP32-P4 平台没有 MIPI CSI 绑定。

## microSD 卡

microSD 卡槽位于 ESP32-P4 SD 主机的槽位 0，接在该槽位固定的引脚上。Wi-Fi 协处理器使用同一主机的槽位 1。[ESP32-P4 平台](/zh/platforms/esp32)拥有这个 SD 主机，并把槽位 0 交给 `micro-sd` 设备。它以 4 线、40 MHz 驱动存储卡，并由芯片的 LDO VO4 以 3.3 V 为卡的 I/O 供电。FAT 格式的卡会出现在 `/removable/micro-sd`。卡槽没有插卡检测线，所以拔出或更换存储卡会在下次读取卡槽时发现，约在一秒之内。

| 信号 | 引脚 |
| --- | --- |
| SD CLK / CMD | `GPIO43` / `GPIO44` |
| SD D0 / D1 / D2 / D3 | `GPIO39` / `GPIO40` / `GPIO41` / `GPIO42` |
| 插卡检测 | 无 |
| I/O 供电 | 片上 LDO VO4，3.3 V |

存储卡和 Wi-Fi 按请求的先后轮流使用 SD 主机唯一的传输引擎。一次存储卡传输最多 4 KiB，所以无论文件多大，Wi-Fi 等待存储卡的时间最多约 0.2 ms。

这张存储卡还没有在实机上试过。

## Wi-Fi

Wi-Fi 射频是 ESP32-C6 协处理器，在 `board.yml` 的 `hardware.wifi-coprocessor` 下声明，运行 M5Stack 出厂的 ESP-Hosted-MCU 固件。[ESP32-P4 平台](/zh/platforms/esp32)在启动时：

1. 通过 `44h` 处 PI4IOE5V6408 扩展芯片的输出 0 打开协处理器的电源。
2. 复位协处理器。
3. 以 40 MHz 的 SDIO 与它通信。

IP 协议栈运行在它的 Wi-Fi 站点上，[Wi-Fi 插件](/zh/plugins/wifi)在协处理器上打开配置热点。网络给设备分配地址后，控制台会输出 `Wi-Fi is up at <地址>`。

| 信号 | 引脚 |
| --- | --- |
| SDIO CLK / CMD | `GPIO12` / `GPIO13` |
| SDIO D0 / D1 / D2 / D3 | `GPIO11` / `GPIO10` / `GPIO9` / `GPIO8` |
| 协处理器复位 | `GPIO15` |
| 协处理器电源 | `I2C0`（`GPIO32` / `GPIO31`）上 `44h` 处 PI4IOE5V6408 的输出 0 |

出厂固件的版本还没有在实机上与本主机核对过。协处理器没有启动，或运行平台无法驱动的固件时，控制台会输出 `Wi-Fi is unavailable: <原因>`，这时开发板没有网络链路，也没有配置热点。

## 插件设置

- [`imessage-gateway`](/zh/plugins/imessage-gateway) 的 `receive-slots` 为 `0`：这块开发板不为消息通道接收循环预留连接。
