M5Stack TimerCamera 是 M5Stack 推出的 ESP32 开发板。

- 开发板 ID：`m5stack-timercam`
- 厂商：M5Stack
- 芯片：ESP32
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`xtensa-esp32-none-elf`
- Profile：[`headless`](/zh/boards/profiles)（默认）
- Flash 布局：`boards/configs/m5stack-timercam/partitions.csv`

## 构建和运行

```bash terminal
cargo board select m5stack-timercam
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。

## 外设

| 设备 | 说明 | Lua 包 |
| --- | --- | --- |
| `status-led` | 指示 LED | — |
| `battery` | 电池电压（ADC 电阻分压） | [`power_monitor`](/zh/plugins/vm-power-monitor) |

平台入口在构建任何其他部分之前就把电池电源锁存脚 `GPIO33`（`hardware.power-hold`）驱动为高电平，因此不接 USB 时开发板也会保持开机。

## 可用引脚

Lua 脚本按名称打开这些引脚。

| 名称 | 引脚 |
| --- | --- |
| `grove-g4` | `GPIO4` |
| `grove-g13` | `GPIO13` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("grove-g4", "up")
print(pin:read())
```
