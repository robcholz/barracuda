M5Stack Unit C6L 是 M5Stack 推出的 ESP32-C6 开发板。

- 开发板 ID：`m5stack-unit-c6l`
- 厂商：M5Stack
- 芯片：ESP32-C6
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`riscv32imac-unknown-none-elf`
- Profile：[`screen`](/zh/boards/profiles)
- Flash 布局：`boards/configs/m5stack-unit-c6l/partitions.csv`

## 构建和运行

```bash terminal
cargo board select m5stack-unit-c6l
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。

## 外设

| 设备 | 说明 | Lua 包 |
| --- | --- | --- |
| `display` | OLED 显示屏（SSD1306） | [`display`](/zh/plugins/vm-display) |
| `buttons` | 按键（PI4IOE5V6408 P0） | — |
| `led-strip` | RGB LED（WS2812，GPIO2） | [`light`](/zh/plugins/vm-led-strip) |
| `buzzer` | 无源蜂鸣器（GPIO11） | [`buzzer`](/zh/plugins/vm-buzzer) |

## 可用引脚

Lua 脚本按名称打开这些引脚。

| 名称 | 引脚 |
| --- | --- |
| `grove-g4` | `GPIO4` |
| `grove-g5` | `GPIO5` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("grove-g4", "up")
print(pin:read())
```
