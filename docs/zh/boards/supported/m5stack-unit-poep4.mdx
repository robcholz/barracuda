M5Stack Unit PoE-P4 是 M5Stack 推出的 ESP32-P4 开发板。

- 开发板 ID：`m5stack-unit-poep4`
- 厂商：M5Stack
- 芯片：ESP32-P4
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`riscv32imafc-unknown-none-elf`
- Profile：[`headless`](/zh/boards/profiles)（默认）
- Flash 布局：`boards/configs/m5stack-unit-poep4/partitions.csv`

## 构建和运行

```bash terminal
cargo board select m5stack-unit-poep4
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。

## 有线以太网

这块开发板的 IP101GRI PHY 在 `board.yml` 的 `hardware.ethernet` 下声明，[ESP32-P4 平台](/zh/platforms/esp32)在它上面运行 IP 协议栈：EMAC 接在 RMII 引脚上，PHY 地址为 1，复位接 `GPIO51`，并运行 DHCP 客户端。插上网线后，控制台会输出 `Ethernet is up at <地址>`；门户在该地址的 8787 端口上应答。

| 信号 | 引脚 |
| --- | --- |
| 参考时钟输入（来自 PHY） | `GPIO50` |
| MDC / MDIO | `GPIO31` / `GPIO52` |
| TX_EN / TXD0 / TXD1 | `GPIO49` / `GPIO34` / `GPIO35` |
| CRS_DV / RXD0 / RXD1 | `GPIO28` / `GPIO29` / `GPIO30` |
| PHY 复位 | `GPIO51` |

平台目前还没有驱动这块开发板上的 Wi-Fi 射频，所以 [Wi-Fi 插件](/zh/plugins/wifi)不会在它上面打开配置热点。

## 插件设置

- [`imessage-gateway`](/zh/plugins/imessage-gateway) 的 `receive-slots` 为 `0`：这块开发板不为消息通道接收循环预留连接。
