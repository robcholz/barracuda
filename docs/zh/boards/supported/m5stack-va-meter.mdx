M5Stack VAMeter 是 M5Stack 推出的 ESP32-S3 开发板。

- 开发板 ID：`m5stack-va-meter`
- 厂商：M5Stack
- 芯片：ESP32-S3
- 平台：[ESP32](/zh/platforms/esp32)
- Rust 目标：`xtensa-esp32s3-none-elf`
- Profile：[`screen`](/zh/boards/profiles)
- Flash 布局：`boards/configs/m5stack-va-meter/partitions.csv`

## 构建和运行

```bash terminal
cargo board select m5stack-va-meter
cargo run
cargo image deploy
```

请先安装工具链，参见 [ESP32](/zh/platforms/esp32)。

## 外设

| 设备 | 说明 | Lua 包 |
| --- | --- | --- |
| `display` | 显示屏（MIPI DBI） | [`display`](/zh/plugins/vm-display) |

## 可用引脚

Lua 脚本按名称打开这些引脚。

| 名称 | 引脚 |
| --- | --- |
| `grove-g8` | `GPIO8` |
| `grove-g9` | `GPIO9` |

```lua
local gpio = require("gpio")
local pin = gpio.open_input("grove-g8", "up")
print(pin:read())
```
