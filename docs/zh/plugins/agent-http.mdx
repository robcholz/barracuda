---
title: "Agent HTTP 插件"
sidebarTitle: "Agent HTTP"
description: "让 Agent 用 `http_request` 工具发出出站 HTTP 请求。"
---

把 `http` 插件的 `Http` 能力作为原生工具暴露给 Agent。

- 插件 ID：`agent-http`
- 依赖：`agent`、`http`
- 设置：无
- 上下文资源：无
- 提供的能力：无
- 所需能力：来自 `agent` 的 `AgentToolRegistry`、来自 `http` 的 `Http`
- Workflow：无
- Agent 工具：`http_request`
- Lua 包：无
- Web：无
- 任务：无
- 存储：无

注册期间，本插件把可等待的 `http_request` 工具添加到
`AgentToolRegistry`。它不拥有任何传输、工作区或后台任务。
