---
title: "Agent Scheduler 插件"
sidebarTitle: "Agent Scheduler"
description: "让 Agent 用 `scheduler_schedule` 和 `scheduler_cancel` 工具创建和取消计划任务。"
---

把 `scheduler` 插件的 `Scheduler` 能力作为原生工具暴露给 Agent。

- 插件 ID：`agent-scheduler`
- 依赖：`agent`、`scheduler`
- 设置：无
- 上下文资源：无
- 提供的能力：无
- 所需能力：来自 `agent` 的 `AgentToolRegistry`、来自 `scheduler` 的
  `Scheduler`
- Workflow：无
- Agent 工具：`scheduler_schedule`、`scheduler_cancel`
- Lua 包：无
- Web：无
- 任务：无
- 存储：无

注册期间，本插件把可等待的 `scheduler_schedule` 和
`scheduler_cancel` 工具添加到 `AgentToolRegistry`。它不拥有任何计划任务、存储、时钟或后台任务。
