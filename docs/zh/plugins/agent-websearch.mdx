把基于 Tavily 的网页搜索直接注册到 Agent 运行时，并提供一个用于 Tavily 配置的门户页面。

- 插件 ID：`agent-websearch`
- 依赖：`agent`、`webserver`、`captive-portal`、`http`
- 设置：无
- 上下文资源：无
- 提供的能力：无
- 需要的能力：来自 `captive-portal` 的 `CaptivePortal`、
  来自 `agent` 的 `AgentToolRegistry`、来自 `webserver` 的 `WebServer`、
  来自 `http` 的 `ClientFactory`
- Workflow：无
- Agent Tool：`web_search`
- Lua 包：无
- Web：门户入口 `agent-websearch`，带状态；`GET /api/tavily/status`、
  `POST /api/tavily`（参见 [HTTP](/zh/plugins/agent-websearch/http)）
- 任务：无
- 存储：插件作用域的 KV 键 `api_base` 和 `api_key`；内置
  `/resources/entry.js`、`/resources/figure.js`、`/resources/icon.svg`

注册期间，本插件把可等待的 `web_search` 工具直接添加到
`AgentToolRegistry`。

本插件负责 Tavily 配置、出站 HTTP 请求、服务商响应的校验，以及 Agent 工具响应的编码。`POST /api/tavily` 原子地替换插件私有 KV 作用域中的 `api_base` 和 `api_key` 条目，然后替换内存中生效的配置。插件注册时会恢复已持久化的配置。进行中的搜索保留配置的一个 `Rc`
快照，而不会克隆 API 密钥。API 密钥从不写入日志，也从不返回。

`GET /api/tavily/status` 报告生效的配置：
`{"configured":true,"config":{"api_base":"https://api.tavily.com"}}`，或者
`{"configured":false}`。对它使用其他方法，以及对 `/api/tavily` 使用 `POST` 以外的方法，都会回答 `405`。

门户入口通过 `CaptivePortal::register_with_status` 注册；它的
`GET /portal/status` 记录是 `EntryStatus::configured`：有生效的 Tavily 配置时为 `ready`
“已配置”，否则为 `off` “未配置”。它读取共享的内存配置槽。

一个可复用的 HTTP 工作区避免了反复分配请求头、读取和请求缓冲区。并发的搜索会收到 `busy`。服务商响应的上限为 64 KiB。

## 门户页面

需要来自 `captive-portal` 的 `CaptivePortal` 和一个私有的插件文件系统作用域。注册过程为一个 `WebEntry` 保留一个 `WebEntryRegistration`，该入口的 ID 为
`agent-websearch`，分组 `WebGroup::Agent`，顺序 20，标题 `Web search`
（双语），一段双语摘要，图标 `icon.svg`，图形 `figure.js`，模块
`entry.js`，以及一个 `ResourceFiles` 提供者。卸载时会移除导航入口和资源提供者；页面使用上面的两个 `/api/tavily` 路由。

Cargo 在编译本插件之前会自动运行声明的 `build` 任务。只想构建它的资源时，在仓库根目录运行 `cargo plugin run build --plugin agent-websearch`。该声明使用共享的 `tools/web/build.ts`
脚本。前端依赖以及 format/lint/check/test 命令在仓库根目录统一管理；测试放在本插件的 `resources/web/tests/` 中。独立的浏览器模块被写入本插件的 `filesystem/resources/entry.js`。通用的镜像构建器只在选中本插件时才包含该目录。门户外壳中不打包任何业务页面。共享的 UI 源码是构建时的辅助工具，而不是对其他贡献者文件的运行时依赖。

页面基于门户 UI 套件构建：带有实时 `loupe` 图形的页头
（`resources/web/figure.js`，使用外壳的全局 `HL`），没有标题图标；Tavily API 密钥；以及一个默认展开的“高级”折叠区，包含 `api_base`（默认值
`https://api.tavily.com`）。它根据门户语言显示中文或英文。
`resources/web/icon.svg` 是 Lucide 的 `search` 图标。

页面提交现有的 POST 配置契约，设备接受后调用 `context.refreshStatus()`，让门户的导航随之更新。它的页头显示“状态”徽标和设备保存的 API 地址，这些信息在挂载时以及每次保存被接受后从
`GET /api/tavily/status` 读取。它不声称设备接受即代表上游服务已经过验证。密钥使用密码输入框，从不保存在浏览器存储中，并在成功或卸载时清空。请求在卸载时取消，从不自动重试。现有的 HTTP API 在这里没有添加身份验证或传输加密；只在可信的配置网络中使用。
