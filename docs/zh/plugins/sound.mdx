title: "Sound 插件"
sidebarTitle: "Sound"
description: "让开发板的音频编解码器一次只借给一个使用者，并保存设备的音量。"
---

拥有开发板的主音频编解码器，以 `Sound` 的形式一次只把它借给一个使用者，并以 `Volume` 的形式保存设备的输出音量，这个音量由用户为所有声音统一设置。

- 插件 ID：`sound`
- 依赖：无
- 设置：无
- 上下文资源：外设槽位 `audio-codec.device`（`primary`，可选）
- 提供的能力：`Sound`、`Volume`
- 所需能力：无
- Workflow：无
- Agent 工具：无
- Lua 包：无
- Web：无
- 任务：无
- 存储：无

本插件只获取一次开发板的主 `AudioCodec`。编解码器的寄存器控制留在 ES8311/ES8389 的实现中；I2S 控制器、DMA 和有界缓冲区留在平台 HAL 的组合中。

- `Sound::lend()` 借出编解码器，直到返回的 `Lease` 被释放；没有编解码器或已被他人借用时返回 `None`。`is_present()` 表示开发板是否有编解码器，`is_idle()` 表示它当前是否可以借用。
- `Lease::codec_volume(own)` 是一个以设备音量的 `own` 百分比播放的声音所对应的编解码器 `0..=255` 输出音量，静音时为 0。使用者在播放每一段数据之前设置它，所以音量的改变会作用到正在播放的声音上。
- `Volume::set(volume, muted)` 设置设备的音量，就像系统界面根据用户的音量和静音设置所做的那样；在没有人借用时，它会立即把音量应用到编解码器上。

`Sound` 的克隆开销很小，克隆可以保存在任何任务中。本插件不做后台工作，也不拥有长时间运行的任务。
