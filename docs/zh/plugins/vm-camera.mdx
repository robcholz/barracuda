Camera 插件拥有开发板的摄像头，并把帧采集作为 `camera` Lua 包暴露给 Lua 代码，默认使用主摄像头。

- 插件 ID：`camera`
- 依赖：`vm`
- 设置：无
- 上下文资源：外设槽位 `camera.devices`（`*`）
- 提供的能力：无
- 所需能力：来自 `vm` 的 `LuaPackageRegistry`
- Workflow：无
- Agent 工具：无
- Lua 包：`camera`
- Web：无
- 任务：无
- 存储：无

本插件获取开发板上没有被其他插件占用的每个 `Camera`，主摄像头排在最前，并安装 `camera` Lua 包。OV2640/OV3660 的控制总线、并行采集和 DMA 仍由实现和平台 HAL 拥有。

Lua API：

- `camera.list() -> { name, ... }`：各摄像头在开发板上的名称，主摄像头排在最前
- `camera.available([name]) -> boolean`：指定名称的摄像头（不给出时为主摄像头）能否打开
- `camera.open([name]) -> handle`：打开指定名称的摄像头，不给出时打开主摄像头
- `camera.snap([capacity[, name]]) -> bytes, pixel_format` 用指定名称的摄像头（不给出时为主摄像头）采集一帧，未指定容量时预留 128 KiB 空间
- `handle:descriptor() -> width, height, pixel_format`
- `handle:capture(capacity) -> bytes`
- `handle:is_open() -> boolean`
- `handle:close()`

当开发板具备该设备时，这个 Lua 包声明一个稳定接口（`PackageInterface::Stable`），版本 3；版本 2 加入了 `camera.snap`，版本 3 加入了 `camera.list` 和摄像头名称。

从版本 2 开始提供的 `snap` 在没有句柄占用摄像头时使用它，在有句柄占用时返回 `nil, error`。

采集存储由调用方指定大小，在大块内存中上限为 512 KiB。没有摄像头的开发板报告不可用。每个摄像头同一时间只能打开一个句柄：显式关闭、词法 `<close>` 和垃圾回收都会阻止对它的后续操作，并归还摄像头，所以 `open` 可以再次使用；插件被撤销会阻止所有后续操作。
