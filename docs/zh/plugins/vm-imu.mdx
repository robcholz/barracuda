基于开发板的主 IMU 安装 `motion` Lua 包。

- 插件 ID：`imu`
- 依赖：`vm`
- 设置：无
- 上下文资源：外设槽位 `inertial-measurement.device`（`primary`，可选）
- 提供的能力：无
- 所需能力：来自 `vm` 的 `LuaPackageRegistry`
- Workflow：无
- Agent 工具：无
- Lua 包：`motion`
- Web：无
- 任务：无
- 存储：无

本插件只获取一次开发板的主 `Imu` 能力，并安装 `motion` Lua 包。I2C 的所有权、芯片初始化、整数单位换算以及相对于开发板的坐标轴映射，仍由所选的实现和生成的开发板 HAL 拥有。

Lua API：

- `motion.available() -> boolean`
- `motion.open() -> handle`
- `handle:descriptor() -> accelerometer_rate_hz, gyroscope_rate_hz, accelerometer_range_mg, gyroscope_range_mdps, has_temperature`
- `handle:read() -> acceleration_x_mg, acceleration_y_mg, acceleration_z_mg, angular_velocity_x_mdps, angular_velocity_y_mdps, angular_velocity_z_mdps, temperature_mc`
- `handle:is_open() -> boolean`
- `handle:close()`

当开发板具备该设备时，这个 Lua 包声明一个稳定接口（`PackageInterface::Stable`），版本 1。

没有 IMU 的开发板报告不可用。这个只能移动的内置能力每次开机只允许一个句柄；显式关闭、词法 `<close>`、垃圾回收和插件被撤销都会阻止后续操作。本插件不做后台采样，也不拥有长时间运行的任务。
