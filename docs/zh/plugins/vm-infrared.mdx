基于开发板的主红外发射器安装 `infrared` Lua 包；开发板带有红外接收器时也一并使用它。

- 插件 ID：`infrared`
- 依赖：`vm`
- 设置：无
- 上下文资源：外设槽位 `infrared.device`（`primary`，可选）
- 提供的能力：无
- 所需能力：来自 `vm` 的 `LuaPackageRegistry`
- Workflow：无
- Agent 工具：无
- Lua 包：`infrared`
- Web：无
- 任务：无
- 存储：无

本插件只获取一次开发板的主 `Infrared` 能力，并安装 `infrared` Lua 包。它使用的是语义层面的外设能力，从不直接操作背后的脉冲序列通道。

Lua API：

- `infrared.available() -> boolean`
- `infrared.can_receive() -> boolean`
- `infrared.send_nec(address, command) -> true` 在 38 kHz 载波上发送一条 NEC 命令；地址大于 255 时按扩展 NEC 发送
- `infrared.send_raw(timings[, carrier_hz[, duty_percent]]) -> true` 发送 `\{mark_us, space_us, mark_us, ...\}`，最多 512 个时长；未给出时载波为 38000 Hz、占空比 33 %
- `infrared.receive([timeout_ms]) -> kind, ...` 等待一帧：返回 `"nec", address, command`；按住按键时的重复码返回 `"repeat"`；其他协议返回 `"raw", timings`，timings 是以微秒为单位、从 mark 开始的表；超过 `timeout_ms` 时返回 `nil, "timeout"`

参数超出范围、在没有接收器的开发板上调用 `receive`，或在另一次调用进行期间调用，都会返回 `nil, error`。取消 `receive` 会停止接收。

当开发板具备该设备时，这个 Lua 包声明一个稳定接口（`PackageInterface::Stable`），版本 1。没有红外设备的开发板仍然会安装这个 Lua 包；`available` 返回 false，其他调用返回 `nil, error`。插件被撤销会阻止所有后续调用。

```lua
local infrared = require("infrared")
infrared.send_nec(0x04, 0x08)
local kind, address, command = infrared.receive(5000)
```
