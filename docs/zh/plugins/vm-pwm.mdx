基于开发板的可用 I/O 引脚安装 `pwm` Lua 包。

- 插件 ID：`pwm`
- 依赖：`vm`
- 设置：无
- 上下文资源：`hal.exposed_io`
- 提供的能力：无
- 所需能力：来自 `vm` 的 `LuaPackageRegistry`
- Workflow：无
- Agent 工具：无
- Lua 包：`pwm`
- Web：无
- 任务：无
- 存储：无

本插件共享开发板统一的可用 I/O 所有者，并安装 `pwm` Lua 包。返回的输出实现了 `embedded_hal::pwm::SetDutyCycle`；定时器、通道和引脚复用的分配留在平台提供者内部。

Lua API：

- `pwm.available(name) -> boolean`
- `pwm.open(name, frequency_hz) -> handle`
- `handle:max_duty() -> integer`
- `handle:set_duty(value)`
- `handle:set_percent(percent)`
- `handle:is_open() -> boolean`
- `handle:close()`

打开操作会从所有其他可用协议所用的同一个所有者那里取走所选的物理引脚。不支持的路由会在令牌转移之前失败。
