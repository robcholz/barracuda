基于开发板的主旋转编码器安装 `encoder` Lua 包。

- 插件 ID：`rotary-encoder`
- 依赖：`vm`
- 设置：无
- 上下文资源：外设槽位 `rotary-encoder.device`（`primary`，可选）
- 提供的能力：无
- 所需能力：来自 `vm` 的 `LuaPackageRegistry`
- Workflow：无
- Agent 工具：无
- Lua 包：`encoder`
- Web：无
- 任务：无
- 存储：无

本插件只获取一次开发板的主 `RotaryEncoder` 能力，并安装 `encoder` Lua 包。平台的脉冲计数器在硬件中计数编码器的边沿，因此两次读取之间的转动不会丢失。

Lua API：

- `encoder.available() -> boolean`
- `encoder.open() -> handle`
- `handle:position() -> edges`：自启动或上次复位以来的有符号位置
- `handle:delta() -> edges`：自上次 `delta` 以来转过的边沿数
- `handle:reset()`：把当前位置设为零
- `handle:is_open() -> boolean`
- `handle:close()`

位置以正交边沿计数，编码器两路信号的一个完整周期计 4。按下旋钮属于开发板 `buttons` 外设的一个按键，不属于这个包。

当开发板具备该设备时，这个 Lua 包声明一个稳定接口（`PackageInterface::Stable`），版本 1。

没有旋转编码器的开发板报告不可用。这个只能移动的内置能力每次开机只允许一个句柄；显式关闭、词法 `<close>`、垃圾回收和插件被撤销都会阻止后续操作。本插件不拥有长时间运行的任务。
