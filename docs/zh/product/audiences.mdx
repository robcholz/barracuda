Barracuda 服务于阶梯上每一级的人。其中最重要的有三类：开发者、教育领域，以及教育类开发板公司。

## 开发者

开发者是核心用户。他们分布在整架阶梯上。

| 是谁 | 阶梯层级 | 想要什么 | Barracuda 给他们什么 |
| --- | --- | --- | --- |
| 创客和爱好者 | 1–2 | 为项目做一台智能设备，而不用和工具链较劲 | 从浏览器安装、能驱动硬件的板上 Agent、只包含他们所选插件的固件 |
| 应用开发者 | 3 | 快速构建带 UI 的真正设备应用 | Live Editor 和浏览器里的 Agent，从浏览器烧录 |
| 插件开发者 | 4 | 只添加一次能力，就能在所有地方工作 | 插件契约，以及在他们自己的编程 Agent 中使用的 `create-plugin` skill |
| 贡献者 | 5 | 把 Barracuda 带到他们关心的硬件上 | `create-board` 和 `create-platform` |
| 构建者 | 6 | 适配芯片和任务的产品固件 | `fully-customize`，以及一切都是可移除插件的运行时 |

开发者最看重的是：嵌入式上的现代开发体验、理解代码库的 Agent，以及无需离开平台就能想钻多深就钻多深的自由。

## 教育

学校、大学、培训项目和创客空间。

- **第一天无需配置**。学生在学校电脑上从浏览器安装；不需要为每个座位管理工具链。
- **从语言到硬件**。学生首先用日常语言让开发板做一件涉及物理世界的事，并看到 Agent 为此编写的脚本。
- **从脚本到系统**。阶梯同时也是一套课程：脚本、配置、应用、插件，最后是开发板和平台。每一级都讲授嵌入式系统中真实的一层。
- **真实的硬件，真实的代码**。学生看到的一切都是真实的：脚本、应用、插件、源码。

## 教育类开发板公司

设计和销售用于学习和创作的开发板与套件的公司。

- **他们的开发板，为 AI 做好准备**。用 `create-board` 添加的开发板会出现在网页安装器中；客户从浏览器把 Barracuda 安装到开发板上。
- **他们的硬件，向 Agent 开放**。板载外设成为 VM 包和插件，因此板上 Agent、应用和脚本可以使用开发板上的一切。
- **随套件一起销售的课程**。阶梯为套件提供了一条从第一课到高级项目的路径。
