## 一句话

Barracuda 是一个基于插件的嵌入式运行时和 Agent 平台：插件是构建每台设备的基本单元，AI Agent 在每一级完成构建工作——从编写一段立即驱动硬件的脚本，到生成为新开发板量身定制的固件。

## 问题

嵌入式开发是软件领域中现代开发体验尚未到达的最后一角。

- **入门是工具链问题。**在开发板做出任何有趣的事之前，新手要安装编译器、驱动、SDK 和烧录工具，并和它们逐一较劲。很多人就止步于此。
- **每个项目都从零开始。**Wi-Fi 配网、网页 UI、存储、调度、消息和 LLM 客户端，要为每个产品、在每颗芯片上、用每家厂商的 SDK 重新构建一遍。
- **AI 止步于设备边缘。**Agent 现在可以编写一个网页应用的大部分代码，但在微控制器上，它们大多只能产出代码片段，仍然需要人把它们接入板级支持包、构建系统和内存预算。而当一台设备“有 AI”时，它通常只是云服务的瘦客户端；设备本身无法推理或适应。
- **硬件是碎片化的。**每个芯片系列都有自己的 SDK、执行器、网络栈和烧录流程。把项目迁移到另一块开发板，往往意味着重写。

## Barracuda 是什么

**由插件构成的运行时。**Barracuda 设备运行一个可移植的 System，它注册一组插件并统一启动它们。Wi-Fi、Web 服务器、设备门户、Agent、脚本 VM、Workflow 自动化、每个消息通道以及每个外设绑定都是插件。同一个 System 运行在微控制器和桌面主机上；只有底层的平台会变化。

**设备上的 Agent。**每台 Barracuda 设备都带有一个轻量的 Agent。它运行在设备本身上，通过用户已经在用的消息通道与用户交谈，并进行即时编程：它编写一段简短的 VM 脚本，在真实硬件上运行，然后在同一个对话中汇报结果。

**构建时的 Agent。**而*为*设备构建，同样借助 Agent。浏览器里的 Agent 在 Live Editor 中构建应用及其 UI。在开发者的电脑上，Claude Code、Cursor 和 Codex 等编程 Agent 使用 Barracuda 的 skill 创建插件、添加开发板和平台，并组合完全定制的固件。

**是阶梯，不是悬崖。**人们从浏览器安装开始，与他们的开发板对话。他们可以止步于此，也可以继续攀登：选择固件中的插件、构建应用、编写插件、添加开发板，最后让整个固件适配芯片和预算。每上一级，都用一点便利换来大量自由，而每一级都有 Agent 承担繁重的工作。

## 原则

1. **插件是基本单元。**每项能力都是一个带有声明式契约的插件。定制设备意味着选择、配置、精简或编写插件——永远不需要分叉运行时。
2. **每一级都有 Agent。**如果某一步可以由 Agent 完成，产品就会被设计成让 Agent 能把它做好：对 Agent 友好的契约、编码了我们约定的 skill，以及既写给人也写给模型阅读的文档。
3. **合适的 Agent 在合适的位置。**即时的工作在设备上完成，用一个小 Agent 和一段小脚本。繁重的生成工作在算力和上下文充足的地方完成：浏览器中和开发者的电脑上。我们从不要求设备去做工作站的工作。
4. **现代开发体验。**入门不需要工具链。从浏览器安装，在网页上配置，在手机上聊天。当开发者真的打开源码时，面对的是一个 Cargo 工作区、一条选择开发板的命令、一条运行的命令。
5. **同一个 System，每个目标。**开发板和平台各自独立选择。可移植的 System 及其插件在 ESP32、STM32 和笔记本电脑之间不会改变，因此工作可以在目标之间迁移，而不必重写。
6. **适配资源。**Barracuda 可以缩小到只有几百 KB RAM 的微控制器，也可以扩展到带外部内存的开发板和桌面电脑。构建者交付的固件只包含它需要的插件。
7. **开放且可检查。**用户能看到 Agent 写了什么、运行了什么。开发者阅读的源码、文档和 skill，与 Agent 阅读的完全相同。

## 成功是什么样子

- 一名学生插上开发板，打开一个网页，几分钟之内就让开发板按某种图案闪烁 LED，并看着它发生，屏幕上还显示着完成这件事的脚本。
- 一位创客选择摄像头和显示插件，去掉不需要的部分，构建一次，就得到一台适合自己项目的设备，而无需编写代码。
- 一位应用开发者在 Live Editor 中描述一个小型设备应用，预览它的 UI，然后烧录。
- 一位插件作者让他的编程 Agent“为这个传感器创建一个插件”，得到一个遵循 Barracuda 所有约定、带有测试和文档的插件。
- 一家开发板厂商用一个 skill 添加他们的开发板，它就会出现在网页安装器中，供他们的客户使用。
- 一位构建者交付一个恰好适配其芯片和任务的产品固件。
