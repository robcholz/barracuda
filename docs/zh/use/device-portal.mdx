---
title: "设备门户"
description: "在设备所在网络中的任意浏览器上设置 Wi-Fi、模型、消息通道、文件和应用。"
---

设备门户是设备自己的网页应用，由设备在 `/portal/` 路径下提供。每个启用且带有设置的插件都会向门户添加自己的页面，所以门户始终与固件保持一致。

## 打开门户

| 设备状态 | 地址 |
| --- | --- |
| 尚未连接 Wi-Fi 的开发板 | 加入开放网络 `Barracuda Setup`，然后打开 `http://192.168.4.1/portal/` |
| 已连上你网络的开发板 | `http://DEVICE_ADDRESS:8787/portal/` |
| `local-linux` | `http://10.42.0.2:8787/portal/` |

门户会跟随浏览器的语言显示中文或英文。

## 页面

| 页面 | 来自插件 | 你可以设置 |
| --- | --- | --- |
| Wi-Fi | [`wifi`](/zh/plugins/wifi) | 扫描并加入网络；设置热点 |
| 模型配置 | [`agent`](/zh/plugins/agent) | 每种 Agent 用途对应的模型服务、模型和 API key |
| 网页搜索 | [`agent-websearch`](/zh/plugins/agent-websearch) | Agent 使用的搜索服务 |
| Web 聊天 | [`imessage-web`](/zh/plugins/imessage-web) | 在浏览器中与 Agent 对话 |
| 微信、QQ、Telegram、BlueBubbles、Inkbox | [消息通道](/zh/use/channels) | 绑定账号、所有者和配对码 |
| 文件 | [`files`](/zh/plugins/files) | 浏览 Workspace 和插件文件 |
| 应用 | [`app-portal`](/zh/plugins/app-portal) | 审核并安装应用 |

只有当对应插件在固件中时，页面才会出现。参见[开发板 profile（配置档）](/zh/boards/profiles)。

<Warning>
  门户的 HTTP API 没有身份验证，也没有传输加密，而且设置热点是开放的。只在你信任的网络中配置设备。
</Warning>

在终端中，`cargo cli configure` 无需浏览器就能填写同样的模型、网页搜索和消息通道设置。参见[构建与运行](/zh/get-started/build-and-run)。
